## Introduction

The <a href="https://exxn.es/en/" target="_blank" rel="noopener noreferrer">EXXN IoT Gateway</a> is a versatile device with an ARM processor that can be adapted to a variety of use cases, including monitoring environmental sensors, energy consumption, radon gas levels, marine environments, and edge computing.

This guide covers integrating the EXXN IoT Gateway Cell 1024 with ThingsBoard via the MQTT API with Access Token authentication.

<ImageGallery images={[{"src":"/src/assets/devices-library/exxn/ennx-dashboard.png","alt":"Example ThingsBoard dashboard displaying EXXN IoT Gateway metrics","caption":"Example ThingsBoard dashboard displaying EXXN IoT Gateway metrics"}]} />

## Prerequisites

- EXXN IoT Gateway Cell 1024
- Device connected to the internet (via Ethernet, Modem, or Wi-Fi)
- ThingsBoard instance (Cloud or on-premise)

## Technical specifications

<ImageGallery images={[{"src":"/src/assets/devices-library/exxn/cell_1024.jpg","alt":"EXXN IoT Gateway Cell 1024","caption":"EXXN IoT Gateway Cell 1024"}]} />

- ARM Cortex-A53 Quad-Core 64-bit Processor
- GPU Mali 470
- 2 GB DDR4 RAM
- 8 GB eMMC storage
- 10/100 Mbit/s Ethernet
- Wi-Fi 802.11 b/g/n/AC
- Bluetooth 4.2
- PoE support

## Provisioning the device in ThingsBoard

### Create a device

Open your ThingsBoard instance or <a href="https://thingsboard.cloud/" target="_blank" rel="noopener noreferrer">ThingsBoard Cloud</a> and log in as a tenant administrator.

Go to **Devices** and click **+ Add device &#8702; Add new device**. 
Enter a device name, and click **Add**.

<ImageGallery images={[{"src":"/src/assets/devices-library/exxn/exxn-create-device-cell-1.png","alt":"Create a new device in ThingsBoard","caption":"Create a new device in ThingsBoard"}]} />

Click on the device to open the device details, and copy the auto-generated **access token** by clicking **Copy access token**.

<ImageGallery images={[{"src":"/src/assets/devices-library/exxn/exxn-create-device-cell-2.png","alt":"Copy the auto-generated access token from device details","caption":"Copy the auto-generated access token from device details"}]} />

### Configure the device

Open the Cell 1024 administration web interface at `https://[IP_DEVICE]` and go to the **Cloud** tab.

<ImageGallery images={[{"src":"/src/assets/devices-library/exxn/conn1.png","alt":"Cell 1024 administration web interface — Cloud tab","caption":"Cell 1024 administration web interface — Cloud tab"}]} />

Enable Cloud control and fill in the connection parameters:

- **Cloud Platform**: ThingsBoard
- **MQTT broker URL**: address of your ThingsBoard instance
- **MQTT broker port**: port used by the broker
- **TLS**: enable if your server uses Transport Layer Security
- **Connection Type**: Access Token
- **Access Token**: the token copied from ThingsBoard

<ImageGallery images={[{"src":"/src/assets/devices-library/exxn/conn2.png","alt":"MQTT connection parameters configured for ThingsBoard","caption":"MQTT connection parameters configured for ThingsBoard"}]} />

<Aside type="note">
Currently, EXXN IoT Gateways use the Access Token integration method. A Pre-Provisioning method that eliminates the need to copy the token manually is under development.
</Aside>

Click **Save configuration**.

<ImageGallery images={[{"src":"/src/assets/devices-library/exxn/conn3.png","alt":"Save configuration to apply the connection settings","caption":"Save configuration to apply the connection settings"}]} />

To verify the connection, go to **Devices**, open the device details, and check the **Attributes &#8702; Client attributes** tab.  
If the device connected successfully, you will see attributes such as `serial_number`, `last_reboot`, `device_model`, and others.

<ImageGallery images={[{"src":"/src/assets/devices-library/exxn/exxn-client-attributes-device-1.png","alt":"Client attributes populated after successful device connection","caption":"Client attributes populated after successful device connection"}]} />

## ThingsBoard configuration

### Configure the datalogger

The EXXN IoT Gateway is configured via a JSON **Shared attribute** with the key `config`. This attribute controls which sensors are enabled, their sampling periods, and MQTT reporting.

Go to the device **Attributes** tab and add a new **Shared** attribute with key `config` and type **JSON**.

<ImageGallery images={[{"src":"/src/assets/devices-library/exxn/exxn-shared-attributes-device-1.png","alt":"Add a Shared attribute with key config and type JSON","caption":"Add a Shared attribute with key config and type JSON"}]} />

### Create a dashboard

Navigate to **Dashboards** and click **+Add dashboard &#8702; Create new dashboard** to create a new <a href="/docs/user-guide/dashboards/" target="_blank" rel="noopener noreferrer">dashboard</a>. Enter a name and click **Add**.
Add a **Radial gauge** widget from the **Analogue gauges** bundle.  
Specify the device `CELL1024_01` and its key `sc1_temperature` as the datasource.

## Troubleshooting

- **No MQTT connection** — verify the device has internet access and can reach the ThingsBoard broker address and port.
- **No telemetry appearing** — confirm the Access Token on the device matches the one configured in ThingsBoard.

For additional support, contact <a href="mailto:troubleshooting@exxn.es">troubleshooting@exxn.es</a> or visit <a href="https://exxn.es/en/" target="_blank" rel="noopener noreferrer">exxn.es</a>.
