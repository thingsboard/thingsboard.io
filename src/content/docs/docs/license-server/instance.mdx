The **ThingsBoard License Server** tracks every ThingsBoard instance (server process) that runs with your license.

## How Instances Are Registered

On startup, an instance registers with the License Server using your license secret and receives an **instance ID**. It then sends periodic license check requests to confirm the license is valid. See <DocLink product={Products.LICENSE} path="what-is-license-server/#architecture" bold={false} target="_blank">Architecture</DocLink>.

The **Subscriptions** and **Perpetual licenses** pages of the License Portal show how many production and development instances each license uses.

## Cluster Setup

All nodes of a ThingsBoard cluster share one license secret, so adding or removing nodes requires no license changes.

Each node counts as one production instance. For a cluster or high availability (HA) setup, buy enough production instances when you create a <DocLink product={Products.LICENSE} path="subscription/" bold={false} target="_blank">subscription</DocLink> or a <DocLink product={Products.LICENSE} path="perpetual/" bold={false} target="_blank">perpetual license</DocLink>.

## Floating Mode

In <a href="https://en.wikipedia.org/wiki/Floating_licensing" target="_blank" rel="noopener noreferrer">floating mode</a>, instances aren't tied to specific hardware. You can deactivate Node 1 and reuse its license secret on Node 2.

<Aside type="caution">
Don't run more instances than your license covers. If the License Server detects extra instances, ThingsBoard shuts down the instances.
</Aside>
