A License Portal account supports unlimited users. Every user is a **customer administrator** and can create and edit subscriptions and perpetual licenses, and manage billing.

The **Users** page lists each user's creation time, first name, last name, and email. Use the icons above the list to search and refresh it.

## Add a User

<Steps>

1. Go to **Users** and click **Add User** (**+**).
2. Enter the **Email** (required) and, optionally, **First Name**, **Last Name**, and **Description**.
3. Select the **Activation method**:
   - **Display activation link** — the License Portal shows a link to copy and send to the user;
   - **Send activation mail** — the License Portal emails the link to the user.
4. Click **Add**.

</Steps>

The user opens the link to activate the account.

## Manage Users

For each user, you can:

- **Log in as the user** — open the License Portal with that user's account;
- **Delete** the user.

## Audit Logs

The **Audit Logs** page records actions in your account, such as adding a user, so you can track who changed what and when. Each entry shows the **Timestamp**, **Entity Type**, **Entity Name**, **User**, **Type**, and **Status**.

Click **`⋯`** in the **Details** column to view the action data as JSON. Use the icons above the list to search and refresh it.

To change the period, click the time window button, select **For all time**, **Last**, **Range**, or **Relative**, and click **Update**.
