---
title: Perpetual fallback license
description: Definition of perpetual fallback license and how to purchase it via ThingsBoard License Server.
---

A perpetual fallback license is a license that allows you to use a specific version of software without an active subscription for it.
When purchasing a perpetual fallback license, you get the right to use ThingsBoard indefinitely, with one year of software updates included. After the first year, you can continue using the platform and purchase software updates for subsequent years at a discounted fee.

A single perpetual fallback license covers a single ThingsBoard instance (server process).
So, if you want to run ThingsBoard in HA mode, you will need at least two licenses.

In order to purchase a perpetual fallback license, register on the License Portal and then follow these simple steps:

- Go to **Perpetual** → **Choose a product** → Input **Billing info** → **Create**

Or choose an exact product from [pricing](/pricing/?product=thingsboard-pe). Once you press the **Get your license** button, you will be routed to the License Portal authentication/registration, or directly to the **Billing info** step if you are already logged in on the License Portal.
