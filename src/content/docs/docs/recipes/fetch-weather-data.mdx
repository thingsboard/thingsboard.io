Use the <DocLink product={Products.CE} path="reference/rule-engine/nodes/external/rest-api-call">REST API Call</DocLink> rule node to call the OpenWeatherMap API on a schedule and store outdoor temperature, humidity, and weather conditions as time series telemetry on the **Building A** asset.

## Use Case

**Building A** has a known geographic location.

ThingsBoard:
- reads the `appid` API key from the assigned customer's server attributes
- reads `latitude`, `longitude`, and `units` from the asset's server attributes
- calls the OpenWeatherMap current weather endpoint on a fixed interval
- extracts temperature and humidity from the response
- saves them as telemetry keys on the asset

## Step 1. Get an OpenWeatherMap API Key

In order to get weather data you should register on a website which will provide it. In this case <a href="https://openweathermap.org/" target="_blank" rel="noopener noreferrer">OpenWeatherMap</a> will be used.

After signing up there go to the <a href="https://home.openweathermap.org/api_keys" target="_blank" rel="noopener noreferrer">API keys page</a> to get your API key.

## Step 2. Add API Key to Customer A

Open **Customer A** &#8702; **Attributes** tab and add a server attribute:

- **Key**: `appid`
- **Type**: `String`
- **Value**: your OpenWeatherMap API key

## Step 3. Create Asset under Customer A

<p>Go to <strong>Assets</strong> and create an asset:</p>

- **Name**: `Building A`
- **Asset profile**: `building`

Open **Building A &#8702; Attributes** tab and add the following **Server attributes**:

| Key | Type | Example |
|-----|------|---------|
| `latitude` | Double | `59.338970597112066` |
| `longitude` | Double | `18.057188573215196` |
| `units` | String | `metric` (Celsius + m/s), `imperial` (Fahrenheit + mph), or empty for Kelvin |

<p>Then, go to <strong>Customers &#8702; Customer A &#8702; Manage customer assets</strong> and click <strong>+ Assign new asset</strong>. Select the <strong>Building A</strong> asset to assign to the customer, and click <strong>Assign</strong>.</p>

<Aside type="note">
  To simplify setup, download the asset with predefined attributes as a <a href="/resources/docs/recipes/fetch-weather-data/building_a_asset_with_coordinates.csv" download="building_a_asset_with_coordinates.csv"><strong>CSV file</strong></a> and <DocLink product={Products.CE} path="user-guide/provisioning/#bulk-provisioning" target="_blank">import it</DocLink>. Then, assign the asset to <strong>Customer A</strong>.
</Aside>

## Step 4. Create Rule Chain

You can import a ready-made rule chain or build it manually.

**Option 1. Import rule chain**

- Download the **Outside Temperature/Humidity** rule chain as a <a href="/resources/docs/recipes/fetch-weather-data/outside_temperature_humidity_rule_chain.json" download="outside_temperature_humidity_rule_chain.json"><strong>JSON file</strong></a> and <DocLink product={Products.CE} path="user-guide/rule-engine/#import-a-rule-chain" target="_blank">import</DocLink> it into your instance.

    <Aside type="note">
      For the generator node, set the **Building A** asset as the originator.
    </Aside>

**Option 2. Create manually**

- <DocLink product={Products.CE} path="user-guide/rule-engine/#create-a-rule-chain" target="_blank">Create a new rule chain</DocLink> named `Outside Temperature/Humidity`, open it, and add the following nodes:

### Step 4.1. Generator Node

Add a <DocLink product={Products.CE} path="reference/rule-engine/nodes/action/generator" target="_blank">Generator</DocLink> node connected to the **Input** node.

This node triggers a weather fetch on a fixed interval with the asset as the originator.

- **Name**: `Trigger Weather Fetch`
- **Generation parameters**:
  - **Generated messages limit**: `100`
  - **Generation frequency in seconds**: `60` seconds
- **Originator**:
  - **Originator type**: `Asset`
  - **Asset**: `Building A`
- **Generate function**:

```javascript
return { msg: {}, metadata: {}, msgType: 'POST_TELEMETRY_REQUEST' };
```

### Step 4.2. Customer Attributes Node

Add the <DocLink product={Products.CE} path="reference/rule-engine/nodes/enrichment/customer-attributes" target="_blank">Customer Attributes</DocLink> node and connect it to a **Generator** node with a relation type **Success**.

This node will put customer attribute APPID into the metadata of message.

- **Name**: `Get Customer API Key`
- **Mapping of customer's**: `Attributes`
- **Attributes mapping**:
  - **Source attribute key**: `appid`
  - **Target key**: `appid`

### Step 4.3. Originator Attributes Node

Add an <DocLink product={Products.CE} path="reference/rule-engine/nodes/enrichment/originator-attributes" target="_blank">Originator Attributes</DocLink> node and connect it to the **Customer Attributes** node with relation type **Success**.

This node loads the building's location attributes into message metadata.

- **Name**: `Get Asset Attributes`
- **Server attributes**: `latitude`, `longitude`, `units`

The values become available as `${ss_latitude}`, `${ss_longitude}`, `${ss_units}` in the next node's URL pattern.

### Step 4.4. REST API Call Node

Add a <DocLink product={Products.CE} path="reference/rule-engine/nodes/external/rest-api-call" target="_blank">REST API Call</DocLink> node and connect it to the **Originator Attributes** node with relation type **Success**.

- **Name**: `Fetch Weather Data`
- **Endpoint URL pattern**:

```
https://api.openweathermap.org/data/2.5/weather?lat=${ss_latitude}&lon=${ss_longitude}&units=${ss_units}&appid=${appid}
```

- **Request method**: `GET`
- **Credential type**: `Anonymous`

On success (HTTP 2xx), the JSON response becomes the message body for the next node.

<Aside type="note">
  Add a <DocLink product={Products.CE} path="reference/rule-engine/nodes/action/log" target="_blank">Log</DocLink> node on the <strong>Failure</strong> output to capture errors such as an invalid API key or exceeded rate limits.
</Aside>

### Step 4.5. Script Transformation Node

Add a <DocLink product={Products.CE} path="reference/rule-engine/nodes/transformation/script" target="_blank">Transformation Script</DocLink> node and connect it to the **REST API Call** node with relation type **Success**.

This node extracts the relevant weather fields from the API response.

- **Name**: `Extract Weather Fields`

<Tabs>
  <TabItem label="TBEL">
    ```javascript
    var newMsg = {
      "outsideTemp": msg.main.temp,
      "outsideMaxTemp": msg.main.temp_max,
      "outsideMinTemp": msg.main.temp_min,
      "outsideHumidity": msg.main.humidity,
    };

    return {msg: newMsg, metadata: metadata, msgType: msgType};
    ```
  </TabItem>
  <TabItem label="JavaScript">
    ```javascript

      "outsideMaxTemp": msg.main.temp_max,

      "outsideHumidity": msg.main.humidity,
    };

    return {msg: newMsg, metadata: metadata, msgType: msgType};
    ```
  </TabItem>
</Tabs>

### Step 4.6. Save Time Series Node

Add a <DocLink product={Products.CE} path="reference/rule-engine/nodes/action/save-timeseries" target="_blank">Save Time Series</DocLink> node and connect it to the **Transformation Script** node with relation type **Success**.

- **Name**: `Save Weather Telemetry`

### Step 4.7. Check Node Connections

- **Trigger Weather Fetch &#8702;** `Success` **&#8702; Get Customer API Key**
- **Get Customer API Key &#8702;** `Success` **&#8702; Get Asset Attributes**
- **Get Asset Attributes &#8702;** `Success` **&#8702; Fetch Weather Data**
- **Fetch Weather Data &#8702;** `Success` **&#8702; Extract Weather Fields**
- **Extract Weather Fields &#8702;** `Success` **&#8702; Save Weather Telemetry**

Save the rule chain.

## Step 5. Verify the Result

Open **Building A &#8702; Latest telemetry** tab.

Within 60 seconds, the following keys should appear:

| Key | Description |
|-----|-------------|
| `outsideTemp` | Current temperature |
| `outsideHumidity` | Relative humidity (%) |
| `outsideMaxTemp` | Maximum temperature |
| `outsideMinTemp` | Minimal temperature |

Download the pre-built dashboard as a <a href="/resources/docs/recipes/fetch-weather-data/weather_dashboard.json" download="weather_dashboard.json"><strong>JSON file</strong></a> and <DocLink product={Products.CE} path="user-guide/dashboards/#import-dashboard" target="_blank">import</DocLink> it.

The <strong>Weather Dashboard</strong> displays <strong>Building A</strong> on the map, a table with <strong>humidity and temperature metrics</strong>, and real-time <strong>temperature</strong> and <strong>humidity graphs</strong>.
