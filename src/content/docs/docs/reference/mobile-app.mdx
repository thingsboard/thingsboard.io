The ThingsBoard Mobile Application is an open-source project based on [Flutter](https://flutter.dev/) that lets you build IoT mobile applications with minimum coding effort.
It is available for both iOS and Android and licensed under **Apache 2.0**.

## Features

- Browse and monitor IoT dashboards on your phone or tablet
- Manage devices and view alarms
- Customize the app with your branding (white-labeling)
- OAuth 2.0 and self-registration support
- QR code scanner for device provisioning
- Localization support

## Source code

The app is developed in the [flutter_thingsboard_app](https://github.com/thingsboard/flutter_thingsboard_app) GitHub repository.

- For ThingsBoard Community Edition, build the `v.1.8.1` tag, the latest app release for Community Edition.
- The `master` branch holds app 2.0.0 and later, which require ThingsBoard 4.4.0 or later.
- Releases 1.x of the former Professional Edition app are in the [flutter_thingsboard_pe_app](https://github.com/thingsboard/flutter_thingsboard_pe_app) repository.
