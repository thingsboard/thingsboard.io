Integrations connect ThingsBoard to the external system your devices already talk to. Choose the type based on where your data is coming from, not what the data contains — browse the categories below to find yours.

## Generic Protocols & Transports

Integrations for devices and systems using standard protocols and transports.

<PlatformIntegrationsGrouped product={Products.CE} group="standard-protocols" />

## LoRaWAN Network Servers

Integrations for low-power, long-range devices connected through LoRaWAN network servers.

<PlatformIntegrationsGrouped product={Products.CE} group="lorawan-servers" />

## Cloud IoT Platforms

Integrations for devices managed through cloud IoT platforms.

<PlatformIntegrationsGrouped product={Products.CE} group="cloud-iot" />

## Messaging & Event Streaming

Integrations for systems exchanging data through brokers, queues, and event streams.

<PlatformIntegrationsGrouped product={Products.CE} group="message-brokers" />

## Connectivity Platforms

Integrations for devices connected through managed LPWAN or cellular networks.

<PlatformIntegrationsGrouped product={Products.CE} group="nb-iot-cellular" />

## Industrial Protocols

Integrations for PLCs, controllers, and industrial equipment using industrial protocols.

<PlatformIntegrationsGrouped product={Products.CE} group="industrial-opc" />

## Custom

Integrations for external systems requiring custom processing or logic.

<PlatformIntegrationsGrouped product={Products.CE} group="custom" />

<Aside type="note">
  **TCP**, **UDP**, and **Custom** integrations run as **remote-only** — they must be deployed outside the main ThingsBoard process. All other types support both embedded and remote deployment.
</Aside>
