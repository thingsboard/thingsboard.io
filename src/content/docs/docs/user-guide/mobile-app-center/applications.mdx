The **Applications** tab in the **Mobile App Center** manages the mobile application configurations registered with your ThingsBoard instance. Each application entry defines the package name, platform, authentication secret, version requirements, and store links used by the <DocLink product={Products.MOBILE} path="" target="_blank">ThingsBoard mobile app</DocLink>.

## Add Application

<Steps>
1. Go to **Mobile center** and open the **Applications** tab.
2. Click **+ Add application** in the upper-right corner.
3. Enter the **Application package** name (e.g. `com.example.myapp`).
4. Select the **Platform type**: **Android** or **iOS**.
5. An **Application Secret** is generated automatically. Copy and store it — your mobile application uses this secret to authenticate with the ThingsBoard API. You can also regenerate it or enter your own.
6. Set the **Status**:
   - **Draft** — application is in development; store information can be added later.
   - **Published** — application is live and available to end users.
   - **Deprecated** — application is no longer actively supported but still accessible.
   - **Suspended** — application is temporarily disabled.
7. (Optional) In **Version information**, specify **Min version** (minimum app version allowed to connect) and **Latest version** (current release), with optional release notes.
8. Add **Store information**:
   - **Android**: **Google Play link** and **SHA256 certificate fingerprints**.
   - **iOS**: App Store URL and App ID.
9. Click **Add** to save. The application appears in the **Applications** list with its status, min version, and latest version.
</Steps>

## Edit Application

All fields except **platform type** can be edited after creation.

<Steps>
1. Click the application row to open its details panel.
2. Click the **pencil** (edit) icon to enter edit mode.
3. Make the necessary changes.
4. Click the **checkmark** icon to save. The updated values appear in the **Applications** list.
</Steps>

## Delete Application

<Steps>
1. Click the **trash** icon on the application row.
2. In the **Delete application** dialog, type `delete application` and click **I understand consequences, delete application**. To disable the application without deleting it, click **Suspend** instead.
</Steps>

<Aside type="caution">
  Deletion is permanent and cannot be undone.
</Aside>
