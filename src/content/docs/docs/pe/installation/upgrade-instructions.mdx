Summary table of supported ThingsBoard upgrade instructions. Releases before 4.4 were published as ThingsBoard Professional Edition (PE). To upgrade from Community Edition (4.3 and earlier), use the <DocLink product={Products.PE} path="installation/upgrade-from-ce/">following instructions</DocLink>. If you're still running the legacy all-in-one `tb-pe` Docker image, see <DocLink product={Products.PE} path="installation/upgrade-instructions/docker-legacy-image-migration/">Migrating from the legacy all-in-one tb-pe image</DocLink> first.

<Aside type="caution" title="Perpetual license: check the software updates period first">
A perpetual license activates only releases published before its software updates period ends. The license is checked when ThingsBoard starts, after the upgrade has already migrated the database. Before you upgrade, compare the end of the software updates period, shown on the **Perpetual licenses** page of the <a href="https://license.thingsboard.io/" target="_blank" rel="noopener noreferrer">License Portal</a>, with the release date of the target version. If the target version was released after that date, renew the software updates period first.
</Aside>
