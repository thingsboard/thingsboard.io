This guide walks you through deploying ThingsBoard on an AWS EC2 instance.

## Prerequisites

You need admin access to EC2 resources in your AWS account.

## Step 1. Create EC2 Instance

Create an EC2 instance using the <a href="https://docs.aws.amazon.com/efs/latest/ug/gs-step-one-create-ec2-resources.html" target="_blank">Amazon user guide</a>. Choose **Ubuntu Server 24.04 LTS** as the operating system.

<Aside type="note">
ThingsBoard requires an instance with at least **4 GB of RAM**. We recommend an instance with **8 GB of RAM** and **2 vCPUs** for optimal performance.
</Aside>

## Step 2. Configure Security Group

Open the following ports in the inbound rules of your instance's security group:

| Port | Protocol | Description |
|---|---|---|
| 22 | TCP | SSH access |
| 80 | TCP | HTTP access |
| 443 | TCP | HTTPS access |
| 1883 | TCP | MQTT protocol |
| 8883 | TCP | MQTT over SSL |
| 7070 | TCP | Edge RPC service |
| 9090 | TCP | Remote Integration service |
| 5683–5688 | UDP | CoAP and LwM2M protocols |

## Step 3. Install ThingsBoard

Connect to your instance via SSH and follow the <DocLink product={Products.PE} path="installation/docker">Docker installation guide</DocLink> to install and configure ThingsBoard.
