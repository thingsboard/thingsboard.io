An alarm rule installs into ThingsBoard's **Alarm rules** section (Alarms → Alarm rules) and attaches to a specific entity — a device, asset, device profile, or asset profile — of your choice. It triggers alerts when the defined conditions are met by incoming telemetry.

<Steps>
1. Open **IoT Hub** from the left sidebar and click **Alarm Rules**.
2. Browse the catalog. Use the left-panel filters to narrow results by **Category** (Threshold, Connectivity, Equipment health, Environmental, Energy, Safety, Geofarcing) or **Use case**. Sort by **Most Installed** to find popular rules.
3. Click **Install** on an alarm rule card.
4. An installation dialog opens. Select the target entity for the alarm rule:
   - **Type** — choose the entity type: Device, Asset, Device profile, or Asset profile.
   - **Entity** — select the specific entity or profile to attach the alarm rule to.
5. Click **Install** to confirm. The button is inactive until an entity is selected.
6. An **Installation Successful** message appears. Click **Open Alarm Rule** to view the installed rule in ThingsBoard, where you can review its trigger conditions, clear conditions, severity levels, and schedule.
</Steps>
