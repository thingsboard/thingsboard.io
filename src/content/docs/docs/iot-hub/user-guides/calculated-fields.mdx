title: Calculated Fields
description: Step-by-step instructions for installing a calculated field from the ThingsBoard IoT Hub and attaching it to a device or asset.

import { Steps } from '@astrojs/starlight/components';

A calculated field installs into ThingsBoard's **Calculated fields** section and attaches directly to an entity — a device, asset, device profile, or asset profile — of your choice.

<Steps>
1. Open **IoT Hub** from the left sidebar and click **Calculated Fields**.
2. Browse the catalog. Use the left-panel filters to narrow results by **Type** (Simple, Script, Propagation, Related Entities Aggregation, Entity Aggregation) or **Category** (Aggregation, Custom Formula, Environmental, Geospatial, Statistical). Sort by **Most Installed** to find popular fields.
3. Click **Install** on a calculated field card.
4. An installation dialog opens. Select the target entity for the calculated field:
   - **Type** — choose the entity type: Device, Asset, Device profile, or Asset profile.
   - **Entity** — select the specific entity or profile to attach the calculated field to.
5. Click **Install** to confirm. The button is inactive until an entity is selected.
6. An **Installation Successful** message appears. Click **Open Calculated Field** to view the installed field in ThingsBoard.
</Steps>
