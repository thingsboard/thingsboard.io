A rule chain installs into ThingsBoard's **Rule chains** section. It is immediately available to reference from your root rule chain or to set as the default for a device or asset profile.

<Steps>
1. Open **IoT Hub** from the left sidebar and click **Rule Chains**.
2. Browse the catalog. Use the left-panel filters to narrow results by **Category** (Automation, Integration) or **Use case**. Sort by **Most Installed** to find popular rule chains.
3. Optionally click a rule chain card to open its detail panel. Review the description — including who the rule chain is for, what it does, node-by-node explanations, and setup instructions — before installing.
4. Click **Install** — either directly on the card or from inside the detail panel.
5. An installation dialog opens. Optionally enable **Set as profile default rule chain**:
   - **Off** (default) — the rule chain is created in your tenant with no profile assignment. The **Install** button is active immediately.
   - **On** — reveals a **Type** dropdown (Device profile or Asset profile) and a required profile field. Select the profile whose entities should route messages through this rule chain. The **Install** button becomes active once a profile is selected.
6. Click **Install** to confirm.
7. An **Installation Successful** message appears. Click **Open Rule Chain** to view the installed rule chain in the visual editor.
</Steps>
