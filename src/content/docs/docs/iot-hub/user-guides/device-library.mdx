The **Device Library** is a catalog of pre-built IoT device connectors in ThingsBoard's **IoT Hub**, contributed by verified hardware vendors. It eliminates manual configuration — a guided wizard provisions all required entities in your ThingsBoard instance automatically. 

To open it, click **IoT Hub** in the ThingsBoard left sidebar and select **Device Library**.

## Understanding the Installation Process

When you click **Connect device**, a wizard collects the configuration specific to your hardware and network setup, then automatically creates the entities your device needs. Depending on the device, this typically includes:

- <DocLink product={Products.CE} path="user-guide/devices/" target="_blank">Device Instance</DocLink> — your actual device in ThingsBoard.
- <DocLink product={Products.CE} path="user-guide/device-profiles/" target="_blank">Device Profile</DocLink> — the blueprint defining what data this device sends.
- <DocLink product={Products.CE} path="user-guide/integrations/uplink-data-converter/" target="_blank">Uplink Converter</DocLink> — the parser that translates raw device data into a readable format.
- <DocLink product={Products.CE} path="user-guide/integrations/" target="_blank">Integration</DocLink> — the connection to your network server (ChirpStack, LORIOT, MQTT, and others).
- <DocLink product={Products.CE} path="user-guide/dashboards/" target="_blank">Dashboard</DocLink> — a pre-configured visualization showing your device's telemetry.

The wizard takes 4–5 steps. No code or manual entity creation needed.

## Discovering & Filtering Devices

### Find devices in the catalog

The catalog displays all available devices with a result count. Use the controls to narrow your search:

- **Vendor** — filter by manufacturer. The panel lists the most popular vendors and includes a search box to find others.
- **Hardware Type** — filter by category: Sensor, Gateway, Tracker, Development Board, Single Board Computer, or Other.
- **Connectivity** — filter by protocol. Icons at the top of the catalog show the supported protocols at a glance: LoRa, MQTT, OPC, HTTP, Modbus, and more.

Use the **search bar** to find a device by name, and the **sort control** (Most Installed by default) to reorder results.

### Explore device details

Clicking a device card opens its detail panel. This shows everything you need to decide whether to install. The panel displays:

- **Install count** — how many times this device has been installed across the ecosystem.
- **Version** — the currently published version number and its release date.
- **Creator** — the contributing vendor or creator.
- **Hardware Type** — the device category (Sensor, Gateway, etc.).
- **Connectivity** — the supported connection protocols (LoRa, MQTT, HTTP, etc.).
- **Use Cases** — the intended application areas (for example: Smart Office, Industrial Automation).
- **Description** — what the device does and how it integrates with ThingsBoard.
- **Device Technical Documentation** — links to datasheets, product pages, and manuals provided by the creator.

Click **Connect device** to start the installation wizard.

## Connecting a Device

Click **Connect device** on a device detail panel to open the Connect wizard. The wizard collects the configuration specific to your hardware and network setup, then provisions all required entities in your ThingsBoard instance. The number of steps varies by device.

<Steps>
  1. **Connection method** *(shown only for network-server-connected devices)*

     If your device connects through a network server rather than directly to ThingsBoard, select which one you use:
     - **ChirpStack** - Self-hosted LoRaWAN networks
     - **ChirpStack (Integration)** - ChirpStack via ThingsBoard Integration
     - **The Things Stack** - Public LoRaWAN network
     - **The Things Industries** - Enterprise LoRaWAN
     - **LORIOT** - LORIOT-hosted LoRaWAN

     Devices that connect directly (MQTT, HTTP, CoAP) skip this step entirely.
  2. **Prerequisites** — Review the hardware, software, and account setup required before proceeding. The wizard links to user manuals, required gateways, or software that must be installed first.
  3. **Configuration** — Fill in the fields presented: device name and any connection-specific details such as network server credentials, gateway address, or broker settings. The exact fields depend on the device and connection method.
  4. **Provisioning** — The wizard creates all required entities in your ThingsBoard instance and shows the status of each item. Wait until all items show **Done**.
  5. **Final step** — Depending on the device, this step shows post-setup instructions to complete on your side (such as an HTTP endpoint URL to register in your network server, a docker compose command to launch a gateway, or a configuration table to apply to the physical device). Follow the instructions, then click **Open Dashboard** or **Open Device**.
</Steps>

<Aside type="tip">
  If data is not appearing after setup, check the troubleshooting notes on the final wizard step, or re-read the device state through your network server or gateway interface to force a data refresh.
</Aside>

## Managing Installed Devices

Installed devices are listed on the **Installed Items** page. 

To open it, click the **Installed Items** button at the top of the Device Library — the button shows the number of items you have installed. Each row in the list shows the device name, type, installed version, and installation date.

### Check for Updates

Click **Check for updates** in the top-right corner of the Installed Items page. ThingsBoard checks all installed items against the latest published versions and adds an **Updates** column to the table. Each device shows either **Up to date** or an available version you can install.

<Aside type="tip" title="Best practice">
  Check for updates regularly to get bug fixes and new features.
</Aside>

### Reviewing Device Instructions

Click the **review device instruction** icon on a device row to reopen the connection wizard for that device. Use this to revisit the prerequisites, configuration reference, or post-install instructions at any time.

### Opening a Device

Click the **open device** icon on a device row to navigate directly to that device in ThingsBoard.

### Removing a Device

Click the **trash** icon on a device row to remove the device.A confirmation dialog warns that removing the item will also delete the installed entity and its associated resources (Device profile, Dashboard, Integration) from your tenant.
Confirm removal by clicking **"Remove anyway"** in the dialog.
