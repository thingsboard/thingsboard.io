This guide explains how to install **Trendz Analytics** on **RHEL/CentOS 8 or 9**.

<Aside type="caution" title="Docker is recommended">
Certain Trendz features — **predictions, metric explorations, and Python calculation fields** — require the Trendz Python Executor, which runs only via Docker. Even on RHEL/CentOS, Docker is needed to fully utilize all Trendz capabilities.

Consider using the <DocLink product={Products.TRENDZ} path="trendz/install/docker">Docker (Linux, macOS)</DocLink> installation guide instead. Proceed here only if you have a specific reason to use an RPM package setup.
</Aside>

## Prerequisites

**Hardware:** At least **1 GB of free RAM**. In small and medium deployments, Trendz can be installed on the same server as ThingsBoard.

**Software:**
- <a href="https://docs.docker.com/engine/installation/" target="_blank">Docker CE</a> and <a href="https://docs.docker.com/compose/install/" target="_blank">Docker Compose</a> (required for the Python Executor)
- **ThingsBoard 4.3.0 or newer**. For older versions see <DocLink product={Products.TRENDZ} path="install/connect-thingsboard">ThingsBoard Connection</DocLink>.
- **Active Trendz Analytics add-on**. See the <DocLink product={Products.TRENDZ} path="trendz/activation/self-managed">Self-Managed Activation</DocLink> guide.

## Installation steps

### Step 1. Install Java 17 (OpenJDK)

```bash
sudo dnf install java-17-openjdk-headless
```

Set Java 17 as the default version:

```bash
sudo update-alternatives --config java
```

Verify the installation:

```bash
java -version
```

Expected output:

```text
openjdk version "17.x.xx"
OpenJDK Runtime Environment (...)
OpenJDK 64-Bit Server VM (build ...)
```

### Step 3. Configure database

Trendz uses PostgreSQL. You can install it on the same server or use a managed PostgreSQL service.

**Install PostgreSQL 16:**

```bash
sudo dnf update
```

<Tabs>
<TabItem label="RHEL/CentOS 8">

```bash
sudo dnf -y install https://download.postgresql.org/pub/repos/yum/reporpms/EL-8-x86_64/pgdg-redhat-repo-latest.noarch.rpm
```

</TabItem>
<TabItem label="RHEL/CentOS 9">

```bash
sudo dnf -y install https://download.postgresql.org/pub/repos/yum/reporpms/EL-9-x86_64/pgdg-redhat-repo-latest.noarch.rpm
```

</TabItem>
</Tabs>

```bash
sudo dnf -qy module disable postgresql
sudo dnf -y install postgresql16 postgresql16-server postgresql16-contrib
sudo /usr/pgsql-16/bin/postgresql-16-setup initdb
sudo systemctl start postgresql-16
sudo systemctl enable --now postgresql-16
```

Set a password for the `postgres` user:

```bash
sudo -u postgres psql -c "\password"
```

Enter and confirm the password when prompted.

**Configure MD5 authentication:**

Edit `pg_hba.conf`:

```bash
sudo nano /var/lib/pgsql/16/data/pg_hba.conf
```

Locate the IPv4 local connections line and replace `ident` with `md5`:

```text
# IPv4 local connections:
host    all             all             127.0.0.1/32            md5
```

Restart PostgreSQL to apply the change:

```bash
sudo systemctl restart postgresql-16.service
```

**Create the Trendz database:**

```bash
psql -U postgres -d postgres -h 127.0.0.1 -W
```

```sql
CREATE DATABASE trendz;
```

Press `Ctrl+D` to exit.

**Configure the database connection:**

```bash
sudo nano /etc/trendz/conf/trendz.conf
```

Add the following lines. Replace `PUT_YOUR_POSTGRESQL_PASSWORD_HERE` with your actual password:

```bash
# DB Configuration
export SPRING_DATASOURCE_URL=jdbc:postgresql://localhost:5432/trendz
export SPRING_DATASOURCE_USERNAME=postgres
export SPRING_DATASOURCE_PASSWORD=PUT_YOUR_POSTGRESQL_PASSWORD_HERE
```

### Step 4. Run the installation script

```bash
sudo /usr/share/trendz/bin/install/install.sh
```

### Step 5. Start Trendz service

```bash
sudo service trendz start
```

## HTTPS configuration (HAProxy)

You can configure HTTPS access using HAProxy when Trendz is hosted in the cloud with a valid DNS name.

### Trendz and ThingsBoard on the same server

If HAProxy and Let's Encrypt are already set up for ThingsBoard, open the HAProxy configuration file:

```bash
sudo nano /etc/haproxy/haproxy.cfg
```

In the `frontend https_in` section, add an ACL rule and backend reference:

```bash
acl trendz_http hdr(host) -i new-trendz-domain.com
use_backend tb-trendz if trendz_http
```

Register the Trendz backend:

```bash
backend tb-trendz
  balance leastconn
  option tcp-check
  option log-health-checks
  server tbTrendz1 127.0.0.1:8888 check inter 5s
  http-request set-header X-Forwarded-Port %[dst_port]
```

Generate an SSL certificate:

```bash
sudo certbot-certonly --domain new-trendz-domain.com --email some@email.io
```

Reload HAProxy:

```bash
sudo haproxy-refresh
```

Trendz is now available at `https://new-trendz-domain.com`.

### Fresh server setup

See the <DocLink product={Products.CE} path="TODO">HAProxy on Ubuntu</DocLink> guide to install HAProxy and generate an SSL certificate using Let's Encrypt.

### ThingsBoard and Trendz on the same domain

ThingsBoard and Trendz can share a single domain — ThingsBoard at `https://{my-domain}/` and Trendz at `https://{my-domain}/trendz/`.

In the `frontend https_in` section, add:

```bash
acl trendz_acl path_beg /trendz/ path_beg /apiTrendz/
use_backend tb-trendz if trendz_acl
```

## Troubleshooting

Trendz logs are stored in `/var/log/trendz`. Check for errors with:

```bash
cat /var/log/trendz/trendz.log | grep ERROR
```
