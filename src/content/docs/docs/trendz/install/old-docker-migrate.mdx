This guide helps you migrate from old Trendz Docker deployment files that used local folder volume bindings to the current named Docker volumes approach. It covers standalone Trendz installations.

## Why deployment files were changed

Previously, data was persisted in local folders with specific ownership requirements instead of using Docker's named volume mechanism. Named volumes are more portable and easier to manage.

## Who needs this guide

You need this guide if your `docker-compose.yml` looks like the following (or similar):

```yml
version: '3.0'
services:
  mytrendz:
    restart: always
    image: "thingsboard/trendz:1.14.0"
    ports:
      - "8888:8888"
    environment:
      TB_API_URL: http://10.0.0.101:8080
      TRENDZ_LICENSE_INSTANCE_DATA_FILE: /data/license.data
      SPRING_DATASOURCE_URL: jdbc:postgresql://postgres:5432/trendz
      SPRING_DATASOURCE_USERNAME: postgres
      SPRING_DATASOURCE_PASSWORD: postgres
      SCRIPT_ENGINE_TIMEOUT: 30000
    volumes:
      - ~/.mytrendz-data:/data
      - ~/.mytrendz-logs:/var/log/trendz
  postgres:
    restart: always
    image: "postgres:15"
    ports:
      - "5432"
    environment:
      POSTGRES_DB: trendz
      POSTGRES_PASSWORD: postgres
    volumes:
      - ~/.mytrendz-data/db:/var/lib/postgresql/data
```

## Move Postgres data to a Docker volume

Create a named Docker volume:

```bash
docker volume create --name trendz-postgres-data
```

Copy data from the local folder into the new volume:

```bash
docker run --rm -v ~/.mytrendz-data/db:/source -v trendz-postgres-data:/destination alpine sh -c "cp -rp /source/* /destination/"
```

<Aside type="caution">
The old deployment used a `postgres:15` image. The current deployment files use `postgres:16`.
After copying data, you must either keep `postgres:15` in your new `docker-compose.yml`, or upgrade the database files before switching to `postgres:16`.
See the <a href="https://www.postgresql.org/docs/16/upgrading.html" target="_blank">official PostgreSQL upgrade guide</a> for instructions.
</Aside>

## Move Trendz data to a Docker volume

Create a named Docker volume:

```bash
docker volume create --name trendz-data
```

Copy data from the local folder into the new volume:

```bash
docker run --rm -v ~/.mytrendz-data/:/source -v trendz-data:/destination alpine sh -c "cp -rp /source/* /destination/"
```

## Switch to new deployment files

Open your `docker-compose.yml` in a text editor:

```bash
nano docker-compose.yml
```

Replace the old content with the current manifest from the
<DocLink product={Products.TRENDZ} path="trendz/install/docker">Docker (Linux, macOS) installation guide</DocLink>
(or the <DocLink product={Products.TRENDZ} path="trendz/install/docker-windows">Windows guide</DocLink> if applicable).
Update the Postgres image tag if you are staying on `postgres:15`.

Once your data is in named volumes and your `docker-compose.yml` matches the current structure, proceed with the
<DocLink product={Products.TRENDZ} path="trendz/install/upgrade-instructions">Upgrade Instructions</DocLink>.
