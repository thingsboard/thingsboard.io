This guide explains how to install and run **Trendz Analytics** using Docker on **Linux or macOS**.

## Prerequisites

- <a href="https://docs.docker.com/engine/installation/" target="_blank">Docker CE</a> and <a href="https://docs.docker.com/compose/install/" target="_blank">Docker Compose</a> installed.

<Aside type="caution">
Add your user to the `docker` group so commands run without `sudo`. See <a href="https://docs.docker.com/engine/install/linux-postinstall/#manage-docker-as-a-non-root-user" target="_blank">Manage Docker as a non-root user</a>.
</Aside>

- **ThingsBoard 4.3.0 or newer**. For older versions see <DocLink product={Products.TRENDZ} path="trendz/connect-thingsboard">Connect ThingsBoard</DocLink>.
- **Active Trendz Analytics add-on**. See the <DocLink product={Products.TRENDZ} path="trendz/activation/self-managed">Self-Managed Activation</DocLink> guide.

## Installation steps

### Step 1. Docker Compose setup

Trendz can run either in the **same** Docker Compose file as ThingsBoard or in a **separate** one. For small and medium deployments, the same file is recommended.

<Tabs>
<TabItem label="Same file as ThingsBoard">

Open your existing ThingsBoard `docker-compose.yml`:

```bash
sudo nano docker-compose.yml
```

Verify that the following services and volumes are present:

| Required services | Required volumes |
|---|---|
| `trendz` | `trendz-conf` |
| `trendz-python-executor` | `trendz-data` |
| `trendz-postgres` | `trendz-python-executor-conf` |
| | `trendz-python-executor-data` |
| | `trendz-postgres-data` |

If any are missing, update your file following the <DocLink product={Products.PE} path="TODO">ThingsBoard PE Docker installation guide</DocLink>.

</TabItem>

**Docker Compose parameters:**

| Parameter | Description |
|---|---|
| `8888:8888` | Maps host port 8888 to Trendz HTTP port 8888 |
| `trendz-conf:/trendz-config-files` | Persists Trendz configuration files |
| `trendz-data:/data` | Persists Trendz application data |
| `trendz-postgres-data:/var/lib/postgresql/data` | Persists PostgreSQL data |
| `SCRIPT_ENGINE_DOCKER_PROVIDER_URL` | Address of the Python Executor service |
| `SCRIPT_ENGINE_TIMEOUT` | Python script execution timeout in milliseconds |
| `restart: always` | Auto-restarts the container on failure or system reboot |

</TabItem>
</Tabs>

### Step 2. Start Trendz service

Run the following from the directory containing your `docker-compose.yml`:

```bash
docker compose --profile trendz up -d && docker compose logs -f trendz
```

Once started, open `http://localhost:8888` in your browser — you should see the Trendz login page.

## Manage containers

Detach from the log stream without stopping the container: press `Ctrl-p` then `Ctrl-q`.

| Action | Command |
|---|---|
| View Trendz logs | `docker compose logs -f trendz` |
| Stop Trendz | `docker compose stop trendz` |
| Start Trendz | `docker compose start trendz` |

## Upgrading

<Aside type="note">
You can upgrade Trendz from any version directly to the latest — no intermediate upgrades are required.
</Aside>

<Aside type="caution">
If you are upgrading from deployment files created before Trendz 1.11, follow the <DocLink product={Products.TRENDZ} path="TODO">old Docker migration guide</DocLink> first.
</Aside>

1. Create a database backup:

```bash
docker compose exec trendz-postgres sh -c "pg_dump -U postgres trendz > /var/lib/postgresql/data/trendz_dump"
```

2. Update the `thingsboard/trendz` and `thingsboard/trendz-python-executor` image versions in `docker-compose.yml` to `{TRENDZ_VER}`.

## Troubleshooting

### DNS issues

If you see errors like:

```text
127.0.1.1:53: cannot unmarshal DNS message
```

Configure your system to use Google public DNS. See the <a href="https://developers.google.com/speed/public-dns/docs/using#linux" target="_blank">Linux</a> or <a href="https://developers.google.com/speed/public-dns/docs/using#mac_os" target="_blank">macOS</a> instructions.
