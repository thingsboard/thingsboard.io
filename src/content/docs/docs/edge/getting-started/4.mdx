In this step, you will learn how telemetry flows from Edge to your ThingsBoard account, how entities created on Edge are synchronized to the server, and how to assign server-side entities to an Edge instance.

---

## Push data from Edge to server

The **Edge Root Rule Chain** controls how Edge processes and forwards data locally. It includes a **push to cloud** node that sends telemetry and attributes to your ThingsBoard account after they are saved in the local Edge database.

To see it:

<Steps>
1. In the Edge UI, go to **Rule chains**.

2. Open the **Edge Root Rule Chain**. The **Post telemetry** and **Post attributes** messages go first to the nodes that save the data locally, and then to the **push to cloud** node, which forwards them to the server.
</Steps>

If the Edge is offline, the messages wait in a local queue and are pushed when the connection is restored.

---

## Provision entities from Edge to server

Entities created on an Edge instance, like devices, assets, and dashboards, are synchronized to your ThingsBoard account automatically.

To verify:

<Steps>
1. In your ThingsBoard account, go to **Entities → Devices**. The devices you created on Edge appear here.

2. Click the device to open its details and go to the **Relations** tab. Switch the direction from **From** to **To**. The list shows the **ManagedByEdge** relation from your Edge instance.
</Steps>

---

## Provision entities from server to Edge

You can assign entities created in your ThingsBoard account, like dashboards, device profiles, or rule chains, to an Edge instance. Once assigned, they synchronize to Edge automatically. The steps below use a dashboard as an example.

<Steps>
1. In your ThingsBoard account, go to **Dashboards** and create a new dashboard. Once configured and saved, go to **Edge Management → Instances**.

2. In the row of your Edge instance, click the **Manage dashboards** icon. The **Dashboards** page of this Edge opens.

3. Click **+**. In the **Assign Dashboard(s) To Edge** dialog, select the dashboard and click **Assign**.

4. Open the Edge UI (<a href="http://localhost:8080" target="_blank" rel="noopener noreferrer">http://localhost:8080</a>) and go to **Dashboards**. The assigned dashboard is available on Edge with the same widgets and configuration.
</Steps>
