A <a href={"/docs/user-guide/dashboards/"} target="_blank">dashboard</a> in ThingsBoard is a configurable interface for monitoring and managing devices in real time. In this step, you will create a dashboard directly in the Edge UI, add a widget to visualize telemetry, and send data to confirm it works.

---

## Create a dashboard and add a widget

<Steps>
1. In the Edge UI (<a href="http://localhost:8080" target="_blank" rel="noopener noreferrer">http://localhost:8080</a>), go to **Dashboards**, click **Add dashboard** (+), and select **Create new dashboard**.

2. Enter a title and click **Add**. The dashboard opens in edit mode.

3. Click **Add widget**, select the **Charts** bundle, and then **Time series chart**.

4. In the widget settings, select your device as the datasource and use `temperature` as the series key: this is the key that the **Check connectivity** command sends. Click **Add**.

5. Click **Save** in the top-right corner to exit edit mode.
</Steps>

---

## Send telemetry and verify

<Steps>
1. Go to **Entities → Devices** and click your device to open its details. Click **Check connectivity**.

2. Select your protocol and operating system, copy the command, and run it in your terminal. Edge has received the data when the HTTP command shows the `HTTP/1.1 200` response, the MQTT command prints `received PUBACK`, or the CoAP command prints a `2.01` response.

3. Switch back to your dashboard. Within a few seconds, the chart shows the temperature value you sent.
</Steps>
