In this step, you will create a device on Edge and activate it.

---

## Add a device on Edge

Devices created on Edge are synchronized to your ThingsBoard account automatically.

<Steps>
1. In the Edge UI (<a href="http://localhost:8080" target="_blank" rel="noopener noreferrer">http://localhost:8080</a>), go to **Entities → Devices** and click **Add device** (+).

2. Enter a name and click **Add**.
</Steps>

<Aside type="note">
To verify the synchronization, go to **Entities → Devices** in your ThingsBoard account. The new device is listed there.
</Aside>

---

## Activate the device

After you create the device, the **Device created. Let's check connectivity!** dialog opens. It contains a ready-to-use command that sends a test telemetry value (`temperature` = `25`) to Edge. The command already includes the access token of the device.

<Steps>
1. In the dialog, select your protocol (**HTTP**, **MQTT**, or **CoAP**) and operating system (**Windows**, **MacOS**, or **Linux**). If the dialog lists client tools to install first, such as `curl`, install them.

2. Copy the command and run it in your terminal. Edge has received the data when the HTTP command shows the `HTTP/1.1 200` response, the MQTT command prints `received PUBACK`, or the CoAP command prints a `2.01` response.

3. In the dialog, **State** changes from **Inactive** to **Active**, and **Latest telemetry** shows the `temperature` value. Close the dialog.

4. **Optional:** In your ThingsBoard account, go to **Entities → Devices** to confirm the device appears there.
</Steps>

<Aside type="tip">
If you closed the dialog, open the device and click **Check connectivity**.
</Aside>
