<h2>Prerequisites</h2>

Before starting, you need:

- An active ThingsBoard account with Edge functionality enabled (<DocLink product={Products.CE} path="installation" target="_blank">self-hosted</DocLink>).
- A Linux-based machine or Docker environment (minimum 1 GB RAM).
- Port `7070` open between the Edge host and your ThingsBoard instance
