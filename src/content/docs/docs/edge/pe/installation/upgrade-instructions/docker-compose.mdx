These steps upgrade an Edge cluster deployed with the Docker Compose scripts from <DocLink product={Products.EDGE_PE} path="installation/docker-compose-setup">Cluster setup with Docker Compose</DocLink>. Run all commands in the directory that holds the scripts and the `.env` file.

<Aside type="caution" title="Upgrade server first">
  Make sure your ThingsBoard Server is up to date before you upgrade Edge. An Edge newer than the server does not start.
</Aside>

<Steps>

1. Stop all services:

   ```bash
   ./docker-stop-services.sh
   ```

2. Back up the `tb-edge` folder next to the scripts. It holds the PostgreSQL data (`tb-edge/postgres`) and the logs.

3. In the `.env` file, set the Edge node image of the new release:

   <Code code={`TB_EDGE_NODE_DOCKER_NAME=${EDGE_PE_COMPOSE_NODE_NAME}\nTB_EDGE_VERSION=${EDGE_PE_COMPOSE_VERSION}`} lang="bash" title=".env" />

4. Pull the new image and upgrade the database:

   ```bash
   ./docker-upgrade-tb.sh
   ```

5. Start all services:

   ```bash
   ./docker-start-services.sh
   ```

</Steps>
