Build ThingsBoard Edge from source on **Ubuntu 22.04 / 24.04 / 26.04 LTS** or **RHEL/CentOS 9/10**.

## Required tools

### Java

ThingsBoard Edge requires Java {javaVer}.

<Tabs>
<TabItem label="Ubuntu">

<Code code={`sudo apt update && sudo apt install openjdk-${javaVer}-jdk-headless`} lang="bash" />

Configure your operating system to use OpenJDK {javaVer} by default:

```bash
sudo update-alternatives --config java
```

Verify the installation:

```bash
java -version
```

</TabItem>
<TabItem label="CentOS/RHEL">

<Code code={`sudo dnf install java-${javaVer}-openjdk-headless`} lang="bash" />

Configure your operating system to use OpenJDK {javaVer} by default:

```bash
sudo update-alternatives --config java
```

Verify the installation:

```bash
java -version
```

</TabItem>
</Tabs>

The expected output:

<Code code={`openjdk version "${javaVer}.x.xx"\nOpenJDK Runtime Environment (...)\nOpenJDK 64-Bit Server VM (build ...)`} lang="text" />

### Maven

ThingsBoard Edge requires Maven 3.6.3 or later.

<Tabs>
<TabItem label="Ubuntu">

```bash
sudo apt-get install maven
```

</TabItem>
<TabItem label="CentOS/RHEL">

```bash
sudo yum install maven
```

</TabItem>
</Tabs>

<Aside type="caution">
  Some Linux package managers set an older JVM as the system default after installing Maven. Run <code>sudo update-alternatives --config java</code> to confirm Java {javaVer} is active.
</Aside>

<Aside type="caution">
  Edge 4.4.0.x depends on the ThingsBoard license client 1.3.3, which is not available from public Maven repositories, so building the <code>release-4.4</code> branch outside ThingsBoard fails on dependency resolution. To run 4.4.0.x, use the published Docker images or packages. Building from source works again from Edge 4.4.1, which uses the public license client.
</Aside>

## Clone the source code

<Code code={`git clone -b ${EDGE_PE_BRANCH} https://github.com/thingsboard/thingsboard-edge.git\ncd thingsboard-edge`} lang="bash" />

## Build

Run the following command from the `thingsboard-edge` directory:

```bash
mvn clean install -DskipTests
```

## Build local Docker images

Make sure <a href="https://docs.docker.com/engine/install/" target="_blank">Docker</a> is installed, then run:

```bash
mvn clean install -DskipTests -Ddockerfile.skip=false
```

## Build artifacts

After a successful build, the `.deb`, `.rpm`, and Windows `.zip` packages are available at:

```bash
application/target
```

## Tips

**Clear Maven cache** if you encounter dependency resolution errors:

```bash
rm -rf ~/.m2/repository
```

**Clear Gradle cache** if building the `.deb` or `.rpm` packages fails:

```bash
rm -rf ~/.gradle/caches/
```

**Clear Node modules** if the Angular frontend build fails:

```bash
rm -rf ui-ngx/node_modules
```

**Build in parallel** with license headers and Docker images:

```bash
mvn -T 0.8C license:format clean install -DskipTests -Ddockerfile.skip=false
```
