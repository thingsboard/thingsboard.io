<Lede> This guide introduces the core ThingsBoard concepts and helps you get started with IoT data in just a few minutes. 🚀 </Lede>

By completing it, you will learn how to:
- Connect a device to ThingsBoard
- Publish telemetry data
- Visualize data on interactive dashboards
- Configure alarms and notifications
- Add a customer and securely share data with them

<Aside type="tip">
  At the end of each page, you will find an interactive checkbox to track your progress in the training materials, along with navigation buttons.
  Using the tracker is optional, but it can help you remember where you left off and mark topics for later review.

  All data is stored locally in your browser and is not sent to or stored by ThingsBoard.
</Aside>

## What Do I Need to Do to Get Started?

You will need a ThingsBoard server up and running:

- **ThingsBoard Cloud:** The fastest way to start with zero setup. Click for the <a href="https://thingsboard.cloud/" target="_blank" rel="noopener noreferrer"><strong>North America</strong></a> or <a href="https://eu.thingsboard.cloud/" target="_blank" rel="noopener noreferrer"><strong>Europe</strong></a> region.
- **Self-Managed Installation:** Alternatively, you can manually install ThingsBoard using our guides for <DocLink bold={false} product={Products.CE} path='installation/docker-windows' target="_blank"><strong>Windows (Docker)</strong></DocLink> or <DocLink bold={false} product={Products.CE} path='installation/docker' target="_blank"><strong>Linux and macOS (Docker)</strong></DocLink>.

## Log In to ThingsBoard

Open the ThingsBoard web interface.

- If you are using <strong>ThingsBoard Cloud</strong>, sign in with Google, GitHub, Apple, or your email address.
- If you are using an <strong>self-managed installation</strong> and imported the sample tenant account, sign in with the default tenant administrator credentials: <code>tenant@thingsboard.org</code> / <code>tenant</code>

After successful authentication, you will be redirected to the ThingsBoard interface.
All further steps in this guide are performed at the **Tenant** level.
