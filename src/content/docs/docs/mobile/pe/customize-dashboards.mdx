ThingsBoard lets you control how dashboards appear on the mobile app's home screen — set a cover image,
define the display order, hide specific dashboards, and rearrange the navigation bar — all from the dashboard details form.

## Dashboard image

Upload a cover image that the mobile app displays on the dashboard tile in the home screen list.

<Steps>

<ol>
  <li>Go to <strong>Monitor</strong> → <strong>Dashboards</strong> in the left main menu.</li>
  <li>In the target dashboard group, click the <strong>Dashboard details</strong> button of the dashboard you want to modify.</li>
  <li>In the dashboard details panel, click the <strong>Edit</strong> (pencil) button.</li>
  <li>Upload the desired image to the <strong>Dashboard image</strong> field.</li>
  <li>Click <strong>Apply changes</strong>.</li>
</ol>

</Steps>

## Dashboard order

Set the position of a dashboard in the mobile app home screen list. Lower numbers appear first.

<Steps>

<ol>
  <li>Go to <strong>Monitor</strong> → <strong>Dashboards</strong> in the left main menu.</li>
  <li>In the target dashboard group, click the <strong>Dashboard details</strong> button of the dashboard you want to modify.</li>
  <li>In the dashboard details panel, click the <strong>Edit</strong> (pencil) button.</li>
  <li>Enter the desired position in the <strong>Dashboard order in mobile application</strong> field.</li>
  <li>Click <strong>Apply changes</strong>.</li>
</ol>

</Steps>

## Hide dashboard in mobile app

You can hide specific dashboards so they do not appear on the mobile app home screen.

<Steps>

<ol>
  <li>Go to <strong>Monitor</strong> → <strong>Dashboards</strong> in the left main menu.</li>
  <li>In the target dashboard group, click the <strong>Dashboard details</strong> button of the dashboard you want to hide.</li>
  <li>In the dashboard details panel, click the <strong>Edit</strong> (pencil) button.</li>
  <li>Enable the <strong>Hide dashboard in mobile application</strong> checkbox.</li>
  <li>Click <strong>Apply changes</strong>.</li>
</ol>

</Steps>

## Modify navigation bar

Use the bundle's **Layout** tab in **Mobile apps** to reorder tabs and show or hide items in the navigation bar.
