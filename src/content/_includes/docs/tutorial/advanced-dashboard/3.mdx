In this lesson, you will simulate device telemetry using a rule chain, display the data in the office sensors table, and add dedicated dashboard states for each device type with visualizations tailored to the sensor.

---

## Step 3.1 Simulate Device Telemetry

Create a rule chain that continuously generates telemetry for all four devices.

<Steps>
1. Go to **Rule Chains** and click **+** to add a new rule chain named **Device Telemetry Emulators**.
2. Open the rule chain and add four **Generator** nodes — one per device.
3. Configure each generator to send **100 messages** at **600-second intervals**.
4. Connect each generator to a **Save time series** action node.
5. Save the rule chain.
</Steps>

Use the following telemetry keys for each device:

| Device | Telemetry keys |
|--------|---------------|
| SD-001 (air-sensor) | `temperature`, `humidity`, `co2` |
| EM-002 (energy-sensor) | `powerConsumption` |
| WM-003 (water-sensor) | `waterConsumption`, `batteryLevel` |
| AM-307 (air-sensor) | `temperature`, `humidity`, `co2` |

Each generator script should produce random values within realistic ranges using `Math.random()`.

<Aside type="tip">
To assign the rule chain to a device, open the device profile (e.g., `air-sensor`) and set **Default rule chain** to **Device Telemetry Emulators**.
</Aside>

## Step 3.2 Display Telemetry in the Sensors List

Update the **Office sensors list** widget to show telemetry readings.

<Steps>
1. Edit the **Office sensors list** widget in the **office** state.
2. Add columns for: `temperature`, `humidity`, `co2`, `powerConsumption`, `waterConsumption`.
3. For each column, apply a **Cell content function** to format values with units (°C, %, ppm, kWh, m³) and conditional color-coded styling based on thresholds.
4. Save the widget and the dashboard.
</Steps>

---

## Step 3.3 Configure the Time Window

<Steps>
1. Open the dashboard settings (gear icon on the toolbar).
2. Set the default time window:
   - **Current day / Current week:** aggregate by **1-hour intervals**.
   - **Current month:** aggregate by **2-hour intervals**.
   - **History mode:** use **Sum** aggregation with **1-hour** grouping.
3. Save.
</Steps>

This ensures that power and water consumption data (cumulative metrics) are displayed correctly using aggregation.

## Step 3.4 Add Device States

Create three new dashboard states for the individual device types.

<Steps>
1. Click **Manage dashboard states → +** to add the following states:
   - ID: `air_sensor`, name: `${entityName}`
   - ID: `energy_sensor`, name: `${entityName}`
   - ID: `water_sensor`, name: `${entityName}`
2. Save.
</Steps>

### Wire Navigation from the Sensors List

<Steps>
1. Edit the **Office sensors list** widget.
2. Add an **On row click** action with a custom function:
   - Inspect the device type from the row data.
   - Navigate to `air_sensor`, `energy_sensor`, or `water_sensor` based on the device profile.
3. Save the widget.
</Steps>

### Wire Navigation from the Image Map

<Steps>
1. Edit the **Image Map** widget.
2. Add a tooltip for each device showing key telemetry values.
3. Add a **Details** button in the tooltip that navigates to the appropriate device state using the same state-selection logic.
4. Save.
</Steps>

## Step 3.5 Air Sensor State (SD-001)

Use widgets from the **Indoor Environment** bundle.

### Current readings

Add three **Value card** widgets — one each for temperature, humidity, and CO2:

<Steps>
1. Click **Add widget** and select a **Value card** from the **Cards** bundle (or **Indoor Environment** bundle if available).
2. Set datasource to **Selected entity** alias.
3. Use `temperature`, `humidity`, and `co2` as the respective data keys.
4. In **Settings**, define color-coded value ranges to indicate normal, warning, and critical conditions.
5. Add an appropriate icon for each card.
</Steps>

### Historical charts

<Steps>
1. Add a **Time series chart** for `temperature` and `humidity` on the same series.
2. Add a second **Time series chart** for `co2`.
3. Set datasource to **Selected entity** for both charts.
</Steps>

---

## Step 3.6 Energy Sensor State (EM-002)

<Steps>
1. Add a **Value card** for `powerConsumption` (current reading).
2. Add a **Time series chart** for `powerConsumption` using **Sum** aggregation to show accumulated consumption.
3. Set datasource to **Selected entity** for both.
</Steps>

---

## Step 3.7 Water Sensor State (WM-003)

<Steps>
1. Add a **Value card** for `waterConsumption`.
2. Add a **Value card** for `batteryLevel` with color-coded thresholds (green / yellow / red).
3. Add a **Time series chart** for `waterConsumption` using **Sum** aggregation.
4. Set datasource to **Selected entity** for all widgets.
</Steps>
