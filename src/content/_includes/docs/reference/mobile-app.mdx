The ThingsBoard app is an open-source mobile app based on [Flutter](https://flutter.dev/) for ThingsBoard and ThingsBoard Cloud. Use it as is, or as the base of your own branded IoT mobile app with minimum coding effort.
It is available for iOS and Android and licensed under **BSD 3-Clause**.

## Features

- Browse and monitor IoT dashboards on your phone or tablet
- Manage devices and view alarms
- Customize the app with your branding (white-labeling)
- OAuth 2.0 and self-registration support
- QR code scanner for device provisioning
- Localization support

## Source code

The app is developed in the [flutter_thingsboard_app](https://github.com/thingsboard/flutter_thingsboard_app) GitHub repository.

Starting with version 2.0.0, one app serves ThingsBoard and ThingsBoard Cloud, and it continues the history of the former Professional Edition app. Releases 1.x of that app are available in the [flutter_thingsboard_pe_app](https://github.com/thingsboard/flutter_thingsboard_pe_app/releases) repository.

## Requirements

- ThingsBoard 4.4.0 or later. On an older server, the app shows a **Server update required** page and does not keep the user signed in.
- Flutter 3.47.9, the version pinned in the repository's `.fvmrc`.
- The default app ID is `org.thingsboard.app` on Android and iOS, and the default app name is **ThingsBoard App**. Set your own app ID before you publish the app; see <DocLink product={Products.MOBILE_PE} path="release" bold={false}>Build and release</DocLink>.
