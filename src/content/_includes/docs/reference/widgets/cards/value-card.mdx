The **Value card** widget displays a single value — the latest telemetry reading or attribute from an entity. It is ideal for KPIs and status metrics such as temperature, battery level, or device uptime where instant readability matters.

## Adding the widget

<Steps>
1. Open the dashboard in edit mode. Click **Add widget** in the top toolbar, or click the **Add new widget** icon in the center of an empty dashboard.
2. In the widget bundle selection dialog, find and click **Cards**.
3. Select the **Value card** widget.
4. Configure the datasource and appearance, then click **Add**.
</Steps>

## Configuration

### Datasource

Select the source of the displayed value:

- **Device** — latest telemetry or attribute from a single device.
- **Entity alias** — data from entities matched by an <DocLink product={props.product} path="user-guide/aliases" bold={false} target="_blank">entity alias</DocLink>.

Add a single data key — a <DocLink product={props.product} path="user-guide/digital-twins/time-series-data/" bold={false} target="_blank">telemetry key</DocLink> or <DocLink product={props.product} path="user-guide/digital-twins/attributes/" bold={false} target="_blank">attribute</DocLink> — whose latest value the card will display.

### Appearance

#### Layout and scaling

| Setting | Description |
|---------|-------------|
| **Layout** | Arrangement of card elements (label, icon, value). Choose from available preset layouts. |
| **Auto scale** | Automatically adjusts text size to fit the available card space. |

#### Content

| Setting | Description |
|---------|-------------|
| **Label** | Descriptive name shown on the card (e.g., `Temperature`, `Status`). |
| **Icon** | Optional icon displayed next to the label. Set icon type, size, and color. |
| **Value** | Displays the resolved data key value. Configure units, decimal places, and color. |
| **Date** | Optional timestamp of the last data update. Select a display format. |

#### Color settings

Use **Color settings** to dynamically color the **Label**, **Icon**, or **Value** based on the incoming value:

- **Constant** — fixed color regardless of value.
- **Gradient** — color transitions smoothly as the value changes across a defined range. Set start value, end value, color stops, and optionally copy the gradient from another element.

#### Card styling

| Setting | Description |
|---------|-------------|
| **Background** | Solid color or image background for the card. |
| **Show card buttons** | Toolbar buttons: **Data export** and **Fullscreen**. |
| **Card border radius** | Corner rounding in pixels. |
| **Card padding** | Spacing between card content and its border. |

### Actions

The Value card supports a <DocLink product={props.product} path="user-guide/actions/#widget-header-button" bold={false} target="_blank">Widget header button</DocLink> action — a button placed in the widget header that triggers a configured action when clicked.  
See <DocLink product={props.product} path="user-guide/actions" bold={false} target="_blank">Widget Actions</DocLink> for the full list of action types.

## Example: Device temperature with gradient color

**Goal:** Display the current temperature from a device named **Smart Device** on a Value card. The value and icon color shift from blue to green to red as the temperature rises from 20 °C to 30 °C.

### Prerequisites

Prepare a device named **Smart Device** that sends `temperature` (°C) as a telemetry key.

### Step 1. Add the widget

Open your dashboard in edit mode. Click **Add widget**, select the **Cards** bundle, then choose **Value card**.

### Step 2. Configure the datasource

Select **Device** as the datasource type, then choose your **Smart Device**. Add `temperature` as the data key.

### Step 3. Configure the appearance

In the **Appearance** section configure the following:

**Label:** `Temperature`

**Icon:**
- **Size:** 32
- **Color settings:** Gradient
  - Start value `20` &#8702; color `#048AD3`
  - Mid color `#06E10E`
  - End value `30` &#8702; color `#FF0000`

**Value:**
- **Units:** `°C`
- **Decimals:** `1`
- **Color settings:** Gradient &#8702; **Copy from:** Icon

### Step 4. Set card styling

In the **Card appearance** section:
- **Background color:** White
- **Card border radius:** `12px`

### Step 5. Save

Click **Add** to place the widget on the dashboard. Resize and reposition as needed, then click **Save** on the dashboard toolbar.

### Result

The Value card displays the device's current temperature. The value and icon color shift smoothly from blue (≤20 °C) through green to red (≥30 °C), giving an instant visual indication of the temperature range. The card updates automatically as new telemetry arrives.

## Troubleshooting

### Widget not showing data

| Cause | Solution |
|-------|----------|
| Incorrect datasource or entity alias | Verify the correct **Device** or **Entity alias** is selected in the datasource configuration. |
| Wrong data key name | Confirm the key name matches the telemetry key sent by the device. Key names are case-sensitive. |
| Device not sending data | Open **Devices → Latest telemetry** and check for recent values. If empty, verify the device transport config and token. |
| No data in the selected time window | Extend the time range or switch to **Realtime** mode to confirm data exists. |

### Value displays wrong units or decimal places

| Cause | Solution |
|-------|----------|
| Units not configured | Set the **Units** field in the **Value** appearance section. |
| Decimals not set | Set the **Decimals** field in the **Value** appearance section. |
