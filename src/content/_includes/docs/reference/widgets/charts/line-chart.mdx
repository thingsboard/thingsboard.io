The **Line chart** widget visualizes time-series telemetry as continuous lines. It supports real-time updates, multiple series, dual Y axes, data aggregation, thresholds, and comparison mode — making it ideal for tracking metrics such as temperature, pressure, voltage, or energy consumption over time.

## Adding the widget

<Steps>
1. Open the dashboard in edit mode. Click **Add widget** in the top toolbar, or click the **Add new widget** icon in the center of an empty dashboard.
2. In the widget bundle selection dialog, find and click **Charts**.
3. Select the **Line chart** widget.
4. Configure the datasource, series, and appearance, then click **Add**.
</Steps>

## Configuration

The widget configuration dialog has **Basic** and **Advanced** tabs. The **Basic** tab groups settings into: **Time window**, **Datasource**, **Series**, **Y axes**, **Thresholds**, **Appearance**, **Chart**, **X axis**, **Legend**, **Tooltip**, **Animation**, and **Card appearance**.

### Time window

Define the time interval to display — for example, *Last 24 hours* or *Current week*. Enable **data aggregation** to summarize values over specific intervals (e.g., hourly averages). See <DocLink product={props.product} path="user-guide/time-window/" bold={false} target="_blank">Time window</DocLink> for details.

### Datasource

Select the source of telemetry data:

- **Device** — data from a single device.
- **Entity alias** — data for all entities matched by an <DocLink product={props.product} path="user-guide/aliases" bold={false} target="_blank">entity alias</DocLink>. Use this to compare multiple devices on the same chart.

### Series

The widget supports two display modes: **Series** and **Comparison**.

#### Series mode

Each data key is rendered as an independent line. Add a key for each telemetry value to display (e.g., `temperature`, `humidity`). Each line updates dynamically as new telemetry arrives.

Click the **settings icon** on a series row to open the **Data key configuration** dialog. It has two tabs: **General** and **Advanced**.

**General tab:**

| Setting | Description |
|---------|-------------|
| **Key** | Telemetry or attribute key name. |
| **Label** | Legend label for this series. |
| **Units** | Unit suffix (e.g., `°C`, `%`). |
| **Decimals** | Decimal places for displayed values. |
| **Color** | Line color. |
| **Use data post-processing function** | Optional JavaScript transform applied to the raw value before display. Signature: `f(value, latestData)`. |

**Advanced tab:**

*Legend settings*

| Setting | Description |
|---------|-------------|
| **Show in legend** | Include this series in the chart legend. |
| **Hidden by default** | Series is rendered but hidden in the legend until toggled. |

*Y axis* — select which Y axis this series is plotted against.

*Line settings*

| Setting | Description |
|---------|-------------|
| **Show line** | Render this series as a line. |
| **Step line** | Draw the line as a stepped function. Choose step position: Start, Middle, or End. |
| **Smooth line** | Use curved Bezier segments instead of straight lines. |
| **Line type** | Line dash style: Solid, Dashed, or Dotted. |
| **Line width** | Stroke width in pixels. |

*Points settings*

| Setting | Description |
|---------|-------------|
| **Show points** | Render a marker at each data point. |
| **Point label** | Display the value as a label above/below the point. Configure label position and font. |
| **Point label background** | Show a background behind point labels. |
| **Point shape** | Marker shape (e.g., Empty circle, Rectangle, Diamond, etc.). |
| **Point size** | Marker diameter in pixels. |

*Fill* — shade the area beneath the line. Options: **None**, **Opacity** (solid fill with transparency), **Gradient**.

*Tooltip settings* — **Tooltip value format function** (`f(value, latestData)`): optional JavaScript function to format the value shown in the hover tooltip for this series.

*Comparison settings* — **Show historical data for comparison**: when enabled, this series also plots a comparison line from a previous time period. Configure **Comparison key label** (auto or custom) and **Comparison data color**.

#### Comparison mode

In Comparison mode, the widget overlays the **same data keys** from a previous time period on top of the current data — for example, *today* vs *yesterday*, or *this week* vs *last week*. Each period is drawn as a separate line, making it easy to spot trends or anomalies across intervals.

Switch to the **Comparison** tab in the Series section to enable this mode. Each comparison entry has:
- An **interval dropdown** — the time offset applied to the base time window for the comparison line.
- An **X axis** button — opens the **Comparison X axis settings** dialog.
- A list of **data keys** to include in the comparison (Show, Key, Label, line Color).

**Comparison interval** options:

| Option | Description |
|--------|-------------|
| **Previous interval** (default) | Shifts the time window back by one full interval length. |
| **Day ago** | Compares with the same period from 24 hours earlier. |
| **Week ago** | Compares with the same period from 7 days earlier. |
| **Month ago** | Compares with the same period from one month earlier. |
| **Year ago** | Compares with the same period from one year earlier. |
| **Custom interval** | Enter a custom offset in milliseconds. |

**Comparison X axis settings** — click the **X axis** button to configure how the comparison time axis is displayed:

| Setting | Description |
|---------|-------------|
| **Show** | Display the comparison X axis on the chart. |
| **Label** | Text label for the comparison axis. |
| **Position** | Axis position: **Top** or **Bottom**. |
| **Tick labels** | Show date/time labels on ticks. Configure font and color. |
| **Show ticks** | Render tick marks on the axis. |
| **Show line** | Render the axis baseline. |
| **Show split lines** | Render vertical grid lines for each tick. |

### Y axes

Configure one or more Y axes to control vertical scaling and labeling. Each series can be assigned to a different axis via its **Y axis** field. Click **Add Y axis** to add a row.

Each row shows: **Id**, **Show** (checkbox), **Label**, **Position**, **Min**, **Max**, **Units**, **Decimals**, and a settings gear icon.

Click the **settings icon** on an axis row to open the **Y axis settings** dialog:

| Setting | Description |
|---------|-------------|
| **Show** | Display this axis on the chart. |
| **Label** | Text label shown next to the axis. Configure font and color. |
| **Position** | **Left** or **Right**. |
| **Units** | Unit suffix for axis tick labels. |
| **Decimals** | Decimal places for tick label values. |
| **Tick labels** | Show value labels on each tick. Configure font and color. |
| **Show ticks** | Render tick marks on the axis line. |
| **Show line** | Render the axis baseline. |
| **Show split lines** | Render horizontal grid lines across the chart for each tick. |
| **Ticks interval** | Interval between ticks. **Auto** derives it from the data range. |
| **Split number** | Suggested number of tick intervals. **Auto** lets the chart decide. |

**Scale limits** — set explicit minimum and maximum bounds for the axis scale. Each bound has a **Source**:

| Source | Description |
|--------|-------------|
| **Constant** | Fixed numeric value entered directly. |
| **Key** | Value taken from a telemetry or attribute key of the current entity. |
| **Entity** | Value taken from a specified entity's attribute or telemetry key. |

### Thresholds

Add horizontal reference lines to mark safe, warning, or critical levels. Click **Add threshold** to add a row. Each row has:

| Column | Description |
|--------|-------------|
| **Source** | **Constant** — a fixed numeric value. **Entity** — value pulled from an entity attribute or telemetry key. |
| **Key / Value** | The numeric value (Constant) or the attribute/telemetry key name (Entity). |
| **Y axis** | Which Y axis the threshold is drawn against. |
| **Color** | Threshold line color. |
| **Units** | Unit suffix displayed in the threshold label. |
| **Decimals** | Decimal places for the threshold label value. |

Click the **settings icon** on a threshold row to open the **Threshold settings** dialog:

| Setting | Description |
|---------|-------------|
| **Y axis** | Y axis this threshold is drawn against. |
| **Units** | Unit suffix for the threshold label. |
| **Decimals** | Decimal places for the threshold label. |
| **Label** | Toggle to show a text label on the threshold line. Set the **position**: Start, Middle, End, Inside start, Inside start top, or Inside start bottom. Configure label font and color. |
| **Label background** | Show a filled background behind the label text. |
| **Line color** | Color of the threshold line. |
| **Line type** | Dash style: **Solid**, **Dashed**, or **Dotted**. |
| **Line width** | Stroke width in pixels. |
| **Start symbol** | Marker at the left end of the line (e.g., **None**, **Arrow**). Set the symbol size. |
| **End symbol** | Marker at the right end of the line (e.g., **None**, **Arrow**). Set the symbol size. |

### Chart

Configure interactive behavior and layout:

| Setting | Description |
|---------|-------------|
| **Data zoom** | Enable horizontal zoom for inspecting narrow time ranges. |
| **Grid** | Adjust padding inside the chart area. |
| **Stack mode** | Accumulate multiple series on the same axis (useful for totals). |

### X axis

Configure the horizontal time axis. The section has a **Show** toggle — disable it to hide the axis entirely.

| Setting | Description |
|---------|-------------|
| **Label** | Text label displayed along the axis. Configure font and color. |
| **Position** | **Bottom** or **Top**. |
| **Tick labels** | Show date/time labels on each tick. Configure date format, font, and color. |
| **Show ticks** | Render tick marks on the axis. Configure color. |
| **Show line** | Render the axis baseline. Configure color. |
| **Show split lines** | Render vertical grid lines across the chart for each tick. |

### Legend

The **Legend** section has a master toggle to show or hide the legend entirely.

| Setting | Description |
|---------|-------------|
| **Label** | Font and color for series name labels in the legend. |
| **Value** | Font and color for statistic values shown in the legend. |
| **Column title** | Font and color for the column header row (visible when Show values is enabled). |
| **Position** | Legend placement: **Top**, **Bottom**, **Left**, or **Right**. |
| **Show values** | Statistics to display per series: **Min**, **Max**, **Average**, **Total**, **Latest**. Multiple values can be enabled simultaneously. |
| **Sort datakeys in legend** | Sort series entries alphabetically in the legend. |

### Tooltip

The **Tooltip** section has a master toggle to show or hide the tooltip entirely.

| Setting | Description |
|---------|-------------|
| **Trigger** | What triggers the tooltip: **Point** — hover over a data point; **Axis** — hover anywhere on the chart shows values for all series at that timestamp. |
| **Label** | Font and color for series name labels in the tooltip. |
| **Value** | Font and color for value text in the tooltip. |
| **Date** | Toggle to show the timestamp. Select the date format (Auto or custom) and configure font and color. |
| **Show date time interval** | Display the time interval range in the tooltip header. |
| **Hide zero values** | Suppress series entries with a value of zero from the tooltip. |
| **Show total value in stack mode** | Show the summed total of all series when Stack mode is enabled. |
| **Background color** | Tooltip background fill color. |
| **Background blur** | Blur radius (px) applied to the tooltip background. |

### Animation

The **Animation** section has a master toggle. When enabled, configure how the chart animates on initial load and on data updates.

| Setting | Description |
|---------|-------------|
| **Animation threshold** | If the number of data points exceeds this value (default **2000**), animation is disabled to maintain performance. |
| **Animation duration** | Duration of the initial load animation in milliseconds (default **500 ms**). |
| **Animation easing** | Easing function for the initial animation (e.g., `cubicOut`). |
| **Animation delay** | Delay before the initial animation starts, in milliseconds. |
| **Update animation duration** | Duration of the animation when data updates arrive (default **300 ms**). |
| **Update animation easing** | Easing function for update animations (e.g., `cubicOut`). |
| **Update animation delay** | Delay before update animations start, in milliseconds. |

### Card appearance

| Setting | Description |
|---------|-------------|
| **Card title** | Title displayed in the widget header. |
| **Card icon** | Optional icon next to the title. |
| **Background** | Solid color or image background. |
| **Show card buttons** | Enable **Fullscreen** and **Data export** toolbar buttons. |
| **Card border radius** | Corner rounding. |
| **Card padding** | Spacing between content and card border. |

### Step 1. Add the widget

Open your dashboard in edit mode. Click **Add widget**, select the **Charts** bundle, then choose **Line chart**.

### Step 2. Configure the time window

In the **Time window** section set:
- **Period:** Realtime, last **12 hours**
- **Aggregation:** Average
- **Grouping interval:** 30 minutes

### Step 3. Configure the datasource

Select **Device** as the datasource type, then choose your **Thermo-hygrometer** device.

### Step 4. Add series

In the **Series** section, add two data keys:

| Key | Label | Y axis | Color | Units | Decimals |
|-----|-------|--------|-------|-------|----------|
| `temperature` | Temperature | `default` | `#F17F42` | °C | 1 |
| `humidity` | Humidity | `axis1` | `#7CB9E8` | % | 1 |

For each key, open advanced settings and enable **Smooth line**, then set **Line width** to **3**.

### Step 5. Configure Y axes

Add two Y axes:

| ID | Label | Position | Units | Decimals |
|----|-------|----------|-------|----------|
| `default` | Temperature, °C | Left | °C | 0 |
| `axis1` | Humidity, % | Right | % | 0 |

### Step 6. Set the title and legend

In the **Appearance** section, enter the **Title**:

```text
Temperature and Humidity
```

Set font size to **18 px** and weight to **600**.

In the **Legend** section, set **Position** to **Top** and enable **Min**, **Max**, **Average**.

### Step 7. Save

Click **Add** to place the widget on the dashboard. Resize and reposition as needed, then click **Save** on the dashboard toolbar.

The Line chart displays two lines updated in real time:
- An **orange line** for temperature changes over 12 hours.
- A **blue line** for humidity levels during the same period.

## Troubleshooting

### Widget not showing data

The widget shows "No data to display" or remains blank.

| Cause | Solution |
|-------|----------|
| Incorrect datasource or entity alias | Verify the correct **Device** or **Entity alias** is selected in the datasource configuration. |
| Wrong data key name | Confirm the key name matches the telemetry key sent by the device. Key names are case-sensitive. |
| Device not sending data | Open **Devices → Latest telemetry** and check for recent values. If empty, verify the device transport config and token. |
| No telemetry in the selected time window | Extend the time range or switch to **Realtime** mode to confirm data exists. |
| Rule chain misconfiguration | Check that the Rule Chain has a **Save time series** node routing device telemetry to the database. |

### Wrong or missing time window

The widget shows only partial data or stops updating.

| Cause | Solution |
|-------|----------|
| Incorrect time window type | Switch between **Realtime** and **History** as appropriate. For live monitoring, use Realtime. |
| Aggregation interval too large | Reduce the grouping interval (e.g., from 1 day to 1 hour) for finer granularity. |
| Browser time zone mismatch | Ensure the dashboard and device use the same time zone. |

### Missing or incorrect series

A series does not appear on the chart.

| Cause | Solution |
|-------|----------|
| Data key not added | Open the **Series** section and confirm each telemetry key is added as a data key row. |
| Series hidden by default | Open the data key's **Advanced** settings and disable **Hidden by default**. |
| Wrong Y axis assignment | Check that each series is assigned to an existing Y axis ID. |

### Import / Export problems

An imported widget does not display data.

| Cause | Solution |
|-------|----------|
| Missing target entity | After import, update the datasource to point to your device or entity alias. |
| Different telemetry keys | Update data key names to match your device's actual telemetry keys. |
