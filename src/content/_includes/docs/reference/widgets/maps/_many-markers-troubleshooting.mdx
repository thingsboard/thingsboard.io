**Map is slow or freezes with many markers:**
- Each marker is a separate element on the map, so loading, panning, and zooming slow down as the number of markers grows. Without clustering, every marker stays visible at every zoom level, which suits overlays with fewer markers.
- When the map becomes slow, enable **Use map markers clustering** on the marker overlay. Nearby markers are then grouped into clusters. With clustering on, **Use lazy load for adding markers** also takes effect. It is enabled by default and makes the widget draw only the markers in the visible area.
- With clustering, individual markers, with their labels and tooltips, are hidden inside cluster icons until you zoom in. To show individual markers at higher zoom levels, set **The maximum zoom level when a marker can be part of a cluster**. To get smaller clusters, lower **Maximum radius that a cluster will cover** (default: 80 px).
- If the page still freezes while markers load, also enable **Use chunks for adding markers so that the page does not freeze**. The widget then adds markers in batches, so they appear gradually instead of all at once.
- Every data update refreshes all markers in the widget. If the map does not need keys that change with every device message, like `lastActivityTime`, remove them from the overlay's additional data keys, label, and tooltip patterns. These values then no longer appear on the map.
