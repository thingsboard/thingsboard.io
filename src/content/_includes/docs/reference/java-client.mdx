The ThingsBoard Java client wraps the <DocLink product={props.product} path='reference/rest-api'>REST API</DocLink> and is auto-generated from the OpenAPI spec. Edition-specific artifacts ensure type-safe access to the right endpoints for your tenant.

## Authentication

### API key (recommended)

<Aside type="tip">
Available since ThingsBoard 4.3. See the <DocLink product={props.product} path='user-guide/security/api-keys'>API Keys</DocLink> guide.
</Aside>

<HostCode product={props.product} lang="java" code={`String url = "{BASE_URL}";
String apiKey = "YOUR_API_KEY_VALUE";
ThingsboardClient client = ThingsboardClient.builder()
    .url(url)
    .apiKey(apiKey)
    .build();

System.out.println(client.getUser());`} />

### Username and password (JWT)

<HostCode product={props.product} lang="java" code={`String url = "{BASE_URL}";
String username = "tenant@thingsboard.org";
String password = "tenant";
ThingsboardClient client = ThingsboardClient.builder()
    .url(url)
    .build();
client.login(username, password);

System.out.println(client.getUser());`} />

The JWT flow refreshes tokens automatically before they expire — no extra bookkeeping required.

## Manage devices

Create a device, save and read shared attributes, then delete:

<HostCode product={props.product} lang="java" meta="maxLines=30 collapsible" code={`String url = "{BASE_URL}";
String apiKey = "YOUR_API_KEY_VALUE";
ThingsboardClient client = ThingsboardClient.builder()
    .url(url)
    .apiKey(apiKey)
    .build();

Device newDevice = new Device();
newDevice.setName("Test Device");
newDevice.setType("default");
Device savedDevice = client.saveDevice(newDevice, null, null, null, null, null, null);
System.out.println("Saved device: " + savedDevice);

String deviceId = savedDevice.getId().getId().toString();
DeviceInfo foundDevice = client.getDeviceInfoById(deviceId);

client.saveEntityAttributesV2("DEVICE", deviceId, "SHARED_SCOPE",
    """
    {"temperature": 22.4, "humidity": 57.4}
    """);

List<AttributeData> attributes = client.getAttributesByScope(
    "DEVICE", deviceId, "SHARED_SCOPE",
    "temperature,humidity", null);
System.out.println("Found attributes:");
attributes.forEach(System.out::println);

client.deleteDevice(deviceId);`} />

<Aside type="note">
CE method signatures have fewer trailing arguments — check the JavaDoc bundled with your edition's JAR under `api-docs/` for exact parameter lists.
</Aside>

## Fetch tenant devices

Paginate through every device on the tenant:

<HostCode product={props.product} lang="java" code={`String url = "{BASE_URL}";

    .url(url)
    .apiKey(apiKey)
    .build();

int page = 0;
PageDataDevice tenantDevices;
do {
    tenantDevices = client.getTenantDevices(10, page, null, null, null, null);

## Manage attributes (read-modify-write)

Read an attribute value, change it, and write it back:

<HostCode product={props.product} lang="java" meta="maxLines=25 collapsible" code={`String url = "{BASE_URL}";
String apiKey = "YOUR_API_KEY_VALUE";
ThingsboardClient client = ThingsboardClient.builder()
    .url(url)
    .apiKey(apiKey)
    .build();

String assetId = "YOUR_ASSET_ID";

List<AttributeData> attrs = client.getAttributesByScope(
    "ASSET", assetId, "SERVER_SCOPE", "deviceCount", null);

long current = 0;
if (!attrs.isEmpty()) {
    current = ((Number) attrs.get(0).getValue()).longValue();
}

long updated = current + 1;
client.saveEntityAttributesV2("ASSET", assetId, "SERVER_SCOPE",
    "{\\"deviceCount\\": %d}".formatted(updated));`} />

## Count entities with Entity Data Query API

Count all devices, then count only the active ones:

<HostCode product={props.product} lang="java" meta="maxLines=30 collapsible" code={`String url = "{BASE_URL}";
String apiKey = "YOUR_API_KEY_VALUE";
ThingsboardClient client = ThingsboardClient.builder()
    .url(url)
    .apiKey(apiKey)
    .build();

EntityTypeFilter typeFilter = new EntityTypeFilter();
typeFilter.setEntityType(EntityType.DEVICE);

EntityCountQuery totalDevicesQuery = new EntityCountQuery();
totalDevicesQuery.setEntityFilter(typeFilter);
Long totalDevices = client.countEntitiesByQuery(totalDevicesQuery);
System.out.println("Total devices: " + totalDevices);

KeyFilter keyFilter = new KeyFilter();
keyFilter.setKey(new EntityKey().type(EntityKeyType.ATTRIBUTE).key("active"));
keyFilter.setValueType(EntityKeyValueType.BOOLEAN);

BooleanFilterPredicate predicate = new BooleanFilterPredicate();
predicate.setOperation(BooleanFilterPredicate.OperationEnum.EQUAL);
predicate.setValue(new FilterPredicateValueBoolean().defaultValue(true));
keyFilter.setPredicate(predicate);

EntityCountQuery activeDevicesQuery = new EntityCountQuery();
activeDevicesQuery.setEntityFilter(typeFilter);
activeDevicesQuery.setKeyFilters(List.of(keyFilter));
Long activeDevices = client.countEntitiesByQuery(activeDevicesQuery);
System.out.println("Active devices: " + activeDevices);`} />
