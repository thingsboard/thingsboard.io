The mobile app supports OAuth 2.0 authentication. When configured, additional sign-in buttons appear on the login screen so users can authenticate with the configured OAuth 2.0 provider.
A System or Tenant Administrator configures OAuth 2.0. For general OAuth configuration, see <a href={props.product === Products.MOBILE_PE ? '/docs/pe/user-guide/security/oauth-2-support/' : '/docs/user-guide/security/oauth-2-support/'}>OAuth 2.0 Support</a>.

## Add an OAuth 2.0 client to the bundle

The mobile app uses the OAuth 2.0 clients selected in its <a href={props.product === Products.MOBILE_PE ? '/docs/pe/user-guide/mobile-app-center/#oauth-20' : '/docs/user-guide/mobile-app-center/#oauth-20'}>bundle</a>. Create the client first and then select it in the bundle, or create it directly from the bundle.

### Option 1: Create the client, then select it in the bundle

<Steps>

1. Go to **Security** → **OAuth 2.0** in the left main menu and open the **OAuth 2.0 clients** tab.
2. Click **+ Add OAuth 2.0 client**, configure the provider, and make sure **Android** and/or **iOS** are among its allowed platforms.
3. Go to **Mobile apps** → **Bundles** and click the target bundle.
4. Open the **OAuth 2.0** tab, enable **OAuth 2.0**, and select the client in the **OAuth 2.0 clients** field.
5. Click **Next** through the remaining steps and save the bundle.

</Steps>

### Option 2: Create the client from the bundle

<Steps>

1. Go to **Mobile apps** → **Bundles** and click the target bundle.
2. Open the **OAuth 2.0** tab, enable **OAuth 2.0**, and click **Create new** next to the **OAuth 2.0 clients** field.
3. Configure the provider and click **Add**. The new client is selected in the bundle.
4. Click **Next** through the remaining steps and save the bundle.

</Steps>

## Configure the mobile app

The app takes its OAuth 2.0 settings from the bundle configuration file. No code changes are needed.

<Steps>

1. Go to **Mobile apps** → **Bundles** and click the **Configuration app** button in the row of the target bundle.
2. Click **Download file** to get `configs.json`. It contains the callback URL scheme (`thingsboardOAuth2CallbackUrlScheme`) and the application secrets the app uses for OAuth 2.0.
3. Put `configs.json` in the project root, next to `pubspec.yaml`, replacing the existing file if you downloaded one earlier.
4. Rebuild the app:

   ```bash
   flutter run --dart-define-from-file=configs.json
   ```

</Steps>

<Aside type="note">
  The domain in `thingsboardApiEndpoint` must match one of the domains configured under **Security** → **OAuth 2.0** → **Domains**.
</Aside>
