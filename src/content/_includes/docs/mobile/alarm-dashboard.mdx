Configure an alarm details dashboard to open when a user taps an alarm on the alarms screen.
The dashboard is set per alarm rule inside the device profile.

## Configure alarm details dashboard

<Steps>

1. Go to **Devices & assets** → **Device profiles** in the left main menu.
2. Click the device profile you want to modify.
3. In the device profile details panel, navigate to the **Alarm rules** tab.
4. Click the **+** (Add alarm rule) button and select **Create new alarm rule**.
5. In the **Alarm rule** dialog, add a trigger condition in the **Trigger conditions** section and select the desired dashboard in its **Mobile dashboard** field.
6. Click **Add**.

</Steps>

<Aside type="note">
  To display data for the alarm originator, configure the dashboard to use the <a href={props.product === Products.MOBILE_PE ? '/docs/pe/user-guide/aliases/#entity-from-dashboard-state' : '/docs/user-guide/aliases/#entity-from-dashboard-state'}>Entity from dashboard state</a> alias in widget datasources.
</Aside>

## Verify configuration

Open the mobile app, navigate to the alarms list, and tap an alarm whose type has the dashboard configured.

<Aside type="caution">
  The alarm dashboard configuration applies only to alarms generated after the configuration is saved, not to existing alarms.
</Aside>
