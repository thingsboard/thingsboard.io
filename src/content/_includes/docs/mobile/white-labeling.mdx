ThingsBoard <a href="/docs/pe/user-guide/white-labeling/">white-labeling</a> allows you to configure your company or product logo and color scheme.
In addition to the web interface, white-label settings also apply to the ThingsBoard PE Mobile app.
You can customize the login screen and the main app interface.

## Login screen white-labeling

As a System or Tenant Administrator, configure the login screen logo and color palette in the **Login White Labeling** form.

<Aside type="note">
By default, system-level login white-labeling is applied (configured by the System Administrator). Each tenant can override these settings by specifying a **Domain name** in the **Login White Labeling** form.
Tenant-level settings are applied based on the domain name of the server address the app connects to: the `thingsboardApiEndpoint` value in the `configs.json` file downloaded from the Mobile Center, or the server the user selects in the app or scans from a QR code.
</Aside>

<Steps>

1. Go to **White Labeling** → **Login White Labeling** through the main menu.
2. Enter your domain in the **Domain name** field for tenant-level settings.
3. Enter the base URL in the **Base URL** field (includes protocol — `http` or `https` — and port if it differs from the standard `80` or `443`).
4. Upload your logo image in the **Logo** field.
5. Specify the logo height if necessary in the **Logo height** field.
6. Select a primary color palette in the **Primary palette** field and, optionally, an accent palette and the **Dark foreground** option.
7. Click **Save** to apply changes.

</Steps>

Starting with version 1.9.1, the mobile login screen uses these settings the same way the web login page does:

| Setting | On the mobile login screen |
|---------|----------------------------|
| **Primary palette** | Background of the login screen. |
| **Accent palette** | Color of the sign-in button. The button text is light or dark, whichever contrasts better. |
| **Dark foreground** | Switches text, icons, field borders, the status bar and the default logo between dark (on) and light (off). Turn it off for a dark primary palette. |
| **Logo** and **Logo height** | Logo centered above the form at the configured height (50 px by default, 200 px at most). A logo wider than the screen is scaled down. |
| **Page background color** | Not used: on the web it fills the area around the login form, which the mobile screen doesn't have. |

<Aside type="tip">
For a dark primary palette, upload a light logo and turn off **Dark foreground**, otherwise the logo and text are hard to see.
</Aside>

Open the mobile app to verify. Your logo should appear at the top of the login form, and the background and buttons should use the selected palettes.

## Main application interface white-labeling

As a System or Tenant Administrator, configure the main app interface logo and color palette in the **White Labeling** form.

<Aside type="note">
By default, system-level white-labeling is applied (configured by the System Administrator). Each tenant can override these settings in the **White Labeling** form.
</Aside>

<Steps>

1. Go to **White Labeling** → **White Labeling** through the main menu.
2. Upload your logo image in the **Logo** field.
3. Select a primary color palette in the **Primary palette** field.
4. Click **Save** to apply changes.

</Steps>

## When changes reach the app

Starting with version 1.9.1, an app that is already running picks up white-labeling changes on its own, with no re-login or restart:

- as soon as the app returns to the foreground, for example when the user switches back to it;
- within an hour, if the app stays open on screen.

Earlier versions apply changes only after the user logs in again or restarts the app.
