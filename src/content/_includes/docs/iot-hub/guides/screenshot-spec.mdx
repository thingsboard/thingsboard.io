**Requirements.**

- **At least 1280 px wide**; 1600×900 is recommended
- **16:9** is the aspect ratio the gallery frame is built for — other ratios are letterboxed, not cropped
- **PNG** or **JPG**
- Up to **2 MB** per file
- Up to **8 screenshots** per listing
