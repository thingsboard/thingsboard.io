By choosing the type of connector, you determine the specific method of connection you will use to ensure the
interaction of your gateway with other systems or devices.

To see how the connector works, you can choose one of the following connectors:

<Tabs>
<TabItem label="MQTT">

Let's add an **MQTT connector**, which will subscribe to some data topics using the
demo broker with a built-in data generator and send data to the gateway.

##### Setup demo MQTT broker

As a demo MQTT broker, we will use docker image, that can be installed and run using the following command:

```shell
docker run -it -p 1884:1884 thingsboard/tb-gw-mqtt-broker:latest
```

After running docker image, you can see the following logs in your terminal:

<ImageGallery images={[
  {
    src: '/src/assets/images/gateway/dashboard/run-demo-mqtt-broker-image.png',
    alt: 'MQTT broker Docker logs',
  },
]} />

##### Setup connector

To create a connector with the default configuration, follow these steps:

<Steps>
1. Click on **Connectors configuration** button on the right panel.

   <ImageGallery images={[
     {
       src: '/src/assets/images/gateway/dashboard/gateway-getting-started-7-ce.png',
       alt: 'Click Connectors configuration button',
     },
   ]} />

2. Click the **+ Add connector** button.

   <ImageGallery images={[
     {
       src: '/src/assets/images/gateway/dashboard/gateway-getting-started-8-ce.png',
       alt: 'Click Add connector button',
     },
   ]} />

3. Choose **MQTT** connector type from the dropdown, fill in the **Name** field, choose **Logging level** to **INFO**, leave the **Fill configuration with default values** option **enabled**, and click the **Add** button.

   <ImageGallery images={[
     {
       src: '/src/assets/images/gateway/dashboard/gateway-getting-started-mqtt-9-ce.png',
       alt: 'Choose MQTT connector type and configure',
     },
   ]} />

4. The connector is created with the default configuration.

   <ImageGallery images={[
     {
       src: '/src/assets/images/gateway/dashboard/gateway-getting-started-mqtt-10-ce.png',
       alt: 'MQTT connector created with default configuration',
     },
   ]} />
5. Let's change default `127.0.0.1` host to `host.docker.internal`. Click on "**Connection to broker**" tab and change the host to `host.docker.internal`. Click the "**Save**" button to apply changes.

   <ImageGallery images={[
     {
       src: '/src/assets/images/gateway/dashboard/gateway-getting-started-mqtt-15-ce.png',
       alt: 'Change default host to host.docker.internal',
     },
   ]} />
</Steps>

Also, you can see the connector logs to make sure that the connector works, for this purpose, follow these steps:

<Steps>
1. In the **General** connector tab enable remove logging by turning on the **Enable remote logging** toggle. Choose **DEBUG** in the **Log level** drop-down menu. Click on the **Save** button to apply changes.

   <ImageGallery images={[
     {
       src: '/src/assets/images/gateway/dashboard/gateway-getting-started-mqtt-logs-14-ce.png',
       alt: 'Enable remote logging in connector General tab',
     },
   ]} />

2. Click on logs icon to open connector logs page.

   <ImageGallery images={[
     {
       src: '/src/assets/images/gateway/dashboard/gateway-getting-started-mqtt-11-ce.png',
       alt: 'Click logs icon',
     },
   ]} />

3. You can see the **Logs** table that consists of **Created time**, **Status** and **Message** columns.

   <ImageGallery images={[
     {
       src: '/src/assets/images/gateway/dashboard/gateway-getting-started-mqtt-logs-12-ce.png',
       alt: 'Connector logs table',
     },
   ]} />
</Steps>

For now, the gateway is ready to process data through the newly created and configured MQTT connector.

</TabItem>
