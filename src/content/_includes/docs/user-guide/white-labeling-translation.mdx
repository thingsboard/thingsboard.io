The **Custom translation** tab of <DocLink product={props.product} path="user-guide/white-labeling">White labeling</DocLink> manages the languages of the ThingsBoard interface. Use it to add a language, change built-in translations, and add your own translation keys. With your own keys, you can translate dashboard titles, widget titles, data key labels, and other text that you enter yourself.

<ShowFor product={props.product} show={[Products.PE]}>

The tab is available to the system administrator, tenant administrators, and customer users with white labeling access.

</ShowFor>
<ShowFor product={props.product} show={[Products.PAAS, Products.PAAS_EU]}>

The tab is available to tenant administrators and customer users with white labeling access.

</ShowFor>

Translations pass down the same way as other white labeling settings: see <DocLink product={props.product} path="user-guide/white-labeling#inheritance-model" target="_blank">Inheritance Model</DocLink>.

## Languages

Go to **White labeling &#8702; Custom translation**. The list shows each language with its **Localization code**, **Language**, **Country**, and **Translation progress**: the share of interface keys that have a translation in this language.

| Action | Description |
|--------|-------------|
| **Download translation** (download icon) | Downloads the complete translation of the language, built-in and custom, as a JSON file. Keys without a translation contain the English text. You can edit the file and upload it with **Upload translation file** when you add a language. |
| **Edit** (pencil icon) | Opens the translation editor. See [Edit Translations](#edit-translations). |
| **Delete** (trash icon) | Deletes the language or your custom translations for it. See [Delete Custom Translations](#delete-custom-translations). |

Use **Refresh** and **Search translation** above the list to reload it or find a language.

## Add a Language

<Steps>
1. Click **Add new language**.
2. In **Language**, start typing and select the language, for example `af_NA` **Afrikaans (Namibië)**.
3. Optionally, turn on **Upload translation file** and add a JSON file with translations: drag it to the field or click **Browse file**. You can also add translations later in the editor.
4. Click **Add**.
</Steps>

The language appears in the list. Users at your level and below, for example the customers of your tenant, can select it as their interface language right away. See [Set the Interface Language](#set-the-interface-language).

## Edit Translations

Click **Edit** (pencil icon) next to a language. The editor opens with two modes: **Basic** and **Advanced**.

### Basic Mode

The **Translation map** table has three columns:

- **Term key**: the key that identifies a text in the interface, for example `access.access-forbidden`.
- **English (United States)**: the English text. It is also used when a key has no translation in the selected language.
- The selected language, for example **Deutsch (German)**: the translated text.

Untranslated rows are highlighted in red, customized rows in green, and added keys in blue.

To filter the keys, use the buttons below the table. You can select several filters; with none selected, all keys are shown.

| Filter | Shows |
|--------|-------|
| **Translated** | Keys with a built-in or inherited translation that you have not changed. |
| **Untranslated** | Keys without a translation. Each one has an empty **Set** field. |
| **Customized** | Keys that you translated or changed. |
| **Added key** | Keys that you added. |

Use **Search translation** (magnifier icon) to find a key, and **Expand to fullscreen** to make the table wider.

**To change a translation:** click the row, edit the value, then press **Enter** or click outside the field. The change is saved right away and the key appears in the **Customized** filter. To undo the change, click **Return to default translation** (broom icon) in that row. The translation returns to the one inherited from the level above, or the key becomes untranslated if there is none.

**To add a key:**

<Steps>
1. Click **Add new key** (plus icon). An empty row appears at the top of the table.
2. Enter the **Term key**, the English text, and the text in the selected language. In the **English (United States)** translation, the row has no separate English field.
3. Press **Enter** or click outside the field. The key is saved and appears in the **Added key** filter.
</Steps>

The English text is saved to **English (United States)**. In other languages, the key appears under **Added key** with an empty **Set** field, and the interface shows the English text until you translate it.

**Delete translation** (trash icon) in the row of an added key removes the key's text in this language only. To remove the key completely, delete it in **English (United States)** and in every language where you translated it.

### Advanced Mode

The **Advanced** mode shows the custom translations made at your level as JSON: changed built-in keys and added keys. Built-in translations and translations inherited from the level above are not shown. Edit the JSON, then click **Save**, or click **Cancel** to discard the changes.

Unlike **Add new key** in Basic mode, the Advanced mode saves keys only for the language you opened. When you add new keys here, also add them with English text in the **English (United States)** translation. Otherwise, users whose language does not have the key, including users with the English interface, see the raw key, for example `{i18n:custom.greenhouse.temperature}`.

For example, add these keys to the JSON of both translations. Keep the keys that are already there: **Save** replaces all custom translations of the language at your level.

**English (United States)**:

```json
{
  "custom": {
    "greenhouse": {
      "dashboard-title": "Greenhouse monitoring",
      "temperature": "Temperature"
    }
  }
}
```

**Deutsch (German)**:

```json
{
  "custom": {
    "greenhouse": {
      "dashboard-title": "Gewächshausüberwachung",
      "temperature": "Temperatur"
    }
  }
}
```

<Aside type="caution">
  If you clear the editor and click **Save**, all your custom translations for the language are deleted. A language that you added stays in the list; to remove it, use **Delete**.
</Aside>

## Use Your Translations with i18n Keys

To show your own text in the user's language, enter an i18n key instead of plain text, for example in a dashboard title, a widget title, a data key label, or a <DocLink product={props.product} path="user-guide/white-labeling-menu" target="_blank">custom menu</DocLink> item. The key has this format:

```text
{i18n:custom.greenhouse.dashboard-title}
```

Here `i18n:` is a required prefix, and `custom.greenhouse.dashboard-title` is a term key from the translation map. ThingsBoard replaces the key with its translation in the user's language.

The example below translates a greenhouse dashboard into German. The dashboard has a **Time series chart** widget with the `temperature` and `humidity` keys of the **Greenhouse sensor** device.

<Steps>
1. Open the **Deutsch (German)** translation and add four keys in [Basic mode](#basic-mode):

   | Term key | English (United States) | Deutsch (German) |
   |----------|-------------------------|------------------|
   | `custom.greenhouse.dashboard-title` | Greenhouse monitoring | Gewächshausüberwachung |
   | `custom.greenhouse.climate-widget-title` | Climate | Klima |
   | `custom.greenhouse.temperature` | Temperature | Temperatur |
   | `custom.greenhouse.humidity` | Humidity | Luftfeuchtigkeit |

   <ImageGallery images={[
     { src: '/src/assets/images/user-guide/custom-translation/i18n-keys-1-pe.png', alt: 'New key row with the term key, English text, and German text in the German translation editor' },
     { src: '/src/assets/images/user-guide/custom-translation/i18n-keys-2-pe.png', alt: 'Four added greenhouse keys shown with the Added key filter' },
   ]} />

2. Go to **Dashboards**, click **Dashboard details** (pencil icon) in the dashboard row, then click **Toggle edit mode** (pencil icon). Set **Title** to `{i18n:custom.greenhouse.dashboard-title}` and click **Apply changes**.

   <ImageGallery images={[
     { src: '/src/assets/images/user-guide/custom-translation/i18n-keys-3-pe.png', alt: 'Dashboard Title field with an i18n key' },
   ]} />

3. Open the dashboard, enter edit mode, and click **Edit widget** on the chart:
   - In **Appearance**, set **Title** to `{i18n:custom.greenhouse.climate-widget-title}`.
   - In **Series**, set **Label** to `{i18n:custom.greenhouse.temperature}` for `temperature` and `{i18n:custom.greenhouse.humidity}` for `humidity`.

   Click **Apply**, then **Save** the dashboard.

   <ImageGallery images={[
     { src: '/src/assets/images/user-guide/custom-translation/i18n-keys-4-pe.png', alt: 'Widget Title field with an i18n key in the Appearance section' },
     { src: '/src/assets/images/user-guide/custom-translation/i18n-keys-5-pe.png', alt: 'Series labels with i18n keys for temperature and humidity' },
   ]} />

4. Set your interface language to **Deutsch (Deutschland)**, the name of the German translation in the profile (see [Set the Interface Language](#set-the-interface-language)), and open **Dashboards**. The dashboard title, the widget title, and the chart legend are shown in German. Users with the English interface see the English text.

   <ImageGallery images={[
     { src: '/src/assets/images/user-guide/custom-translation/i18n-keys-6-pe.png', alt: 'Dashboard list in German showing the translated dashboard title' },
     { src: '/src/assets/images/user-guide/custom-translation/i18n-keys-7-pe.png', alt: 'Dashboard in German with the translated widget title and legend' },
   ]} />
</Steps>

<Aside type="note">
  If the key is not in the translation map, for example because of a typo, the raw `{i18n:...}` text is shown instead.

  <ImageGallery images={[
    { src: '/src/assets/images/user-guide/custom-translation/i18n-keys-8-pe.png', alt: 'Dashboard list showing the title as a raw i18n key because of a typo in the key' },
  ]} />
</Aside>

<Aside type="tip">
  - Start your keys with `custom.` and group them by place, for example `custom.greenhouse.temperature`. This keeps them apart from built-in keys.
  - Add a translation for every language your users select.
</Aside>

## Delete Custom Translations

The **Delete** (trash icon) button is active only for languages that you added or customized at your level. Click it and confirm:

- For a language that you added, the language is removed from the list and from the users' **Language** choices.
- For other languages, all your custom translations for the language are deleted.

<Aside type="caution">
  After you confirm, the deleted translations cannot be recovered.
</Aside>

## Set the Interface Language

Each user selects their interface language in the profile:

<Steps>
1. Click your name in the bottom-left corner and select **Account**. The **Profile** tab opens.
2. Select a language in **Language**. **Auto** uses the language of the browser if ThingsBoard has a translation for it, otherwise English.
3. Click **Save**.
</Steps>

An administrator can also set the language for a user in the user's details. See <DocLink product={props.product} path="user-guide/users#user-details" target="_blank">User Details</DocLink>.
