The **Applications** tab of the **Mobile apps** page manages the mobile application configurations registered with your ThingsBoard instance. Each application entry defines the package name, platform, authentication secret, version requirements, and store links used by the <DocLink product={Products.MOBILE_PE} path="" target="_blank">ThingsBoard app</DocLink>.

## Add Application

<Steps>
1. Go to **Mobile apps** and open the **Applications** tab.
2. Click **+ Add application** in the upper-right corner.
3. Enter the **Application package** name (e.g. `com.example.myapp`) and, optionally, an **Application title**.
4. Select the **platform type**: **Android** or **iOS**.
5. An **Application Secret** is generated automatically. Copy and store it — your mobile application uses this secret to authenticate with the ThingsBoard API.
6. Set the **Status**:
   - **Draft** — application is in development; store information can be added later.
   - **Published** — application is live and available to end users.
   - **Deprecated** — application is no longer actively supported but still accessible.
   - **Suspended** — application is temporarily disabled.
7. (Optional) Specify **Min version** (minimum app version allowed to connect) and **Latest version** (current release), with optional release notes.
8. Add **store information**:
   - **Android**: **Google Play link** and **SHA256 certificate fingerprints**.
   - **iOS**: **App Store link** and **App Site Association ID**.
9. Click **Add** to save.
</Steps>

## Edit Application

All fields except **platform type** can be edited after creation.

<Steps>
1. Click the application row to open its details panel.
2. Click the **pencil** (edit) icon to enter edit mode.
3. Make the necessary changes.
4. Click **Apply changes** to save.
</Steps>

## Delete Application

<Steps>
1. Click the **trash** icon on the application row.
2. Confirm the deletion. The dialog depends on the application **Status**:
   - **Published** — the dialog asks you to type `delete application` and click **I understand consequences, delete application**. You can click **Suspend** instead to disable the application without deleting it.
   - **Draft**, **Deprecated**, or **Suspended** — a standard confirmation dialog asks whether you are sure you want to delete the application, and the deletion is confirmed with **Yes**.
</Steps>

<Aside type="caution">
  Deletion is permanent and cannot be undone.
</Aside>
