## Log In with QR Code

Once the app is installed, scan the QR code on the Home page to log in instantly. The QR code encodes a short-lived login link to your ThingsBoard instance; the app opens it, exchanges the embedded secret for a session, and connects automatically — no manual host or credential entry required.

## Configure the QR Code Widget

QR code widget settings are inherited from the system level by default. Tenant administrators can override them. Navigate to <strong>Mobile apps → QR code widget</strong> and disable the <strong>Use system settings</strong> toggle.

The settings page has two sections: **Applications** and **Appearance on Home page**.

### Applications

Choose which mobile application the QR code links to:

**Default** — links to the officially published **ThingsBoard Cloud** app ([Google Play](https://play.google.com/store/apps/details?id=org.thingsboard.cloud) / [App Store](https://apps.apple.com/us/app/thingsboard-cloud/id6499209395)). This app can switch its server host automatically when the user scans the QR code, connecting to your ThingsBoard instance without any manual configuration.

**Custom** — links to your own branded application. Select **Custom**, choose the bundle configured on the <DocLink product={props.product} path="user-guide/mobile-app-center/#bundle">Bundle</DocLink> tab, and save.

### Appearance on Home Page

| Setting | Description |
|---|---|
| **Enabled** | Show or hide the QR code widget on the Home page. |
| **Badges** | Show the App Store / Google Play badges and choose their position: **Left** or **Right**. |
| **Label** | Text displayed below the QR code (e.g. *Scan to connect or download mobile app*). |

## Add QR Code Widget to a Dashboard

You can add the **Mobile app QR code** widget to any dashboard to give customers a convenient login entry point on their mobile devices.

<Steps>
1. Go to **Monitor** → **Dashboards** in the left main menu and click the target dashboard to open it.
2. Click the **Edit mode** (pencil) button in the bottom-right corner and click **Add widget** (**Add new widget** on an empty dashboard).
3. Select the **Cards** widget bundle.
4. Choose **Mobile app QR code** from the widget list.
5. Configure the widget appearance — use system settings or override badge position and label.
6. Adjust the widget size as needed, then click **Save**.
</Steps>
