The **Login** tab of <DocLink product={props.product} path="user-guide/white-labeling">White labeling</DocLink> customizes the login page that users see when they open ThingsBoard on your custom domain. Go to **White labeling &#8702; Login**. The tab has three sections: **Domain**, **Logo & titles**, and **Appearance**.

Configure the settings in the sections below, then click **Save**. To check the result, open your domain in the browser.

<Aside type="note">
  The login page appearance also applies to the sign-up form for <DocLink product={props.product} path="user-guide/security/self-registration" target="_blank">customer self-registration</DocLink>. Self-registration itself is configured under **Security &#8702; Self registration**.
</Aside>

## Domain

| Setting | Description |
|---------|-------------|
| **Domain name** | The domain the login page is served on. Select a domain, or click **Create new** to add one. |
| **Base URL** | The public URL of the domain. Include the protocol (`http` or `https`) and the port if it is not `80` or `443`. |
| **Prohibit to use hostname from the client request headers** | ThingsBoard uses the **Base URL** instead of the hostname sent by the client. Select it for production environments; leaving it cleared may cause security issues. |

To add a domain from this tab:

<Steps>
1. Click **Create new** next to **Domain name**. The **Add domain** dialog opens.
2. Enter the **Domain name**. Make sure you own this domain.
3. Optionally, set up sign-in with an external provider: turn on **Enable OAuth 2.0 settings** and select the **OAuth 2.0 clients**, or click **Create new** to add one. Register the **Redirect URI template** (use the copy icon) as the redirect URI in the provider's settings.
4. Optionally, turn on **Propagate to Edge** to propagate the domain to ThingsBoard Edge.
5. Click **Add**.
</Steps>

The login page works on the domain only after its DNS record is set up. For DNS setup and other domain settings, see <DocLink product={props.product} path="user-guide/security/domains" target="_blank">Domains</DocLink>. For OAuth 2.0, see <DocLink product={props.product} path="user-guide/security/oauth-2-support" target="_blank">OAuth 2.0</DocLink>.

## Logo & Titles

| Setting | Description |
|---------|-------------|
| **Application title** | Title in the browser tab on the login page. |
| **Website icon** | Icon in the browser tab and bookmarks. PNG or ICO, 32×32 px recommended. |
| **Logo** | Logo on the login form. SVG or PNG, at least 96 px high, up to 200 KB. |
| **Logo height** | Logo height in pixels: 80 px by default, up to 200 px for tall logos. The logo scales proportionally and stays centered. |
| **Show platform name and version** | Shows **Platform Name** and **Platform version** (required; prefilled with ThingsBoard and the current version) at the place selected in **Platform name and version position**, for example **Bottom of the login form**. |

For **Website icon** and **Logo**, click **Browse from gallery** to pick an image from the <DocLink product={props.product} path="user-guide/image-gallery" target="_blank">image gallery</DocLink>, or **Set link** to use an image URL.

## Appearance

The preview at the top of the section shows the login form with the selected colors.

| Setting | Description |
|---------|-------------|
| **Primary palette** | The main brand color of the login page. |
| **Dark foreground** | Makes login page text and icons dark. Use it with light backgrounds. |
| **Accent palette** | Colors checkboxes, radio buttons, toggles, sliders, progress bars, and badges. |
| **Page background color** | Fills the main content area behind pages. |

To set a palette, select one from the **Primary palette** or **Accent palette** list, for example **Default**, **Red**, or **Purple**. To adjust its colors, click **Customize** (pencil icon) next to the list. Palettes work the same way as on the **General** tab; see <DocLink product={props.product} path="user-guide/white-labeling#appearance">Appearance</DocLink>.

To set the background color, click **Page background color** (palette icon) next to the field, pick a color or enter its HEX value, and click **Select**. Click **Clear** to return to the default color.

<h4>Advanced CSS</h4>

Use custom CSS for what the palettes do not cover. CSS set on this tab applies only to the login page.

<Steps>
1. Click **Add Custom CSS**.
2. Enter your CSS in the **Advanced CSS** editor.
3. Click **Save** in the dialog, then **Save** on the tab.
</Steps>

## Reset to Default

To discard all customizations of the login page, click **Reset to default** at the bottom of the **Login** tab and confirm.

<Aside type="caution">
  **Reset to default** restores all login white labeling settings to their defaults. After you confirm, your customizations are lost and cannot be recovered.
</Aside>
