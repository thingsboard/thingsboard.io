The **Custom menu** tab of <DocLink product={props.product} path="user-guide/white-labeling">White labeling</DocLink> changes the navigation sidebar for tenant users, customers, user groups, or individual users. In a custom menu, you can rename, hide, reorder, and change the icons of the default items, change the **Home** page, and add your own items that open a dashboard or a web page.

<ShowFor product={props.product} show={[Products.PE]}>

The tab is available to the system administrator, tenant administrators, and customer users with white labeling access.

The system administrator sees three default menus and can only edit their items. Adding, deleting, or renaming menus and managing their assignees are not available.

- **System default menu** is the system administrator's own sidebar.
- **Tenant default menu** and **Customer default menu** apply to the tenant and customer users of every tenant that has not assigned its own menu.
- In these menus, **Home** always opens the default home page, and custom items can link only to a URL.

</ShowFor>

## Custom Menus

Go to **White labeling &#8702; Custom menu**. The list shows each menu with its **Name**, **Scope**, and **Assignee type**. Customer users do not see the **Scope** column.

| Action | Description |
|--------|-------------|
| **Edit name** (pencil icon next to the name) | Renames the menu. |
| **Manage custom menu assignees** (people icon) | Changes who sees the menu. See [Assignees](#assignees). |
| **Manage custom menu config** (pencil icon) | Opens the menu items. See [Configure Menu Items](#configure-menu-items). |
| **Delete** (trash icon) | Deletes the menu. See [Delete a Custom Menu](#delete-a-custom-menu). |

## Add a Custom Menu

<Steps>
1. Click **Add custom menu**.
2. Enter the **Name**.
3. Select the **Scope**: **Tenant** for tenant users or **Customer** for customer users. Customer users do not see this field: their menus always have the **Customer** scope.
4. Select the **Assignee type** and, if needed, the assignees in **Assign to**. See [Assignees](#assignees).
5. Click **Add**.
</Steps>

The new menu contains all default items. Click **Manage custom menu config** (pencil icon) to change them.

### Assignees

| Assignee type | Who sees the menu |
|---------------|-------------------|
| **Not assigned** | Nobody. Use it to prepare a menu before you assign it. |
| **All tenant users** or **All customer users** | All users of the scope, unless a more specific menu applies to them. Only one menu per scope can have this type. |
| **Users list** | The users that you select. |
| **User group names** | Users in the user groups with the names that you select or type, for example **Tenant Administrators** for the **Tenant** scope or **Customer Users** for the **Customer** scope. A name matches the group of that name in every customer. |
| **Customers list** | Users of the customers that you select. Available only for the **Customer** scope. |

If you assign **All tenant users** or **All customer users** while another menu of the same scope already has this type, the **Menu conflict** dialog opens. Click **Replace** to assign your menu; the other menu becomes **Not assigned**.

To change the assignees later, click **Manage custom menu assignees** (people icon) in the menu row, change the **Assignee type** or **Assign to**, and click **Save**.

### Which Menu a User Sees

When several menus apply to a user, ThingsBoard uses the first one in this order:

1. A menu assigned to the user with **Users list** or in the **Custom menu** field of the <DocLink product={props.product} path="user-guide/users#user-details" target="_blank">user details</DocLink>.
2. A menu assigned to one of the user's groups with **User group names**. For a customer user, menus of the customer are checked first, then menus of its parent customers and of the tenant.
3. For a customer user: a menu of the customer with **All customer users**, then a menu assigned to the customer with **Customers list** or in the **Custom menu** field of the customer details, then the same for each parent customer.
4. The tenant's menu of the scope with **All tenant users** or **All customer users**.
5. The default menu of the system administrator for the scope. If there is none, the user sees the standard ThingsBoard menu.

## Configure Menu Items

Click **Manage custom menu config** (pencil icon) in the menu row. The page lists all menu items. Each row has:

- **Drag** handle to move the item up or down within its level. Subitems move only inside their section or parent item.
- A toggle that shows or hides the item. **Home** cannot be hidden.
- The icon and the name of the item. Type in the name field to rename the item.
- **Edit menu item** (pencil icon) to open all settings of the item.
- **Reset menu item back to default** (broom icon) for a changed default item, or **Delete menu item** (trash icon) for an item that you added.

Above the list:

- **Show hidden items** shows or hides the hidden items on this page. It does not change the sidebar.
- **Hide all menu items** hides all items and subitems except **Home** and turns off **Show hidden items**.
- **Reset to default menu** returns all items to their defaults and deletes the items that you added.

Changes apply only after you click **Save** at the bottom of the page. Click **Cancel** to discard them.

### Edit a Default Item

Click **Edit menu item** (pencil icon) in the row. You can change the visibility, the icon, and the name. The action of a default item cannot be changed. Click **Apply**, then **Save**.

For **Home**, you can also set **Home page type**:

- **Default**: the standard ThingsBoard home page.
- **Dashboard**: the dashboard that you select. **Hide toolbar** (on by default) opens it without the dashboard toolbar.

### Add a Custom Item

<Steps>
1. Click **Add custom menu item** at the bottom of the list.
2. Keep **Visible** on to show the item in the sidebar.
3. Click the icon next to **Menu item name** to choose an icon. On the **System** tab, pick a built-in icon. On the **Custom** tab, click **Browse from gallery** to use an image from the <DocLink product={props.product} path="user-guide/image-gallery" target="_blank">image gallery</DocLink> or **Set link** to use an image URL, then click **Set**. Enter the **Menu item name**.
4. In **Item type**, select **Link** or **Section**. For a section, see [Add a Section](#add-a-section).
5. For **Link**, select what the item opens:
   - **Dashboard**: select the **Dashboard**. **Hide toolbar** (on by default) opens it without the dashboard toolbar.
   - **URL**: enter the **URL**. The page opens inside ThingsBoard in an iframe. **Set access token** is on by default: ThingsBoard adds the current user's access token to the URL as `accessToken=<token>`. Turn it off unless the page needs the token.
6. Click **Add**, then **Save**.
</Steps>

An item added with the button at the bottom appears at the end of the list; items that you add are labeled **Custom item**. To insert an item between two rows, hover between them and click **Add custom menu item** (plus icon). Drag items to reorder them.

<Aside type="note">
  A page opens in the iframe only if its server allows embedding. Pages with the [X-Frame-Options](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/X-Frame-Options) header set to `DENY` or `SAMEORIGIN` cannot be embedded on other domains.
</Aside>

<Aside type="caution">
  With **Set access token**, the target page receives a token that allows actions in ThingsBoard on behalf of the user. Keep it on only for pages that you trust.
</Aside>

To change a custom item, click **Edit menu item** (pencil icon), change the settings, click **Apply**, then **Save**.

<Aside type="tip">
  To show the item name in the user's language, enter an i18n key as the name, for example `{i18n:custom.menu.reports}`. See <DocLink product={props.product} path="user-guide/white-labeling-translation#use-your-translations-with-i18n-keys" target="_blank">Custom translation</DocLink>.
</Aside>

### Add a Section

A section groups items under a collapsible heading.

<Steps>
1. Add a custom item with **Item type** set to **Section** and click **Add**.
2. Under the section, click **Add subitem** and add a link to a dashboard or a URL. Repeat for each subitem.
3. Click **Save**.
</Steps>

A section appears in the sidebar only if it has at least one visible subitem. Subitems are always links; sections cannot be nested. **Item type** cannot be changed after you add the item.

### Delete a Custom Item

Click **Delete menu item** (trash icon) in the row, then **Save**. Default items cannot be deleted; [hide](#configure-menu-items) them instead.

<Aside type="note" title="Hiding an item does not switch the feature off">
  A custom menu controls the sidebar only. Buttons that a feature places on the entity pages themselves, such as **Configure with AI**, are not menu items, so they stay visible whatever you hide here.<ShowFor product={props.product} show={[Products.PE]}> To remove the AI entry points, see <DocLink product={props.product} path="user-guide/ai-assistant/#turning-ai-features-off" target="_blank">Turning AI Features Off</DocLink>.</ShowFor>
</Aside>

## Delete a Custom Menu

Click **Delete** (trash icon) in the menu row and confirm with **Yes**. If the menu is assigned with **Users list** or **Customers list**, a second dialog lists the assignees; click **Delete anyway**. They then get the menu that applies next (see [Which Menu a User Sees](#which-menu-a-user-sees)).

<Aside type="caution">
  After you confirm, the menu and its items cannot be recovered.
</Aside>
