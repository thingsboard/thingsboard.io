The **Plan and billing** page lets tenant administrators manage the subscription, track usage against plan limits, set the payment method and billing details, and review invoices.

## Open Plan and Billing

To open **Plan and billing**, click your name at the bottom of the main menu, then click the **Subscription** card, which shows the current plan and its status. The card is shown only to **tenant administrators**.

If your billing details are missing, the page shows the banner *Your billing information is incomplete*. Click **Update billing information** in the banner to open the **Billing information** tab.

The page has five tabs:

| Tab | Description |
|-----|-------------|
| **<DocLink product={props.product} path='user-guide/billing-info/subscription'>Subscription</DocLink>** | Current plan, usage against plan limits, and plan changes. |
| **<DocLink product={props.product} path='user-guide/billing-info/billing-details'>Billing information</DocLink>** | Payment method and the details printed on invoices. |
| **<DocLink product={props.product} path='user-guide/billing-info/invoices'>Invoices</DocLink>** | Past invoices. |
| **<DocLink product={props.product} path='user-guide/billing-info/invoices#upcoming-invoice'>Upcoming invoice</DocLink>** | Preview of the next invoice. |
| **[Audit logs](#audit-logs)** | History of subscription changes. |

## Audit Logs

The **Audit logs** tab lists subscription changes recorded from Stripe, for example a **Subscription updated** entry for each new billing period. Each entry shows **Timestamp**, **Entity type**, **Entity name**, **User**, **Type**, and **Status**. Click <code>&#8901;&#8901;&#8901;</code> in the **Details** column to see the full record.

Use **Audit log filter** to filter entries and the time window button to change the period. Use the search icon to find an entry.
