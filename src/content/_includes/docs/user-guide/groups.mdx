**Entity Groups** let you organize <DocLink product={props.product} path='user-guide/devices' target="_blank">devices</DocLink>, <DocLink product={props.product} path='user-guide/assets' target="_blank">assets</DocLink>, <DocLink product={props.product} path='user-guide/entity-views' target="_blank">entity views</DocLink>, <DocLink product={props.product} path='user-guide/customers' target="_blank">customers</DocLink>, <DocLink product={props.product} path='user-guide/users' target="_blank">users</DocLink>, <DocLink product={props.product} path='user-guide/dashboards' target="_blank">dashboards</DocLink>, and <DocLink product={props.product} path='user-guide/edge-computing' target="_blank">edge instances</DocLink> into custom collections. Each entity can belong to multiple groups simultaneously. A special **"All"** group always contains every entity of a given type within the tenant.

Groups serve three main purposes:

- **Organization** — categorize entities by location, function, project, or any custom criteria
- **Access control** — share groups with customers and configure permissions per group
- **Bulk operations** — change ownership, move, add, or remove entities in batches

## Create Entity Group

The process is the same for all entity types. The steps below use devices as an example:

<Steps>
1. Navigate to the entity page (e.g., **Devices & assets &#8702; Devices**) and switch to the **Groups** tab.
2. Click **+ Add entity group**.
3. On the **Entity group details** step, enter the group **name** and, optionally, a **description**.
4. Click **Next: Share entity group** to open the optional second step. Enable **Share entity group** to share the new group with a Customer right away, and configure it as described in **[Share Entity Group](#share-entity-group)** below — or skip this step to create an unshared group.
5. Click **Add**.
</Steps>

The new group appears in the Groups tab. Open it to view and manage its entities.

## Group Configuration

Open a group and click the **pencil** icon to open its configuration.

| Tab | Description |
|---|---|
| **Details** | Edit the group name, description, and (device groups only) assigned firmware/software; shortcuts to open, delete, share, or make the group public, and to copy its ID |
| **Columns** | Add, remove, reorder, and style the columns shown in the group's entity table |
| **Settings** | Control the group's display behavior — search, add/delete/select entities, pagination, etc. |
| **Actions** | Define quick actions (navigate to dashboard or custom logic) for each entity in the group |
| **Permissions** | Grant a <DocLink product={props.product} path='user-guide/roles'>role</DocLink> to a user group for all entities in this group |
| **Attributes** | View, add, and delete server attributes on the entity group itself |
| **Latest telemetry** | View, add, and delete the most recent telemetry values on the entity group itself |
| **Audit logs** | View a history of actions performed on the entity group |
| **Version control** | Configure a <DocLink product={props.product} path='user-guide/version-control' target="_blank">Git repository</DocLink> to version and restore the entities inside this group |

## Manage Permissions

Grant a <DocLink product={props.product} path='user-guide/roles'>role</DocLink> to a user group for all entities in the group, from the group's **Permissions** tab (see [Group Configuration](#group-configuration)):

<Steps>
1. Click **+** to add a permission entry.
2. Select a **Role** and the **User group** it applies to.
3. Click **Add**.
</Steps>

To edit or delete an entry, use the corresponding icon next to it in the same tab.

<Aside type="tip">
Permissions supplement tenant-wide RBAC and do not override global restrictions. See <DocLink product={props.product} path='user-guide/roles'>Roles</DocLink> for details on how group roles interact with generic roles.
</Aside>

## Batch Operations

Select multiple entities within a group using checkboxes to perform bulk actions:

| Operation | Description |
|-----------|-------------|
| **Change owner** | Transfer selected entities to another Customer or back to the Tenant |
| **Add to group** | Add selected entities to another group (does not remove from current group) |
| **Move to group** | Move selected entities to another group (removes from current group) |
| **Remove from group** | Remove selected entities from the current group (does not delete the entities) |
| **Delete** | Permanently delete selected entities |

## Share Entity Group

Sharing a group grants a Customer's user group access to all entities inside it by creating a single permission entry.

<Steps>
1. In the **Groups** tab, click the **Share** icon next to the target group (or enable **Share entity group** on the second step of the **Add entity group** wizard when creating a new group).
2. Select the **Customer** (required).
3. Enable **All users** to grant access to every user of that Customer, or leave it unchecked and select a specific **user group** instead.
4. Under **Permissions**, choose **Read**, **Write**, or **Other** to assign one or more entity-group-scoped **Roles** (e.g. **Entity Group Administrator**, **Entity Group Read-only User**).
5. Click **Share** (or **Add** when sharing from the creation wizard).
</Steps>

To update or revoke access later, see [Manage Permissions](#manage-permissions).

## Make Group Public or Private

Public groups provide read-only access to anyone without sign-in. Use this only for non-sensitive data.

**Make public:**
<Steps>
1. In the **Groups** tab, click the **Make public** icon next to the target group.
2. Confirm in the dialog.
</Steps>

<Aside type="note">
Public dashboards that display device data require both the dashboard group and the related device group to be public.
</Aside>

**Make private:**
<Steps>
1. Click the **Make private** icon next to the group.
2. Confirm in the dialog. Public access is removed immediately.
</Steps>

For controlled access to specific customers, use [share entity group](#share-entity-group) or [manage permissions](#manage-permissions) instead.

## Delete a Group

Click the **trash** icon next to a group in the list (or select multiple groups with checkboxes to delete them in bulk), or open the group and click **Delete entity group** on its **Details** tab. Confirm the deletion.

<Aside type="caution">
After confirmation, the entity group and all related data become unrecoverable — deleting a group deletes all entities inside it too. To keep the entities, use the **Remove from group** [batch operation](#batch-operations) instead of deleting the group.
</Aside>
