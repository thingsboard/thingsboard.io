## Add user

1. Click **Users** in the left-hand menu, then click the **plus icon**.
2. Provide the user's email address (must be unique). First name, last name, and description are optional. Click **Add**.

<ImageGallery images={[
  { src: '/src/assets/images/docs/mqtt-broker/user-guide/ui/add-user-broker-1.png', alt: 'Navigate to Users page and click the plus icon' },
  { src: '/src/assets/images/docs/mqtt-broker/user-guide/ui/add-user-broker-2.png', alt: 'Provide email and optional fields, then click Add' },
]} />

All new users are created with the default password `sysadmin`. Users are prompted to change it on first login.

## Edit user

1. Locate the user in the **Users** table and click on the row.
2. Click the **Toggle edit mode** button.
3. Modify the first name, last name, or description, then click **Apply changes**.

  { src: '/src/assets/images/docs/mqtt-broker/user-guide/ui/edit-user-broker-1.png', alt: 'Click on the user row in the Users table' },

## Delete user

A logged-in user can delete other users but not themselves.

1. Find the user in the **Users** table and click on the row.
2. Click the **Delete user** button and confirm by selecting **Yes**.

<ImageGallery images={[
  { src: '/src/assets/images/docs/mqtt-broker/user-guide/ui/delete-user-broker-1.png', alt: 'Click Delete button in the user row' },
  { src: '/src/assets/images/docs/mqtt-broker/user-guide/ui/delete-user-broker-2.png', alt: 'Confirm deletion by clicking Yes' },
]} />

## Login as another user

Administrators can log in as other users without requiring their credentials.

1. Find the user in the **Users** table.
2. Click the **Login** button in the corresponding row.
