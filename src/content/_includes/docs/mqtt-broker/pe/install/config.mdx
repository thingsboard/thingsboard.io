    <p class="config-def-desc">Enable proxy protocol support as a global setting for all listeners. Disabled by default. If enabled, supports both v1 and v2.  Useful to get the real IP address of the client in the logs, for session details info and unauthorized clients feature</p>

    <p class="config-def-desc">The threshold (in KB) where Netty considers the channel non-writable. When the limit reached, TBMQ stops delivering data to subscriber until the channel is writable again.  Non-persistent clients lose data in this case</p>
