Any visualization saved in Trendz Analytics can be added to a ThingsBoard dashboard or embedded on an external site.
Before adding a Trendz view to a dashboard, make sure the <DocLink product={props.product} path="trendz/trendz-bundle">Advanced analytics Bundle</DocLink> is imported into ThingsBoard.

## Add a view to a ThingsBoard dashboard

### Using the Share dialog

<Steps>
1. Open the visualization in Trendz and click the **Share** button in the top-right corner.

2. Choose whether to add the view to a new or existing dashboard.

3. Select the dashboard state where the widget should appear.

4. Enable **Create alias from filter** if you want the dashboard to pass an entity alias into the view.
   With this option enabled, the view automatically filters its data when the alias value changes — for example, when a user selects a different device from a dashboard widget.

5. Click **Save**.
</Steps>

### Using a direct widget link

<Steps>
1. Open the visualization in Trendz and click **Share → Copy link**. The shareable URL is copied to your clipboard.

2. Open the target ThingsBoard dashboard in edit mode.

3. Add the **Advanced analytics View Static** widget from the **Advanced analytics Bundle**.

4. Switch to the **Advanced** tab of the widget and paste the copied URL.

5. Save the dashboard.
</Steps>

## Use the dashboard time window

By default, each Trendz view uses its own time range. You can override this so the widget follows the dashboard time window instead.
This works with both the **View Static** and **View Latest** (with aliases) widgets.

<Steps>
1. Open the dashboard in edit mode.

2. Select the Trendz widget.

3. Switch to the **Advanced** tab.

4. Enable **Use Dashboard Time Window**.
</Steps>

## Embed a view on an external site

You can embed any Trendz visualization in an external webpage using an `<iframe>`:

```html
<iframe src="http://{TRENDZ_URL}/viewMode/{VIEW_ID}?jwt={JWT_TOKEN}"></iframe>
```

| Placeholder | Description |
|-------------|-------------|
| `TRENDZ_URL` | URL of your Trendz service |
| `VIEW_ID` | ID of the saved visualization in Trendz |
| `JWT_TOKEN` | ThingsBoard JWT token used to authenticate the request |

## Troubleshooting

### Blank view (mixed content / HTTPS issue)

If ThingsBoard uses HTTPS and Trendz uses HTTP, the browser blocks requests to Trendz as mixed content. The widget appears blank and an error is visible in the browser console.

To fix this, enable HTTPS for Trendz. See the Trendz installation guide for details.
