The **Task Service** manages and runs background tasks related to data processing and calculations — scheduling,
executing, and monitoring them so that data updates and calculations happen efficiently and on time.
This service is essential for automating both real-time data handling and historical data reprocessing.

Navigate to **Tasks** in the main menu to view and control all tasks.

## Task Types

Use the **Job Type** filter on the Tasks tab to narrow the list by task type.

#### System

| Job Type | Description |
|----------|-------------|
| Execute task sequence | Runs a predefined sequence of tasks in order |
| Import configuration | Imports a Trendz configuration from a file |
| Topology discovery | Full scan — discovers all entity types, fields, and relations from ThingsBoard |
| Lite topology discovery | Incremental scan — discovers only new entity types or refreshes existing ones |
| Refresh cache | Clears and rebuilds cached data |

#### Views

| Job Type | Description |
|----------|-------------|
| Build view report | Generates a data report for a view |
| Load view filter | Loads available filter values for a view |
| Save telemetry to TB | Writes generated telemetry to ThingsBoard |
| Build alarm report | Generates an alarm report for a view |

#### Anomaly Detection

| Job Type | Description |
|----------|-------------|
| Build anomaly model | Trains an anomaly detection model on historical data |
| Find anomalies | Re-runs anomaly detection over a specific historical time range and item set |
| Anomaly autodiscovery | Scheduled — continuously scans recent data for new anomalies per item |

#### Calculation Fields

| Job Type | Description |
|----------|-------------|
| Test calculation | Validates a calculation field definition |
| Save calculation result to TB | Saves calculation field output to ThingsBoard |

#### Prediction

| Job Type | Description |
|----------|-------------|
| Train prediction model | Trains a forecasting model on historical data |
| Save prediction model result to TB | Extends forecasts using partial fit and re-prediction, then saves results to ThingsBoard |
| Prediction model accuracy | Evaluates the accuracy of a trained prediction model |

#### AI & Metric Explorer

| Job Type | Description |
|----------|-------------|
| AI Assistant response | Generates an AI Assistant answer for a view |
| Run custom prompt | Executes a custom AI prompt |
| Generate view summary | Creates an AI-generated summary for a view |
| Find metric | Uses AI to generate metric definitions in the Metric Explorer |
| Generate metric calculation | Uses AI to write the Python implementation of a metric definition |

## Tasks Tab

Click any task in the list to view its execution details:

| Field | Description |
|-------|-------------|
| Time Started | When the task execution began |
| Duration | How long the task has been running |
| Time Finished | When the task completed or is expected to finish |
| Status | Current state — see [Task Statuses](#task-statuses) below |

From the task detail panel you can also:

- **Execute Task** — trigger the task to run immediately.
- **Stop Task** — stop a running task.
- **Go to entity** — navigate to the ThingsBoard entity associated with the task.

### Task Statuses

| Status | Meaning |
|--------|---------|
| Created | Scheduled but not yet started |
| Running | Currently executing |
| Finished | Completed successfully |
| Failed | Terminated with an error |
| Canceled | Stopped manually before completion |
| Lost | Execution was interrupted unexpectedly |
| None | No status available |

### Bulk Actions

- **Stop All Tasks** — immediately stops all currently running task executions. The tasks themselves and their configurations are not affected.
- **Clear All Executions** — removes the execution history for all tasks. By default, execution records are retained for 3 days. This action only clears history and does not affect future task execution.

## Executions Tab

The **Executions** tab provides a detailed log of all task executions. Filter by status — **All**, **Created**, **Running**, or **Failed** — to quickly find relevant entries.

For each execution the tab shows: **Time Started**, **Duration**, **Time Finished**, and **Status**.
