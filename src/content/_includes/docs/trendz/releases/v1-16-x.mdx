## v1.16.0 (Sep 30, 2026)

**New features:**

- Added prediction model creation wizard.
- Added prediction model result page.
- Added Time to Threshold prediction intent.
- Added Period Total prediction intent.
- Added Hit Target prediction intent.
- Added ability to create alarms for Time to Threshold and Hit Target intents.
- Added vibration analysis feature.
- Added the Cumulative data transform for view fields, alongside Delta.

**Improvements:**

- Migrated Trendz to Java 25 and Angular 20.
- Significantly improved performance of prediction model training and refresh.
- Improved prediction model accuracy calculation logic.
- Improved <DocLink product={Products.TRENDZ} path="date-picker">date pickers</DocLink> and added the ability to specify future options.

**Bug fixes:**

- Fixed Trendz running against a highly available PostgreSQL cluster.
- Fixed inactive telemetry keys missing from the Metric Explorer.
- Fixed anomaly models clearing their scanned items after a rebuild.
