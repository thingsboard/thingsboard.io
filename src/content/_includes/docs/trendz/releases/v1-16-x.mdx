## v1.16.1 (Nov 2, 2026)

**Improvements:**

- Added ThingsBoard API key authentication for the Trendz REST API.
- Added a setting to disable zoom in views.
- Improved AI assistant model configuration with support for any model name.
- Improved vibration analysis usability.
- Improved import/export performance.
- Reduced Python executor Docker image size.

**Bug fixes:**

- Fixed security issues.
- Fixed anomaly models getting stuck in the Queued status.
- Fixed duplicated manual fields after topology discovery.
- Fixed a database deadlock issue during business entity scan.
- Fixed topology discovery failing on telemetry keys with an empty name.
- Fixed copying prediction models with rules failing on the alarm type uniqueness check.
