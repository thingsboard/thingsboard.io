**Vibration Models** in the left menu is where you create, open, and manage vibration models. One model reads the
vibration samples of the machines in one device or asset profile, and turns every sample it scans into results:
metrics, spectra, an ISO zone, and the most likely shaft and bearing problems.

## Layout

You work with two screens. The **Vibration Models list** shows every model of the tenant. Click a model to see its
details beside the table, then open it.

<DocLink product={props.product} path='vibration/getting-started'>Getting Started</DocLink>.

Each row in the table shows:

| Column | Description |
|--------|-------------|
| **Name** | Model name and the profile it reads |
| **Created** | When the model was created |
| **Telemetry key** | The key that holds the waveform, with the axis count and the points per sample |
| **Alarms** | Open alarms raised by this model's rules |
| **Monitoring** | Whether scheduled scanning is enabled |
| **Saved as telemetry** | Whether each scan writes the selected metrics back to ThingsBoard |
| **Items** | Machines scanned, out of the machines the profile holds |

### Model detail panel

Click any model row to describe it beside the table, without opening it:

<ImageGallery images={[
  {

| Field | Description |
|-------|-------------|
| **Alarms raised** | How many alarms the model has raised |
| **Last scan** | How long ago the model last scanned new samples |
| **Items with alarms** | How many machines have at least one alarm |
| **Items** | Machines the model covers, out of all machines in the profile, for example **5 / 5** |
| **Monitoring** | **On** when the model scans new samples on a schedule, **Off** when it scans only when you start a scan |
| **Saved as telemetry** | **On** when the model writes its metrics back to ThingsBoard as telemetry, **Off** when it does not |
| **Profile** | The device or asset profile the model reads |
| **Vibration telemetry** | The telemetry key that holds the waveform, and its unit, for example **vibration (g)** |
| **Points/s** | The sample rate of the sensor: how many points it records per second, for example **25.6 kHz** is 25 600 points per second. Set on the model, or read per machine from an attribute |
| **Items scanned** | The period the stored results cover, from the earliest scanned sample to the latest |
| **Avg samples / item** | How many samples the model has stored per machine, on average |
| **Axes** | How many axes each sample holds, for example 1 for a single-axis sensor |

## Tabs

The model page has five tabs. Click a tab name to switch to it.

- **Overview**, **Monitoring**, and **Analyzer** show the results of the model's scans: the verdict for each
  machine, how it changes over time, and one sample in detail.
- **Properties** shows how the model is set up, and lets you change it.
- **Tasks** shows the scans the model has run.

Each tab is described in detail on its own page, linked below.

and how long it took.

### Scan latest data

Click **Scan latest data** to bring the model up to date by hand. It is the same scan that scheduled scanning runs.

- Only new samples are scanned: for each machine, from its newest stored sample up to now.
- It covers the machines the model has already scanned. To add new machines, use [Scan more data](#scan-more-data).

### Duplicate

Create a copy of the model, for example to try another setting without touching the model that is running.

1. Click **More actions** (1) and choose **Duplicate** (2).
2. The copy opens in a new browser tab.

The copy has the same settings and alarm rules. It starts with no results and runs its own scan, and its
monitoring is off.

### Scan more data

Scan a period of history, for example to fill a gap, to rescan after the data was fixed, or to add machines.

1. Click **More actions** (1) and choose **Scan more data** (2).
2. Pick the period: **All history**, **Last 180 days**, **Last 90 days**, **Last 30 days**, or a custom range.
3. Pick the machines under **Scope**:

   | Scope | Scans |
   |-------|-------|
   | **All in profile** | Every machine of the profile, including ones not scanned yet |
   | **Scanned items** | The machines the model already holds |
   | **Specific** | Only the machines you pick |

4. Click **Scan**. Results already stored for that period are replaced.
