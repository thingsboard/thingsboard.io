In this guide you create your first vibration model. It checks the health of the machines you pick from one device
profile, using the vibration samples your sensors already send to ThingsBoard. Setup takes a few minutes and needs no code.

By the end of this guide, you will have this model:

**Before you start:** you need devices of one profile in ThingsBoard whose sensors send raw vibration samples in the
Trendz format. If they do not yet, start with [Prepare your data](#prepare-your-data).

## Prepare your data

### Install the sensor

Use a vibration sensor that records the raw signal, not only a summary value like RMS. Many wireless IIoT
vibration sensors and vibration gateways can do this when set to send the raw time waveform. A sensor that
reports only RMS, peak, or temperature cannot be analyzed. Mount it on the bearing housing and set it to record a
**sample** at a fixed interval, for example once an hour: about 3 seconds of acceleration readings, sent to
ThingsBoard as one telemetry value.

Pick a sample rate of at least twice the highest frequency you want to analyze. Bearing faults and envelope
analysis need high frequencies, so choose a rate in the kHz range. The 25,600 points per second used in
[Step 4](#step-4-set-the-sample-rate) covers frequencies up to 12.8 kHz. For a sensor with a ready-made
ThingsBoard integration, see the
[**NCD vibration and temperature sensor**](/iot-hub/devices/ncd-vibration-temperature-sensor/) in IoT Hub.

How sensors and samples work is described in
<DocLink product={props.product} path='vibration/basics#sensors-and-samples'>Vibration Analysis Basics</DocLink>. If
you need help with a sensor or gateway setup, <a href="/contact-us/">contact us</a>.

### Trendz Vibration Data Input Formats

Save each sample as **one string telemetry value**: all readings of the sample in recording order, separated by
spaces.

```plaintext title="one sample from a single-axis sensor"
0.012 -0.034 0.051 0.007 -0.019 0.023 0.041 -0.008 …
```

A sensor with several axes sends them in the same value: first all readings of axis 1, then axis 2, and so on,
with a comma between the axes. Every axis must hold the same number of readings.

```plaintext title="one sample from a triaxial sensor"
0.12 -0.03 0.45 0.11 …, 0.02 -0.07 0.30 0.01 …, 0.20 0.04 -0.12 0.09 …
```

If the sensor sends another shape, such as a JSON array or one reading per message, convert it in the device's
<DocLink product={Products.PE} path='user-guide/rule-engine'>rule chain</DocLink> before it is saved, for example with a
<DocLink product={Products.PE} path='reference/rule-engine/nodes/transformation/script'>script transformation node</DocLink>
that joins the array into one space-separated string.

### Step 3. Choose the signal

Tell Trendz where the samples are and what they measure:

1. Pick the **Signal unit**: the unit the sensor records acceleration in, **g**, **mm/s²**, or **in/s²**. Every
   metric is computed from the raw values, so pick the unit the sensor really writes. How acceleration relates to
   velocity and displacement is described in
   <DocLink product={props.product} path='vibration/basics#acceleration-velocity-and-displacement'>Vibration Analysis Basics</DocLink>.
2. Pick the **Telemetry key** that holds the samples. The list shows the telemetry keys of the profile. The key must
   hold samples in the [Trendz format](#trendz-vibration-data-input-formats).
3. Check the **Data readiness** panel on the right (1). **Ready** means Trendz found samples it can analyze. The
   panel also shows how many axes and points per sample it read.

Machine details turn readings into verdicts.

**ISO class** grades velocity RMS into the ISO zones A to D. **Manual** applies one class to every machine,
**From attribute** reads it per machine. The zones and classes are described in
<DocLink product={props.product} path='vibration/basics#iso-10816-1-severity-zones'>Vibration Analysis Basics</DocLink>.

### Step 6. Add bearings (optional)

<Aside type="tip">
If you do not know your bearings, click **Create model** without adding one. You can add bearings later on the
<DocLink product={props.product} path='vibration/interface/properties-tab#bearings'>Properties tab</DocLink>.
</Aside>

Bearings let Trendz mark their fault frequencies, BPFO, BPFI, BSF, and FTF, on the spectra and name the defect.
What the four frequencies mean is explained in
<DocLink product={props.product} path='vibration/basics#bearing-fault-frequencies-bpfo-bpfi-bsf-ftf-and-envelope-analysis'>Vibration Analysis Basics</DocLink>.
The fault frequencies turn into hertz only with a shaft speed, so set it in Step 5.

**Add a bearing.**

1. Click **Add bearing**.
2. A new row, such as **Bearing 1**, appears in the list and opens on the right. A warning icon stays on it until
   the bearing is complete: hover it to read **Complete this bearing or remove it**.
3. Enter the bearing as described below.

  {
    src: '/src/assets/images/trendz/vibration/getting-started-wizard-bearing-empty.webp',

  {
    src: '/src/assets/images/trendz/vibration/getting-started-wizard-bearing-warning.webp',
    alt: 'New bearing row Bearing 1 highlighted with its warning icon and the tooltip Complete this bearing or remove it',
    caption: 'The warning stays until the bearing is complete.',
  },
  {
    src: '/src/assets/images/trendz/vibration/getting-started-wizard-bearing-new.webp',
    alt: 'New bearing row highlighted in the list, and its Source select set to Manual',

**Enter the bearing.** It applies to every machine of the model:

1. Type a name, for example **Drive end — SKF 6205**.
2. Under **Defined by**, choose **Fault frequencies** or **Geometry**, and fill in the fields. Both are described
   in the table below.
3. Check **Resolved at … RPM** below the fields: it shows each fault frequency in hertz at the shaft speed.

| Defined by | What you enter |
|------------|----------------|
| **Fault frequencies** | **BPFO**, **BPFI**, **BSF**, and **FTF** as orders, multiples of the shaft speed. They are usually in the bearing maker's catalog |
| **Geometry** | **Rolling elements**, **Element ⌀** and **Pitch ⌀** in mm, and **Contact angle** in degrees. Trendz calculates the orders from them |

### Step 8. Keep it up to date

A new model scans once. To scan new samples as they arrive, click **Configure** on the
<DocLink product={props.product} path='vibration/interface/overview-tab#monitoring-card'>Monitoring card</DocLink> of the **Overview** tab:

1. Switch **Scheduled scanning** on and choose how often, for example every 6 hours.
2. Click **Save changes**.
