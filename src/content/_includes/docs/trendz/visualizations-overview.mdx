Trendz provides a set of built-in visualization types for analyzing IoT datasets. Each type is optimized for a different analytical task — from spotting trends over time to comparing distributions across entities.

## Available view types

| View type | Best for |
|-----------|----------|
| <DocLink product={props.product} path="visualizations-tables">Table</DocLink> | Showing raw or aggregated values in a structured grid; exporting data |
| <DocLink product={props.product} path="visualizations-line">Line Chart</DocLink> | Tracking how a metric changes over time; comparing multiple series |
| <DocLink product={props.product} path="visualizations-bar">Bar Chart</DocLink> | Comparing totals or distributions across entities or time intervals |
| <DocLink product={props.product} path="visualizations-pie">Pie Chart</DocLink> | Showing proportional share of a total across a small number of categories |
| <DocLink product={props.product} path="visualizations-scatter">Scatter Plot</DocLink> | Revealing correlations or clusters between two numeric fields |
| <DocLink product={props.product} path="visualizations-heatmap">Heat Map</DocLink> | Spotting patterns across two dimensions using color intensity |
| <DocLink product={props.product} path="visualizations-calendar">Calendar</DocLink> | Visualizing daily values across weeks and months in a calendar layout |
| <DocLink product={props.product} path="visualizations-card">Card</DocLink> | Displaying a single key metric with an optional comparison value |
| <DocLink product={props.product} path="visualizations-card-with-line">Card with Line Chart</DocLink> | Showing a key metric alongside its trend sparkline with period-over-period comparison |
| <DocLink product={props.product} path="visualizations-ai-card">AI Card</DocLink> | Cumulative telemetry with forecasting and an AI-generated summary |

## Create your first view

<Steps>
1. Open the Trendz home page and click **Create View**.

2. Select **Line** as the chart type.

3. From the left panel, drag a **Date** field into the **X axis** slot.

4. Drag any telemetry field into the **Y axis** slot and click **Build Report**.

   At this point, the chart shows the average measurement across all entities in ThingsBoard.

5. Add **Entity Name** to the **Series** slot to split the chart into one line per entity.
</Steps>
