**Period Total** answers the question a budget asks: how much by the end of the period? The model forecasts the
metric for the rest of the period, adds what has been measured so far, and reports the total, peak, average, or
minimum for the whole period next to the same figure for the previous period.

## When to use it

Use Period Total when you need one number for a whole period, such as a month, rather than the curve.

| Use case | What Period Total predicts | What you do with it |
|----------|----------------------------|---------------------|
| **Check the energy bill** | Total energy of each site for this month | See the bill before the invoice arrives, and compare it with last month |
| **Estimate fuel spend** | Total fuel each vehicle of a fleet will use this month | See which vehicles will go over the monthly fuel budget |
| **Report water use** | Total water use of each building for this quarter | Report the change against the previous quarter before the quarter ends |

Period Total raises no alarms. To be warned when a metric crosses a limit, use
<DocLink product={props.product} path="prediction/intents/time-to-threshold">Time to Threshold</DocLink>. To track
a goal with a risk score and alarms, use
<DocLink product={props.product} path="prediction/intents/hit-target">Hit Target</DocLink>. For the plain curve
over a horizon, use <DocLink product={props.product} path="prediction/intents/forecast">Forecast</DocLink>.

## How to create a model

### Step 1: Open the wizard

Two entry points are available on the Prediction models page:

- **Create model** — button in the top-right corner, visible on both tabs.
- **+ Create** — inline button on any profile row of the Profile coverage table. Opens the wizard with that
  profile pre-selected.

### Step 3: Configure the period

The **Configure forecast** step sets the period the model totals, how much history it learns from, and how fine
the result is.

**Prediction period** — choose the calendar period to total. Pick **Day**, **Week**, **Month**, or **Quarter**,
or **Custom** and type the number of units. The info block splits the period into the part already measured and
the part still to be forecast:

## Period Total result page

The Result tab shows the period of one item at a time. Pick the item in the table below the chart; the cards on
the right show the monitoring settings and the data status of the model.

### Period total card

The card on the left shows the period of the selected item:

<ImageGallery images={[
  {
    src: '/src/assets/images/trendz/prediction/period-card.webp',
    alt: 'Result tab of a Period Total model with the Period total card highlighted: the Sum tab, the predicted total for September, the actual and predicted parts, and the change against August',
    caption: 'The predicted September total, split into measured and forecast, against August.',
  },
]} />

| Part | What it shows |
|------|---------------|
| **Sum**, **Maximum**, **Average**, **Minimum** | Tabs that switch the aggregation. All four come from the same forecast |
| **Predicted total** | The value for the whole period, measured part plus forecast |
| **Actual** | The measured part, from the start of the period to the latest reading |
| **Predicted** | The forecast part, from the latest reading to the end of the period |
| **vs Previous** | The same value for the previous period, and the change in percent |

A rise shows as good news in green. For a metric where less is better, such as energy, turn on **Reverse
comparison colors** on the Properties tab.

]} />

### Period chart

The chart shows the selected item over the whole period: **Actual**, **Forecast**, and **Previous period**, with a
**Now** marker at the latest reading.

<ImageGallery images={[
  {
    src: '/src/assets/images/trendz/prediction/period-chart.webp',
    alt: 'Result tab of a Period Total model with the chart highlighted: the running total for September, its forecast to the end of the month, and August as a dashed line',
    caption: 'The running total for September, against August.',

Two buttons above the chart switch what it draws. They open as set in
[Result page settings](#result-page-settings); click one to switch it.

| Button | On | Off |
|--------|----|-----|
| **Cumulative** | Each point adds up everything from the start of the period, so the line climbs toward the period total | Each point shows only its own hour or day, for example the energy used from 14:00 to 15:00 |
| **Compare** | The previous period is drawn over the current one | Only the current period |

### Items table

The table under the chart lists every item in the model's scope. Select a row to switch the card and the chart to
that item.

<ImageGallery images={[
  {
    src: '/src/assets/images/trendz/prediction/period-items.webp',
    alt: 'Result tab of a Period Total model with the items table highlighted: predicted totals, actual and predicted parts, the previous month, and the change per site',
    caption: 'Every site is heading below its August consumption.',
  },
]} />

| Column | Meaning |
|--------|---------|
| **Item** | The device or asset name |
| **Predicted total** | The value for the whole period, measured part plus forecast |
| **Actual** | The measured part, from the start of the period to the latest reading |
| **Predicted** | The forecast part, from the latest reading to the end of the period |
| **Previous** | The same value for the previous period |
| **Δ %** | The change against the previous period |
| **Last refresh**, **Refresh status**, **Training** | The item's refresh and training state |

Each column header shows the dates it covers. The names follow the selected tab, so with Maximum selected the first
value column reads **Predicted peak**.

### Result page settings

The **Result page** card on the Properties tab sets how the Result tab opens for everyone. The **Cumulative** and
**Compare** buttons on the chart change the view only for your session.

<ImageGallery images={[
  {
    src: '/src/assets/images/trendz/prediction/period-result-settings.webp',
    alt: 'Result page card on the Properties tab with units, default aggregation, and the enable comparison, cumulative, compare, and reverse colors switches',
    caption: 'The Result page card sets the units, the opening tab, and the two chart toggles.',
  },
]} />

| Setting | Effect |
|---------|--------|
| **Units** | Printed after the values on the card and in the table |
| **Default aggregation** | The tab the card opens on: Sum, Maximum, Average, or Minimum |
| **Enable comparison** | Master switch for the previous period. Off hides vs Previous, the Compare button, and the Δ % column |
| **Cumulative by default** | Whether the chart opens on the running aggregate |
| **Compare by default** | Whether the previous period is overlaid when the tab opens |
| **Reverse comparison colors** | Colors a fall as good news, for metrics where less is better, such as energy |

None of them rebuilds the model. Click **Apply changes** and the Result tab follows.
