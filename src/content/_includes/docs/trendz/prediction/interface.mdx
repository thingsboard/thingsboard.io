**Prediction models** in the left menu is where you create, open, and manage prediction models. One model predicts
one telemetry key for the items of one device or asset profile, and keeps its forecasts, events, and alarms up to
date.

## Layout

**Prediction models** opens on two tabs. The **Summary** tab shows the state of every model at a glance.

### Summary tab

The **Summary** tab opens by default. It shows every prediction model of the tenant: how they refresh, how accurate
they are, which profiles they cover, and how their latest runs went.

## Model tabs

The model page has up to five tabs. Click a tab name to switch to it.

- **Result** shows what the model predicts, in a layout that depends on its intent.
- **Properties** shows how the model is set up, and lets you change it.
- **Events** lists the predicted events. Time to Threshold models only.
- **Accuracy metrics** shows how close past forecasts came to what really happened.
- **Tasks** shows the training and refresh runs of the model.

The first four are described in detail on their own pages, linked below. **Tasks** is described here.

### Result tab

The predictions of every item. The chart shows the selected item, and the table lists all items.

<ImageGallery images={[
  {
    src: '/src/assets/images/trendz/prediction/interface-tab-result.webp',
    alt: 'Result tab of Time to Threshold: Backup Generators with the Result tab name highlighted',
    caption: 'The Result tab.',
  },
]} />

Its layout depends on the intent, and each one is described on its intent page:

| Intent | Result tab shows | Described in |
|--------|------------------|--------------|
| **Forecast** | The predicted values over the horizon | <DocLink product={props.product} path='prediction/intents/forecast#forecast-result-page'>Forecast</DocLink> |
| **Period Total** | The predicted total of the current period | <DocLink product={props.product} path='prediction/intents/period-total#period-total-result-page'>Period Total</DocLink> |
| **Time to Threshold** | The time left until the value crosses a limit | <DocLink product={props.product} path='prediction/intents/time-to-threshold#time-to-threshold-result-page'>Time to Threshold</DocLink> |
| **Hit Target** | Whether each item reaches its goal by the end of the period | <DocLink product={props.product} path='prediction/intents/hit-target#hit-target-result-page'>Hit Target</DocLink> |

Two parts are the same for every intent: the item actions, and the **Data status** card.

### Item actions

The **⋯** at the end of an item row opens the actions for that one item.

| Action | What it does |
|--------|--------------|
| **Refresh** | Learns from the readings that arrived since the last refresh, and predicts again |
| **Retrain** | Trains the item again from its whole training period, for example after its behavior changed or its training failed |
| **Delete** | Takes the item out of the model. The device or asset in ThingsBoard stays as it is |

### Tasks tab

Trendz runs the work of a model as tasks: one that trains it, and one that refreshes it on a schedule while periodic
refresh is on. The **Tasks** tab lists them, so you can check when each run happened and whether it finished.

<ImageGallery images={[
  {
    src: '/src/assets/images/trendz/prediction/interface-tab-tasks.webp',
    alt: 'Tasks tab of Time to Threshold: Backup Generators with the Tasks tab name highlighted and two tasks: the scheduled refresh and the training task',
    caption: 'The Tasks tab.',
  },
]} />

| Column | Description |
|--------|-------------|
| **Name** | The task and the model, for example **Prediction model, refresh: Time to Threshold: Backup Generators (fuelLevel)** |
| **Created** | When the task was created |
| **Updated** | When the task last changed |
| **Status** | **RUNNING** while a run is in progress, **NOT ACTIVE** between runs |
| **Task type** | **Run Once** for training, **Scheduled** for the periodic refresh |
| **Job Type** | **Train prediction model** or **Save prediction model result to TB** |

The **⋯** menu at the end of a row holds two actions:

- **Details** opens the runs of the task: when each started and finished, how long it took, and its status.
  Clicking the row does the same.
- **Go to Task** opens the task on the global **Tasks** page, in a new browser tab. The page is described in
