**Trendz Analytics** is an add-on for ThingsBoard that turns raw IoT telemetry into actionable insights.
It connects directly to your ThingsBoard entity model and lets you explore data from any device or asset,
detect anomalies, forecast trends, and share the results as dashboard widgets — without writing code.

## What you can do with Trendz

| Capability | Description |
|------------|-------------|
| **Explore telemetry** | Instantly browse and visualise any metric from any device or asset in your ThingsBoard instance |
| **Calculated fields** | Define custom KPIs and derived metrics using a no-code formula builder; store results back in ThingsBoard |
| **Anomaly detection** | Train ML models to flag unusual patterns in time-series data; trigger ThingsBoard alarms |
| **Prediction** | Forecast future values using built-in or custom Python models |
| **State analysis** | Track how long equipment spends in each operating state |
| **AI Assistant** | Generate visualisations and plain-language summaries with natural language prompts |
| **Dashboard embedding** | Embed any Trendz view as a widget in a ThingsBoard dashboard |
| **White-labelling** | Customise Trendz branding and translations for your end-users |

## How Trendz fits into ThingsBoard

```plaintext
  ThingsBoard
  ┌──────────────────────────────────────────────┐
  │  Devices & Assets  →  Telemetry & Attributes │
  └────────────────────────┬─────────────────────┘
                           │  reads entity model
                           │  and telemetry
                           ▼
  Trendz Analytics
  ┌──────────────────────────────────────────────┐
  │  Visualise  │  Calculate  │  Predict         │
  │  Detect     │  Summarise  │  Embed           │
  └────────────────────────┬─────────────────────┘
                           │  pushes calculated
                           │  fields, alarms, widgets
                           ▼
  ThingsBoard Dashboards
```
