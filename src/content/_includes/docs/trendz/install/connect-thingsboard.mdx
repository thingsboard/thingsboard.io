This page is for users connecting Trendz to **ThingsBoard 4.2.1 or older**. If you are on a newer version, the sync happens automatically — see the installation guide for your platform.

<Aside type="caution" title="Upgrade recommended">
ThingsBoard 4.2.1 and older are no longer supported. Upgrade to the latest version to use all Trendz features without manual configuration.
</Aside>

## Install Trendz for ThingsBoard 4.2.1 or older

1. Follow **Steps 1–5** of the installation guide for your platform.
2. Before the **Start Trendz service** step, configure `TRENDZ_LICENSE_SECRET` and `TB_API_URL` as described below.
3. Complete all remaining steps, **except** the Sync ThingsBoard With Trendz step.
4. After the service is running, perform the post-installation steps manually.

## Configure license secret

To connect to ThingsBoard 4.2.1 or older, Trendz requires a license secret key. If you don't have one, contact [ThingsBoard support](/docs/contact-us/).

Edit the Trendz configuration file:

```bash
sudo nano /etc/trendz/conf/trendz.conf
```

Add the following line, replacing `YOUR_LICENSE_SECRET_HERE` with your key:

```bash
export TRENDZ_LICENSE_SECRET=YOUR_LICENSE_SECRET_HERE
```

For Docker installations, set the `TRENDZ_LICENSE_SECRET` environment variable in your Docker Compose file.

## Configure TB_API_URL

By default, Trendz expects ThingsBoard to be running on the same server at:

```
http://localhost:9090
```

If ThingsBoard is on a different server or port, update the configuration:

```bash
sudo nano /usr/share/trendz/conf/trendz.conf
```

Set the correct URL:

```bash
export TB_API_URL=http://localhost:9090
```

For Docker installations, set the `TB_API_URL` environment variable in your Docker Compose file.
