Trendz AI features send requests to a large language model (LLM) that you connect in **Settings > AI Settings**.
This page shows how to add a model, check that Trendz can reach it, and choose which features use it.

| AI feature | Where you use it |
|------------|------------------|
| **Prompts** | <DocLink product={props.product} path="ai-widget-summary">AI Widget Summary</DocLink> and other user-created prompts |
| **View Assistant** | The <DocLink product={props.product} path="ai-assistance-overview">AI Assistant</DocLink> chat that answers questions and builds views |
| **Metric Code Assistant** | Metric generation in <DocLink product={props.product} path="metric/overview">Metric Explorer</DocLink> |

<Aside type="note">
Trendz Cloud includes a default model with a limited request quota. Self-hosted Trendz has no default model, so you
add one before any AI feature works. AI models and settings belong to a tenant: tenants on the same instance can use
different providers.
</Aside>

## Before you start

Get credentials from one of the supported providers:

| Provider | What you need | Where to get it |
|----------|---------------|-----------------|
| **Google Gemini** (recommended) | API key | <a href="https://ai.google.dev/gemini-api/docs/api-key" target="_blank" rel="noopener noreferrer">Google AI Studio</a> |
| **OpenAI** | API key | <a href="https://platform.openai.com/api-keys" target="_blank" rel="noopener noreferrer">OpenAI platform</a> |
| **Amazon Bedrock** | AWS region, access key, and secret key | <a href="https://docs.aws.amazon.com/bedrock/latest/userguide/getting-started-api.html" target="_blank" rel="noopener noreferrer">AWS Bedrock API guide</a> |

## Add an AI model

<Steps>
1. On the **AI Settings** tab, click **New AI Model**.
2. Enter a **Name** that identifies the model in Trendz, and choose the **Provider**.
3. Choose the **Model Name**. Trendz fills in the provider's newest chat model, and the list under the field suggests
   the others, newest first. Type to filter it, or enter any other model name the provider accepts. The suggestions come
   from the public models.dev catalog: if Trendz cannot reach it, the field stays empty and you type the model name.
4. Enter the credentials. For Google Gemini, that is the **API Key**.
</Steps>

<Steps>
5. Click **Check connectivity**. Trendz sends a test request to the provider with the values in the form.

7. Click **Save**. The model appears in the **AI Models** list.
</Steps>

<Aside type="tip">
Saving does not test the connection. Run **Check connectivity** before you save, so a wrong key or model name does not
reach your users as a failed AI request.
</Aside>

You can add several models, like a fast and inexpensive one for prompts and a more capable one for metric code.

## Turn on AI features

<Steps>
1. Turn on **Enable AI Features**.
2. Choose how features get their model:
   - **Use Single Model** on: select the model in **Single AI Model**. Every feature uses it.
   - **Use Single Model** off: select a model for **Prompts**, **View Assistant**, and **Metric Code Assistant**
     separately. Select **Disabled** to turn a feature off for everyone in the tenant.
3. Click **Save**.
</Steps>

## Edit a model

Change a model's name, provider, model name, or credentials, like when you rotate an API key or move to a newer model.
Features that use the model switch to the new values as soon as you save.

<Steps>
1. In the **AI Models** list, click the actions menu (**...**) in the model's row and select **Edit**. Clicking the row
   itself opens the same form.
2. Change the fields you need. The form is the same as **New AI Model**, and its title shows the model you edit.
3. Click **Check connectivity** and wait for **Connected**, especially after you change the key or the model name.
4. Click **Save**. Trendz shows **AI Model was saved**, and the list shows the new values.
</Steps>

## Delete a model

<Steps>
1. Make sure no AI feature still uses the model. If one does, select another model for it in the AI features section
   and click **Save**.
2. In the **AI Models** list, click the actions menu (**...**) in the model's row and select **Delete**.
3. Click **Yes** to confirm. Trendz shows **Success!**, and the model disappears from the list.
</Steps>

## Provider fields

Every model has a **Name**, which only labels it in Trendz, and a **Provider**. The provider decides which other fields
the form shows.

| Provider | Field | What to enter |
|----------|-------|---------------|
| **Google Gemini** | **Model Name** | The Gemini model ID, like `gemini-3.5-flash-lite` |
| | **API Key** | An API key from <a href="https://ai.google.dev/gemini-api/docs/api-key" target="_blank" rel="noopener noreferrer">Google AI Studio</a> |
| **OpenAI** | **Base URL** | The API endpoint. Leave the default `https://api.openai.com/v1` for OpenAI itself, or enter the endpoint of any service with an OpenAI-compatible API, like a self-hosted model server |
| | **Model Name** | The OpenAI model ID |
| | **API Key** | A secret key from the <a href="https://platform.openai.com/api-keys" target="_blank" rel="noopener noreferrer">OpenAI platform</a> |
| **Amazon Bedrock** | **Region** | The AWS region where Bedrock gives your account access to the model, like `us-east-1` |
| | **Model Name** | The Bedrock model ID or inference profile ID, as listed in the Bedrock console |
| | **Access Key** | The access key ID of an IAM user allowed to invoke Bedrock models |
| | **Secret Key** | The secret access key of that IAM user. See the <a href="https://docs.aws.amazon.com/bedrock/latest/userguide/getting-started-api.html" target="_blank" rel="noopener noreferrer">AWS Bedrock API guide</a> |

When you choose a provider, Trendz fills **Model Name** with that provider's newest chat model. Replace it if you want
another model. Keys show as dots in the form, including when you edit a saved model.

Token prices depend on the model and change over time. Check the provider's pricing page before you choose a model.
