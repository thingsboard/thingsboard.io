The Pie Chart view splits a total value into proportional slices. Two sections define the chart:

| Section | Purpose |
|---------|---------|
| **Sector Value** | The numeric field that determines each slice's size — drop a telemetry field here with the required aggregation (SUM, AVG, etc.) |
| **Sector Name** | The field that splits the data into groups — each unique value becomes a separate slice (device name, asset attribute, product category, etc.) |

```plaintext
  Sector Name:  building name
  Sector Value: energy_consumption (SUM)

              Building C
               (18%)
           ╱────────────╲
          ╱  Building A   ╲
         │    (45%)        │
         │                 │
          ╲  Building B   ╱
           ╲────────────╱
               (37%)

  Total = sum of all buildings' energy consumption
```
