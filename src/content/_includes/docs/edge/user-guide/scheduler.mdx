The **ThingsBoard Scheduler** automates periodic tasks on the Edge, like telemetry and attribute updates, RPC commands, and rule chain triggers. It runs locally, so scheduled tasks keep running even when the Edge has no connection to the server.

<Aside type="note">
  Scheduler is a Professional Edition feature. For the full configuration reference, see the <DocLink product={Products.PE} path="user-guide/scheduler" target="_blank">ThingsBoard Scheduler</DocLink> documentation.
</Aside>

You can create scheduler events on the server and assign them to the Edge, or, on Edge 4.3 and later, create them directly on the Edge. Both run locally on the Edge.

## Configure scheduler events

<Steps>

1. On the server, go to **Platform > Scheduler**.

2. Click **Add scheduler event**. Enter a **Name** and, on the **Configuration** tab, select the **Event type**, for example **Send RPC Request to Device** or **Update Attributes**, and fill in its fields. On the **Schedule** tab, set the **Start time** and, if needed, **Repeat**. Click **Create**. For all fields, see the <DocLink product={Products.PE} path="user-guide/scheduler" target="_blank">Scheduler Event dialog</DocLink> documentation.

3. Go to **Edge management > Edges**, open the Edge, and go to its **Assignments** tab. In **Scheduler events**, click **Assign scheduler event to this edge**, select the event, and click **Assign**.

4. On the Edge, go to **Platform > Scheduler** to confirm that the event was received. The list shows its **Name** and **Type**.

</Steps>

To run the same events on many Edges, add them to their <DocLink product={props.product} path="user-guide/edge-management#edge-profiles">edge profile</DocLink> instead. A scheduler event owned by a customer reaches only Edges owned by that customer.

To remove an event from the Edge, open the Edge's **Assignments** tab on the server and click **Unassign from this edge** in the row of the event.

To create an event on the Edge instead, go to **Platform > Scheduler** on the Edge and click **Add scheduler event**. The dialog is the same. The Edge pushes the event to the server, where it appears under **Platform > Scheduler** and is assigned to this Edge.

## Use case: Smart Irrigation on ThingsBoard Edge

The <a href="/iot-hub/solution-templates/smart-irrigation/" target="_blank" rel="noopener noreferrer">Smart Irrigation solution template</a> shows the Scheduler in a remote deployment. It irrigates fields based on soil moisture readings and fixed schedules, with ThingsBoard Edge running locally so that irrigation continues during network outages.

The solution:
- Irrigates fields twice a day at fixed times.
- Monitors soil moisture, daily water consumption, and irrigation duration in real time.
- Runs locally on ThingsBoard Edge, independent of internet connectivity.

### Install the solution template

On the server, go to **IoT Hub > Solution Templates**, find **Smart irrigation**, and click **Install**.

The template creates an Edge and assigns everything it needs to it. To see them, go to **Edge management > Edges**, open the Edge, and go to its **Assignments** tab.

### Scheduler configuration

The **Scheduler events** section of the Edge's **Assignments** tab lists the assigned events. To view the configuration of an event, open it under **Platform > Scheduler**:

- The **Configuration** tab shows the event type, the message type, and the **Message body** with the parameters of the task.
- The **Schedule** tab shows when and how often the event runs.

On the Edge, go to **Platform > Scheduler** to confirm that the events were received.

### Rule chain configuration

The **Rule chains** section of the same **Assignments** tab lists the rule chains the template assigned to the Edge, and marks the one that is its root.

### Dashboard

The template also assigns a dashboard to the Edge. Open it on the Edge to see soil moisture, water consumption, and irrigation duration.

### Benefits

Running the Scheduler on ThingsBoard Edge:
- Keeps irrigation running in remote locations, even without a connection to the server.
- Saves water by running irrigation on a fixed schedule.
- Reduces manual work through automated event execution.
- Provides real-time soil moisture telemetry even when offline.
