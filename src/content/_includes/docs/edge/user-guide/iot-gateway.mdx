ThingsBoard Edge can run alongside the <a href="/docs/iot-gateway/" target="_blank" rel="noopener noreferrer">ThingsBoard IoT Gateway</a> on the same device. The IoT Gateway collects data from local sensors and legacy protocols, translates it into ThingsBoard-compatible format, and sends it to the Edge. The Edge rule engine processes it in real time and synchronizes results with the central server.

<DocImage src="/src/assets/images/docs/edge/user-guide/iot-gateway/how-does-it-work.webp" alt="Architecture diagram: the IoT Gateway sends data to Edge, and Edge synchronizes with the ThingsBoard server" width="600px" />

<Aside type="note">
When deployed in a remote location with an unreliable internet connection, Edge continues operating until connectivity is restored.
</Aside>

## Prerequisites

- <a href="https://docs.docker.com/engine/install/" target="_blank" rel="noopener noreferrer">Docker</a> installed on the IoT Gateway device.
- A ThingsBoard server account (Cloud, Professional Edition, or Community Edition).
- A Linux-based IoT Gateway device with SSH access.

<Aside type="caution">
ThingsBoard Edge uses port **8080** for its web UI, and the ThingsBoard IoT Gateway also defaults to port **8080**. When both run on the same device, one of them must use a different port. Configure this in the respective `docker-compose.yml` file before starting the services.
</Aside>

## Step 1. Create a new Edge instance

<Steps>
1. Log in to your ThingsBoard server and go to **Edge management > Edges**.

2. Click **Add edge** and select **Add new edge**.

3. Enter a name for the Edge instance and click **Add**. The new Edge appears at the top of the list, and the **Edge created! Check Install & Connect Instructions** dialog opens with ready-to-use installation instructions. You can close it for now: the next step shows how to open the instructions again.
</Steps>

## Step 2. Install Edge on the IoT Gateway device

Connect to the device over SSH:

```bash
ssh username@ip_address
```

Replace `username` and `ip_address` with your device credentials. If SSH runs on a non-default port, add `-p <port>` to the command.

<Steps>
1. Create a directory for the Edge service:

   ```bash
   mkdir tb_edge
   ```

2. Inside that directory, create a `docker-compose.yml` file:

   ```bash
   nano docker-compose.yml
   ```

3. On the server, go to **Edge management > Edges**, open the Edge, and click **Install & Connect Instructions** on its **Details** tab.

4. Select the **Docker** tab, copy the configuration lines, paste them into `docker-compose.yml`, and save the file. Press **CTRL+X** to close the editor.

5. Start the Edge container:

   ```bash
   docker compose up -d
   docker compose logs -f mytbedge
   ```

   Run both commands from the `tb_edge` directory.
</Steps>

To verify Edge started successfully, log in to the Edge UI and go to **Edge > Status**. The **Status** field should show **Connected**.

To access the Edge UI from your local machine, open another terminal tab and set up SSH port forwarding:

```bash
ssh -N -L 8080:127.0.0.1:8080 username@ip_address
```

- **`8080` (first):** The port on your local machine.
- **`127.0.0.1`:** The target host accessible from the IoT Gateway device.
- **`8080` (second):** The port on the IoT Gateway device.
- **`username`:** The username with access to the device.
- **`ip_address`:** The IP address of the device.

Any connection to `localhost:8080` on your local machine is forwarded to `127.0.0.1:8080` on the IoT Gateway device. Open <a href="http://127.0.0.1:8080" target="_blank" rel="noopener noreferrer">http://127.0.0.1:8080</a> and log in with your tenant credentials.

## Step 3. Provision the IoT Gateway on Edge

<Steps>
1. Open the Edge UI at <a href="http://127.0.0.1:8080" target="_blank" rel="noopener noreferrer">http://127.0.0.1:8080</a>, log in with your tenant credentials, and go to **Devices & assets > Gateways**.

2. Click **Add Gateway**. In the **Add gateway** dialog, enter the gateway name in the **Name** field, select the **default** device profile, and click **Create**.

3. The **Launch command** dialog opens. Under **Download configuration file**, click **Download** to get the `docker-compose.yml` file for the IoT Gateway. The file already contains the access token of the gateway and the address of the Edge. To open this dialog again later, open the gateway in the list and click **Launch command**.
</Steps>

## Step 4. Install the IoT Gateway software on the device

Connect to the device over SSH:

```bash
ssh username@ip_address
```

<Steps>
1. Create a directory for the IoT Gateway service:

   ```bash
   mkdir iot_gateway
   ```

2. Inside that directory, create a `docker-compose.yml` file:

   ```bash
   nano docker-compose.yml
   ```

3. Paste the contents of the downloaded `docker-compose.yml` into the new file and save it. Press **CTRL+X** to close.

4. Start the IoT Gateway:

   ```bash
   docker compose up -d
   docker compose logs -f
   ```
</Steps>

To verify the IoT Gateway connected successfully, go to **Devices & assets > Gateways** on the Edge. The **Status** of the gateway changes from **Inactive** to **Active**.
