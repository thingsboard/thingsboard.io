## Create a rule chain template on the server

<Steps>
1. On the server, go to **Edge management → Rule chain templates** and click **Add** (+).
2. Enter a name and click **Add**.
3. Open the new template, configure your rule nodes and connections, and click **Apply changes**.
</Steps>

The template is not yet active on any Edge until you assign it.

## Assign a template to an Edge instance

<Steps>
1. On the server, go to **Edge management → Instances**, open the target Edge instance, and click **Manage rule chains**.
2. Click **Add** (+), select the template from the list, and click **Assign**.
</Steps>

The template is pushed to the Edge instance and becomes active immediately.

## Create a rule chain directly on Edge

Available from Edge 4.0. Changes made on Edge propagate back to the server automatically when the connection is available.

<Steps>
1. On the Edge instance, go to **Rule chains** and click **Add** (+).
2. Choose **Create new rule chain**, enter a name, and click **Add**.
3. Configure your rule nodes and click **Apply changes**.
</Steps>
