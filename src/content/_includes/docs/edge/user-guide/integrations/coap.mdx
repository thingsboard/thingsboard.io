**CoAP Integration** opens a CoAP server on the Edge. CoAP devices post their data to it, and the uplink converter turns the payload into ThingsBoard telemetry.

<Aside type="note">
  The Edge CoAP integration works the same way as the CoAP integration on the ThingsBoard server. Only the way it is created and deployed differs. For the full list of settings, see <DocLink product={Products.CE} path="user-guide/integrations/coap" target="_blank">CoAP Integration</DocLink>.
</Aside>

## Prerequisites

- A ThingsBoard server with tenant administrator access. The templates are created there.
- A ThingsBoard Edge PE instance connected to the server.
- The `coap-client` utility to simulate a device:

  ```bash
  sudo apt update
  sudo apt install libcoap2-bin
  coap-client --version
  ```

This guide uses the **NO SECURE** security mode. The example sensor **SN-001** posts temperature and humidity to the Edge at `10.7.3.0`, port `15683`. Replace this with the IP address of your Edge and the port the CoAP integration should listen on.

The device can send its data in one of three payload formats. Pick the one that matches your device:

<Tabs>
  <TabItem label="Text">
    ```text
    SN-001,default,temperature,25.7,humidity,69
    ```
  </TabItem>
  <TabItem label="JSON">
    ```json
    {
      "deviceName": "SN-001",
      "deviceType": "default",
      "temperature": 25.7,
      "humidity": 69
    }
    ```
  </TabItem>
  <TabItem label="Binary">
    ```text
    \x53\x4e\x2d\x30\x30\x31\x64\x65\x66\x61\x75\x6c\x74\x32\x35\x2e\x37\x36\x39
    ```

    | Bytes | Hex | Value |
    |---|---|---|
    | 0-5 | `\x53\x4e\x2d\x30\x30\x31` | Device name `SN-001` |
    | 6-12 | `\x64\x65\x66\x61\x75\x6c\x74` | Device type `default` |
    | 13-16 | `\x32\x35\x2e\x37` | Temperature `25.7` |
    | 17-18 | `\x36\x39` | Humidity `69` |
  </TabItem>
</Tabs>

## Create converter template

The CoAP integration has no downlink, so only an uplink converter is needed. It is created on the server.

<Steps>

1. On the server, go to **Edge management > Templates** and open the **Converter** tab. Click **Add data converter** and select **Create new converter**.

2. Set **Converter type** to **Uplink**, select **CoAP** as the **Integration type**, and enter the name `CoAP uplink converter`.

3. In **Main decoding configuration**, select **TBEL**, paste the script for your payload format, and click **Add**.

   <Tabs>
     <TabItem label="Text payload">
       ```js maxLines=10 collapsible
       /** Decoder **/

       // decode payload to string
       var strArray = decodeToString(payload);
       var payloadArray = strArray.replaceAll("\"", "").split(',');

       var telemetryPayload = {};
       for (var i = 2; i < payloadArray.length; i = i + 2) {
           var telemetryKey = payloadArray[i];
           var telemetryValue = parseFloat(payloadArray[i + 1]);
           telemetryPayload[telemetryKey] = telemetryValue;
       }

       // Result object with device attributes/telemetry data
       var result = {
           deviceName: payloadArray[0],
           deviceType: payloadArray[1],
           telemetry: telemetryPayload,
           attributes: {}
       };

       /** Helper functions 'decodeToString' and 'decodeToJson' are already built-in **/

       return result;
       ```
     </TabItem>
     <TabItem label="JSON payload">
       ```js maxLines=10 collapsible
       /** Decoder **/

       // decode payload to JSON
       var data = decodeToJson(payload);

       var deviceName = data.deviceName;
       var deviceType = data.deviceType;
       var result = {
           deviceName: deviceName,
           deviceType: deviceType,
           attributes: {},
           telemetry: {
               temperature: data.temperature,
               humidity: data.humidity
           }
       };

       /** Helper functions 'decodeToString' and 'decodeToJson' are already built-in **/

       return result;
       ```
     </TabItem>
     <TabItem label="Binary payload">
       ```js maxLines=10 collapsible
       /** Decoder **/

       // decode payload to string
       var payloadStr = decodeToString(payload);

       var deviceName = payloadStr.substring(0, 6);
       var deviceType = payloadStr.substring(6, 13);

       // Result object with device/asset attributes/telemetry data
       var result = {
           deviceName: deviceName,
           deviceType: deviceType,
           attributes: {},
           telemetry: {
               temperature: parseFloat(payloadStr.substring(13, 17)),
               humidity: parseFloat(payloadStr.substring(17, 19))
           }
       };

       /** Helper functions 'decodeToString' and 'decodeToJson' are already built-in **/

       return result;
       ```
     </TabItem>
   </Tabs>

</Steps>

<Aside type="note">
  To see every processed message on the **Events** tab while you test, click the debug button in the dialog (it shows **Failures** by default) and select **All messages (15 min)**.
</Aside>

## Create integration template

<Steps>

1. On the server, go to **Edge management > Templates**, open the **Integration** tab, and click **Add integration**.

2. On the **Basic settings** step, select **CoAP** as the **Integration type**. Keep the name `CoAP integration` or enter your own. Click **Next**.

3. On the **Uplink data converter** step, select **Select existing**, choose `CoAP uplink converter`, and click **Next**. The CoAP wizard has no downlink step.

4. On the **Connection** step, keep **Security mode** at **NO SECURE** and set **Base URL** to `coap://${{edgeIp}}`. Click **Add**.

</Steps>

**Base URL** is the address the CoAP server listens on, with the `coap://` scheme, for example `coap://10.7.3.0:15683`. The integration endpoint is `<Base URL>/i/<integration key>`. The `${{edgeIp}}` placeholder lets you assign one template to several Edges: each Edge replaces it with the value of its own `edgeIp` server attribute. See <DocLink product={props.product} path="user-guide/integrations/overview#configuration-placeholders">Configuration placeholders</DocLink>.

<Aside type="note">
  The debug button on the **Basic settings** step is set to **15 min** by default, so the **Events** tab of the integration shows all messages for the first 15 minutes. After that, only failures are stored. Debug events are stored in the database, so do not keep all messages enabled in production.
</Aside>

## Assign the integration to the Edge

Add the `edgeIp` attribute first. Without it, the assignment dialog warns **Edge has missing attribute(s)** and the Edge receives the literal placeholder.

<Steps>

1. On the server, go to **Edge management > Edges** and click the Edge. On the **Attributes** tab, with the **Server attributes** scope selected, click **+**. Enter `edgeIp` as the key and the Edge IP address with the CoAP port, for example `10.7.3.0:15683`, as the value. Click **Add**.

2. Go to the Edge's **Assignments** tab. In **Integrations**, click **Assign integration to this edge**, select `CoAP integration`, and click **Assign**.

3. Log in to the Edge and go to **Integrations > Integrations**. Open the integration. **Base URL** shows `coap://10.7.3.0:15683` instead of the placeholder, and **CoAP endpoint URL** shows the full endpoint.

</Steps>

Once the integration is assigned, the CoAP server on the Edge starts and waits for device data.

## Send an uplink message

<Steps>

1. On the Edge, go to **Integrations > Integrations**, open the CoAP integration, and copy the **CoAP endpoint URL**.

2. Send a test message for your payload format. Replace `$YOUR_COAP_ENDPOINT_URL` with the copied URL:

   <Tabs>
     <TabItem label="Text payload">
       ```shell
       echo -e 'SN-001,default,temperature,25.7,humidity,69' | coap-client -m post $YOUR_COAP_ENDPOINT_URL -t text/plain -f-
       ```
     </TabItem>
     <TabItem label="JSON payload">
       ```shell
       echo -e -n '{"deviceName": "SN-001", "deviceType": "default", "temperature": 25.7, "humidity": 69}' | coap-client -m post $YOUR_COAP_ENDPOINT_URL -t application/json -f-
       ```
     </TabItem>
     <TabItem label="Binary payload">
       ```shell
       echo -e -n '\x53\x4e\x2d\x30\x30\x31\x64\x65\x66\x61\x75\x6c\x74\x32\x35\x2e\x37\x36\x39' | coap-client -m post $YOUR_COAP_ENDPOINT_URL -t application/octet-stream -f-
       ```
     </TabItem>
   </Tabs>

3. Open the **Events** tab of the integration. An **Uplink** event with status **OK** appears.

4. The device **SN-001** is created automatically. On the Edge, go to **Devices & assets > Devices**, open it, and select the **Latest telemetry** tab. The `temperature` and `humidity` keys show the received values.

5. To see how the converter processed the message, go to **Integrations > Data converters**, open `CoAP uplink converter`, and select the **Events** tab. The **In** column shows the raw payload, the **Out** column the decoded result.

</Steps>
