A **public dashboard** can be opened by anyone who has its link, without logging in. It is always read-only.

On ThingsBoard Edge, public dashboards work the same as on the ThingsBoard server, with a few differences:

- The public link uses the local address of the Edge: `http://<Edge-IP>:8080/dashboard/<dashboard-id>?publicId=<public-customer-id>`.
- The dashboard keeps working on the local network when the Edge has no connection to the server. It shows live data from the devices on the Edge.
- Changes you make to the dashboard on the Edge are synchronized to the server once the connection is restored.

For creating and editing dashboards, see <DocLink product={props.product} path="user-guide/dashboards" target="_blank">Dashboards</DocLink>.

<Aside type="note">
The dashboard and the data behind it are made public separately. To show data from devices, assets, and entity views through the public link, make their entity groups public too.
</Aside>

## Make a dashboard public

You make a whole dashboard group public, not a single dashboard. Dashboard groups are created and made public on the ThingsBoard server and then <DocLink product={props.product} path="user-guide/edge-management#assign-entities-to-an-edge">assigned to the Edge</DocLink>. The Edge UI has no **Make public** action.

<Steps>
1. On the server, go to **Monitor > Dashboards** and open the **Groups** tab.
2. Click the **Make public** icon in the row of the dashboard group and confirm. On the Edge, the **Public** column of the **Groups** tab shows a check mark for this group.
3. On the Edge, go to **Monitor > Dashboards**, open the **Groups** tab, and open the group. Click the **Public dashboard link** icon in the row of the dashboard and copy the link from the dialog.
</Steps>

## Make a dashboard private

On the server, go to **Monitor > Dashboards**, open the **Groups** tab, click the **Make private** icon in the row of the dashboard group, and confirm. All public links of the dashboards in this group stop working, on the Edge too.
