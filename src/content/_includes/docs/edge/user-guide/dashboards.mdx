Dashboards on ThingsBoard Edge work the same way as on the ThingsBoard server. They display real-time IoT data from devices connected locally to the Edge, and continue working even when the Edge instance is offline. Widgets show the most recently received data during an outage. When the connection is restored, any changes made on Edge are synchronized to the server automatically.

For a general introduction to dashboards and widgets, see <DocLink product={props.product} path="user-guide/dashboards" target="_blank">Dashboards</DocLink>.

## Assign a dashboard from the server

Dashboards reach an Edge through dashboard groups. To assign a dashboard group to an Edge:

<Steps>
1. On the ThingsBoard server, go to **Edge management > Edges** and click the Edge.
2. On the **Details** tab, click **Manage dashboard groups**.
3. Click **Assign to edge** (+), select the group, and click **Assign**.
</Steps>

The dashboard group is sent to the Edge as a downlink. If the Edge is connected, the dashboards appear right away. If it is offline, they appear once the connection is restored. To check, log in to the Edge and go to **Monitor > Dashboards**.

## Create a dashboard on Edge

You can also create dashboards directly on the Edge. Dashboards created on Edge are sent to the ThingsBoard server automatically when the connection is available.

<Steps>
1. Log in to the Edge and go to **Monitor > Dashboards**.

2. Click **Add dashboard** and select **Create new dashboard**. To upload a previously exported dashboard JSON file instead, select **Import dashboard**.

3. Enter the dashboard **Title** and click **Add**.

4. The new dashboard opens in edit mode. Add widgets with **Add widget**, then click **Save**.

   The dashboard appears in the list and is pushed to the server automatically. To check, go to **Monitor > Dashboards** on the server.
</Steps>

To edit an existing dashboard, open it and click **Edit mode** in the toolbar. The dashboard editor works the same way as on the server. For details, see <DocLink product={props.product} path="user-guide/dashboards" target="_blank">Dashboards</DocLink>.

<Aside type="note">
If you have multiple Edge instances, deleting a dashboard on one Edge instance does not affect the others. To remove a dashboard from all Edge instances at once, delete it from the ThingsBoard server.
</Aside>

## Make a dashboard public

A public dashboard is accessible to anyone with the link, without logging in. On Edge, the link points to the Edge instance's local URL, so the dashboard remains available on the local network even if the internet connection is lost.

<Aside type="note">
For data to appear on a public dashboard, the devices it displays must also be made public.
</Aside>

{props.product === Products.EDGE && (
  <>
    <Steps>
      <ol>
        <li>Go to <strong>Monitor &gt; Dashboards</strong> and click <strong>Make public</strong> (share icon) next to the dashboard.<br />
          A confirmation dialog appears with the public link.
        </li>
        <li>Copy the link and click <strong>OK</strong>.<br />
          The link can also be retrieved later from the dashboard's <strong>Details</strong> panel.
        </li>
      </ol>
    </Steps>
    <p>To make a public dashboard private again, click <strong>Make private</strong> (↩ icon) in the dashboard list and confirm.</p>
  </>
)}

{props.product === Products.EDGE_PE && (
  <Aside type="note">
    In ThingsBoard PE, public access is managed at the dashboard group level, not per individual dashboard. For the steps, see <DocLink product={props.product} path="user-guide/public-dashboard">Public dashboards</DocLink>.
  </Aside>
)}

## Assign entity views to Edge

Entity views expose a filtered subset of a device's attributes and telemetry to specific users, without granting access to the full device. You can create them on the Edge or on the server.

For a general introduction to entity views, see <DocLink product={props.product} path="user-guide/provision-entity-view" target="_blank">Entity views</DocLink>.

Entity views reach an Edge through entity view groups. To assign an entity view group to an Edge:

<Steps>
1. On the ThingsBoard server, go to **Edge management > Edges** and click the Edge.
2. On the **Details** tab, click **Manage entity view groups**.
3. Click **Assign to edge** (+), select the group, and click **Assign**.
</Steps>

## Remove a dashboard from Edge

Unassigning a dashboard group removes it from that Edge only. The dashboards stay on the server and can be assigned again at any time.

<Steps>
1. On the ThingsBoard server, open the Edge and click **Manage dashboard groups** on its **Details** tab.
2. In the row of the group, click **Unassign entity group from edge** and confirm.
</Steps>

To remove only one dashboard from the Edge, remove it from the group on the server.
