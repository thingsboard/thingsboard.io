Running ThingsBoard Edge behind a <a href="https://en.wikipedia.org/wiki/Proxy_server" target="_blank" rel="noopener noreferrer">proxy server</a> means all outbound communication — to ThingsBoard Cloud or any other external service — is routed through the proxy instead of going directly to the internet.

<DocImage src="/src/assets/images/docs/edge/user-guide/edge-proxy/without-proxy.webp" alt="Direct connection — Edge connects to ThingsBoard Cloud without a proxy" width="400px" />

<DocImage src="/src/assets/images/docs/edge/user-guide/edge-proxy/with-proxy.webp" alt="Indirect connection — Edge connects to ThingsBoard Cloud through a proxy server" width="575px" />

This setup is common in restricted network environments where direct internet access is deliberately blocked. Proxies also add a security layer by filtering and monitoring outbound traffic, and can cache resources to reduce bandwidth usage.

## Prerequisites

- A proxy server (HTTP or HTTPS) with its host, port, and credentials if required.
- Java 17 installed.
- ThingsBoard Edge installed and running.

## Step 1. Modify the configuration file

Edit `/etc/tb-edge/conf/tb-edge.conf` to enable the proxy:

```bash
sudo tee -a /etc/tb-edge/conf/tb-edge.conf > /dev/null <<EOL
#Enable the proxy
export CLOUD_RPC_PROXY_ENABLED=true

#Set the proxy server host and port
export CLOUD_RPC_PROXY_HOST="proxy_host"
export CLOUD_RPC_PROXY_PORT="proxy_port"
EOL
```

Replace `proxy_host` and `proxy_port` with your proxy's hostname and port.

If certain hosts should bypass the proxy (e.g., local network addresses), add a `NO_PROXY` variable using the format: `localhost|127.0.0.1|yourdomain.com`.

### Configure authentication (optional)

If your proxy requires authentication, append the following:

```bash
export CLOUD_RPC_PROXY_USERNAME="proxy_username"
export CLOUD_RPC_PROXY_PASSWORD="proxy_password"
```

Replace `proxy_username` and `proxy_password` with your actual credentials.

### Verify the changes (optional)

```bash
cat /etc/tb-edge/conf/tb-edge.conf
```

## Step 2. Restart ThingsBoard Edge

```bash
sudo service tb-edge restart
```

Once restarted, open the Edge UI at <a href="http://localhost:8080" target="_blank" rel="noopener noreferrer">http://localhost:8080</a> and log in with your tenant credentials.

<Aside type="note">
If the Edge HTTP port was changed to **18080** during installation, access Edge at <a href="http://localhost:18080" target="_blank" rel="noopener noreferrer">http://localhost:18080</a> instead.
</Aside>

## Troubleshooting

Check Edge logs for errors:

```bash
cat /var/log/tb-edge/tb-edge.log | grep ERROR
```

Test connectivity through the proxy:

```bash
curl -x http://proxy_host:proxy_port https://your_tb_cloud_url
```

Confirm the proxy host is reachable:

```bash
ping proxy_host
traceroute proxy_host
```

## Prerequisites

- A proxy server (HTTP or HTTPS) with its host, port, and credentials if required.
- ThingsBoard Edge installed and running via Docker Compose.
- <a href="https://docs.docker.com/engine/install/" target="_blank" rel="noopener noreferrer">Docker</a> and <a href="https://docs.docker.com/compose/install/" target="_blank" rel="noopener noreferrer">Docker Compose</a> installed.

<Aside type="note">
Run all commands from the directory that contains your `docker-compose.yml` file.
</Aside>

## Step 1. Stop the container

```bash
docker compose stop
```

## Step 2. Update docker-compose.yml

Open the file:

```bash
sudo nano docker-compose.yml
```

Add the following lines to the `environment` block:

```yaml
      HTTP_PROXY: http://proxy_user:proxy_password@proxy_host:proxy_port
      HTTPS_PROXY: http://proxy_user:proxy_password@proxy_host:proxy_port
      NO_PROXY: localhost,127.0.0.1,postgres,PUT_YOUR_CLOUD_IP
```

- **`HTTP_PROXY` / `HTTPS_PROXY`** — proxy address for HTTP and HTTPS traffic. Example: `http://user:password@proxy.example.com:8080`
- **`NO_PROXY`** — comma-separated list of addresses that bypass the proxy. Example: `localhost,127.0.0.1,postgres,thingsboard.cloud`

## Step 3. Restart the containers

```bash
docker compose up -d && docker compose logs -f mytbedge
```

Once started, open the Edge UI at <a href="http://localhost:8080" target="_blank" rel="noopener noreferrer">http://localhost:8080</a> and log in with your tenant credentials.

<Aside type="note">
If the Edge HTTP port was changed to **18080** during installation, access Edge at <a href="http://localhost:18080" target="_blank" rel="noopener noreferrer">http://localhost:18080</a> instead.
</Aside>

## Troubleshooting

Verify proxy environment variables are set:

```bash
echo $HTTP_PROXY
echo $HTTPS_PROXY
echo $NO_PROXY
```

If not set, check inside the running container:

```bash
docker exec -it container_name printenv | grep -i proxy
```

Test internet access through the proxy from inside the container:

```bash
docker exec -it container_name curl -I https://google.com
```

Test connectivity to ThingsBoard Cloud through the proxy:

```bash
curl -x http://proxy_host:proxy_port https://your_tb_cloud_url
```

Check container logs for proxy-related errors:

```bash
docker logs container_name
```
