A rule chain template is a rule chain created on the server, on the **Rule chain** tab of **Edge management > Templates**. It does not run on the server. It is copied to every Edge you assign it to, and runs there. On Edge 4.0 and later, you can also create and edit rule chains directly on the Edge.

## Create a template on the server

Use a template when you want to deploy the same rule chain logic to several Edges from one place.

<Steps>
1. On the server, go to **Edge management > Templates** and open the **Rule chain** tab. Click **+** and select **Create new rule chain**.
2. Enter a name and click **Add**.
3. Click the new template in the list to open it. Use the **Search nodes** field on the left to find rule nodes, drag them onto the canvas, connect them, and click **Apply changes**.
</Steps>

The template is not active on any Edge until you assign it.

## Assign a template to an Edge

<Steps>
1. On the server, go to **Edge management > Edges** and click the Edge.
2. On the **Details** tab, click **Manage rule chains**.
3. Click **Assign to edge** (+). In the **Assign Rule Chain(s) To Edge** dialog, select the template and click **Assign**.
</Steps>

The template appears in the rule chain list of this Edge. The **Root** column shows which rule chain is the root rule chain of the Edge.

The template is sent to the Edge as a downlink. If the Edge is connected, it receives the rule chain right away. If it is offline, it receives it once the connection is restored.

To assign a template to every new Edge automatically, or to make it the root rule chain of new Edges, use the row actions **Assign rule chain to edge(s) on creation** and **Make rule chain as edge template root** in the template list. See <DocLink product={props.product} path="user-guide/edge-management#rule-chains-of-new-edges">Rule chains of new Edges</DocLink>.

## Create a rule chain directly on Edge

Available from Edge 4.0. Rule chains created on Edge are sent to the server automatically when the connection is available. Use this approach for Edge-specific logic that does not need to be shared with other Edges.

<Steps>
1. On the Edge, go to **Data processing > Rule chains**, click **+**, and select **Create new rule chain**.
2. Enter a name and click **Add**.
3. Click the new rule chain in the list to open it. Add and connect your rule nodes, then click **Apply changes**.
</Steps>

## Verify a rule chain on Edge

After you assign a template or create a rule chain on Edge, confirm that it is active and configured correctly.

<Steps>
1. Log in to the Edge and go to **Data processing > Rule chains**. The rule chain is in the list.
2. Open it and check that the nodes and connections match what you defined.
</Steps>
