Running ThingsBoard Edge behind a <a href="https://en.wikipedia.org/wiki/Proxy_server" target="_blank" rel="noopener noreferrer">proxy server</a> means that its gRPC connection to the ThingsBoard server (port 7070 by default, set by `CLOUD_RPC_PORT`) is routed through the proxy instead of going directly to the internet. Edge opens this connection through the proxy with an HTTP `CONNECT` tunnel. Only this connection uses the proxy: devices, the Edge UI, and the local database are not affected, so there is no bypass list to configure.

This setup is common in restricted network environments where direct internet access is deliberately blocked. Proxies also add a security layer by filtering and monitoring outbound traffic, and can cache resources to reduce bandwidth usage.

## Prerequisites

- An HTTP proxy server that allows `CONNECT` to the ThingsBoard server's gRPC port, with its host, port, and credentials if required.
- ThingsBoard Edge must be installed and running.

## Step 1. Modify the configuration file

Edit `/etc/tb-edge/conf/tb-edge.conf` to enable the proxy:

```bash
sudo tee -a /etc/tb-edge/conf/tb-edge.conf > /dev/null <<EOL
#Enable the proxy
export CLOUD_RPC_PROXY_ENABLED=true

#Set the proxy server host and port
export CLOUD_RPC_PROXY_HOST="proxy_host"
export CLOUD_RPC_PROXY_PORT="proxy_port"
EOL
```

Replace `proxy_host` and `proxy_port` with your proxy's hostname and port.

### Configure authentication

If your proxy requires authentication, append the following to the same file:

```bash
export CLOUD_RPC_PROXY_USERNAME="proxy_username"
export CLOUD_RPC_PROXY_PASSWORD="proxy_password"
```

Replace `proxy_username` and `proxy_password` with your actual credentials.

### Verify the changes

```bash
cat /etc/tb-edge/conf/tb-edge.conf
```

Confirm that `CLOUD_RPC_PROXY_ENABLED`, `CLOUD_RPC_PROXY_HOST`, and `CLOUD_RPC_PROXY_PORT` appear with the correct values.

## Step 2. Restart ThingsBoard Edge

```bash
sudo service tb-edge restart
```

Once restarted, open the Edge UI at <a href="http://localhost:8080" target="_blank" rel="noopener noreferrer">http://localhost:8080</a> and log in with your tenant credentials. Go to **Edge → Status** and confirm the **Status** field shows **Connected** — this confirms Edge is reaching the server through the proxy.

<Aside type="note">
If the Edge HTTP port was changed to **18080** during installation, access Edge at <a href="http://localhost:18080" target="_blank" rel="noopener noreferrer">http://localhost:18080</a> instead.
</Aside>

## Troubleshooting

Check Edge logs for errors:

```bash
cat /var/log/tb-edge/tb-edge.log | grep ERROR
```

Test connectivity through the proxy:

```bash
curl -x http://proxy_host:proxy_port https://your_tb_cloud_url
```

Confirm the proxy host is reachable:

```bash
ping proxy_host
traceroute proxy_host
```
