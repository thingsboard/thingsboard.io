OTA firmware packages are created on the ThingsBoard server, automatically propagated to all connected Edge instances, and then assigned to devices or device profiles on Edge. This recipe walks through the complete workflow.

<Aside type="caution">
  OTA packages can only be created on the ThingsBoard server. They cannot be created, modified, or deleted on the Edge.
</Aside>

## Step 1 — Upload the firmware package on the server

<Steps>
1. Log in to the ThingsBoard server and go to **Devices & assets > OTA updates**.
2. Click **Add package** and fill in:
   - **Title:** a descriptive name (for example, `sensor-fw-v2.1`)
   - **Version:** the firmware version string
   - **Version tag:** auto-populated from the version field; override only if it must match a specific string reported by the device
   - **Device profile:** the profile of devices this firmware targets
   - **Package type:** **Firmware**
3. Either upload a binary file, or select **Use external URL** and enter the download link in **Direct URL**.
4. Click **Add**.
</Steps>

<Aside type="caution">
  Once a package is saved, the title, version, device profile, and type cannot be modified.
</Aside>

## Step 2 — Confirm propagation to Edge

The package is automatically pushed to all connected Edge instances.

<Steps>
1. Log in to the Edge and go to **Devices & assets > OTA updates**.
2. Confirm the new package appears in the list.
</Steps>

<Aside type="note">
  If the Edge is offline when the package is created, it will sync the package once connectivity is restored.
</Aside>

## Step 3 — Assign the firmware to a device or profile

<Steps>
1. On the Edge, go to **Devices & assets > Devices** (or **Devices & assets > Device profiles**).
2. Open the target device or profile and click the pencil icon (**Toggle edit mode**).
3. In the **Assigned firmware** field, select the uploaded package.
4. Click **Apply changes**.
</Steps>

ThingsBoard Edge notifies the device of the available update. The device retrieves the firmware chunks over its active transport (MQTT, CoAP, or HTTP).

## Monitor update progress

Go to **Devices & assets > Devices**, open the device, and check the **Attributes** tab for the `fw_state` and `fw_version` keys to track download and installation progress.

For the full OTA reference including software updates and attribute keys, see <DocLink product={props.product} path='user-guide/ota-updates' target="_blank">OTA updates</DocLink>.
