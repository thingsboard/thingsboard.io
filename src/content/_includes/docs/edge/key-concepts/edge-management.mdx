Edge management covers the tools and workflows for provisioning, monitoring, and controlling Edge instances from the ThingsBoard server.

## Overview

An Edge instance represents a remote ThingsBoard Edge node connected to the cloud server. From the server, you can assign rule chains, dashboards, and entity groups to each Edge instance, monitor its connectivity status, and push configuration updates without manual on-site access.

## Edge instances

Each Edge instance is registered on the server as a dedicated entity. You can view and manage all registered Edge instances under **Edge Management > Instances**.

## Assigned entities

You control what data and logic runs on an Edge instance by assigning entities to it:

- **Rule chains:** Assign custom rule chains to process data locally on the Edge.
- **Dashboards:** Push dashboards to the Edge for local visualization.
- **Entity groups:** Assign device and asset groups so the Edge synchronizes their data.

Changes to assigned entities are propagated to the Edge instance automatically when it is online, or queued and delivered when it reconnects.

## Architecture options

- **Edge with ThingsBoard Cloud:** Simplest deployment. Edge instances sync with ThingsBoard Cloud. No server infrastructure to manage.
- **Edge with self-hosted ThingsBoard:** Run ThingsBoard server on-premise or in your own cloud. Full control over infrastructure and data.
- **Edge standalone:** Run Edge without cloud connection. Suitable for fully isolated sites or air-gapped environments.
- **Hybrid (multi-site):** Deploy Edge at every remote location (factories, stores, substations). Aggregate data in the cloud for enterprise-wide analytics.
