**ThingsBoard Agent** installs, upgrades, and monitors ThingsBoard Edge remotely from the cloud: no manual Docker commands and no maintenance access to the target machine. The agent is a small Docker container that runs next to Edge on the same host, connects to your ThingsBoard server, and executes deployments on its behalf.

Compared to a manual Docker installation, the agent adds:

- **Remote installation:** Deploy Edge from the ThingsBoard UI to any host where the agent runs.
- **Managed upgrades:** Push new Edge versions from the cloud, with volume backups, automatic database migration, and rollback on failure.
- **Monitoring:** Host and container metrics, container states, and live logs in the ThingsBoard UI.
- **Fleet operations:** Upgrade or restart all Edge instances of a fleet with <DocLink product={props.product} useTbDocs path='user-guide/agents/bulk-actions'>bulk actions</DocLink>.

## Prerequisites

- ThingsBoard Professional Edition server or a ThingsBoard Cloud tenant.
- Docker installed on the target machine (Linux, amd64 or arm64).
- Outbound network access from the target machine to the ThingsBoard gRPC port (default `7070`).

## Install Edge with an agent

<Steps>
  <ol>
    <li>
      Create an Edge instance in ThingsBoard: go to **Edge management > Edges**, click **Add** (+), enter a name, and click **Add**.
    </li>
    <li>
      Open the Edge details and click **Install & connect instructions**, then select the **Agent** tab.
    </li>
    <li>
      Select the agent that runs on the target machine. If the machine has no agent yet, create one and run the generated `docker run` command on the target machine first; see <DocLink product={props.product} useTbDocs path='user-guide/agents/installation'>Install ThingsBoard Agent</DocLink>.
    </li>
    <li>
      Review the deployment configuration and confirm. The agent pulls the Edge images, creates the containers, and starts the instance; the **Event progress** dialog shows every step.
    </li>
    <li>
      Verify the result. The Edge details page shows the agent deployment status: agent health, the managed application, and recent events. The Edge instance connects to the server and appears as active.
    </li>
  </ol>
</Steps>

Once deployed, open the Edge UI at `http://<target-machine>:8080` and log in with your tenant administrator credentials.

## Provision a fleet

To roll out many Edge instances without creating each one by hand, use <DocLink product={props.product} useTbDocs path='user-guide/agents/agent-profiles'>agent auto-provisioning</DocLink> with the **Edge** preset. Every machine that runs the provisioning command registers a new agent and receives an Edge deployment automatically.

## Upgrade Edge remotely

Agent-managed Edge instances upgrade from the ThingsBoard UI: the agent stops the instance, backs up the selected volumes, migrates the database when needed, and starts the new version. A failed upgrade rolls back automatically. See <DocLink product={props.product} useTbDocs path='user-guide/agents/application-actions'>Application actions</DocLink>.

<Aside type="note">
To install Edge without an agent, use the manual <DocLink product={props.product} path='installation/docker'>Docker installation</DocLink>.
</Aside>
