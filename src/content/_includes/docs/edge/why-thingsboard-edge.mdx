## ThingsBoard Edge features

- **Local data processing**: Process and store device data without a cloud connection. Telemetry, alarms, and entity updates sync to the cloud when connectivity resumes.
- **Traffic filtering**: Filter device data on the edge and push only the required subset to the cloud for storage or further processing.
- **Local alarms**: Respond to critical conditions on site without a cloud connection.
- **Real-time dashboards**: Monitor local events and time series data on dashboards running at the edge.
- **Batch configuration updates**: Apply configuration changes to multiple Edge instances from the cloud in a single operation.
