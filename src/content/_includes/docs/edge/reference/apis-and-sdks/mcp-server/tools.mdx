The MCP server provides tools organized into the following groups. All groups are enabled by default and work against Edge's local REST API. To turn a group off, set its variable to `false`.

| Group | Variable | Description |
|-------|----------|-------------|
| **Entity data query** | `THINGSBOARD_TOOLS_EDQ` | Entity data queries and query guides |
| **Telemetry** | `THINGSBOARD_TOOLS_TELEMETRY` | Read, write, and delete attributes and time-series data |
| **Devices** | `THINGSBOARD_TOOLS_DEVICE` | Find, create, update, and delete devices, and manage their credentials |
| **Assets** | `THINGSBOARD_TOOLS_ASSET` | Find, create, update, and delete assets |
| **Alarms** | `THINGSBOARD_TOOLS_ALARM` | Find, acknowledge, clear, and manage alarms |
| **OTA packages** | `THINGSBOARD_TOOLS_OTA` | Manage firmware and software updates |
| **Relations** | `THINGSBOARD_TOOLS_RELATION` | Find, create, and delete entity relations |
| **Customers** | `THINGSBOARD_TOOLS_CUSTOMER` | Find and manage customers |
| **Users** | `THINGSBOARD_TOOLS_USER` | Find and manage users |
| **Entity groups** | `THINGSBOARD_TOOLS_GROUP` | Find and manage entity groups |

On the Edge, write operations follow the Edge rules: for example, customers, entity groups, and OTA packages can be created only on the server, so those requests fail on the Edge.

For a full tool reference, see the <a href="https://github.com/thingsboard/thingsboard-mcp" target="_blank" rel="noopener noreferrer">ThingsBoard MCP GitHub repository</a>.

## Example prompts

Here are some prompts to try once the MCP server is connected to your Edge node:

- **Devices:** "List all devices on this Edge node and show their latest telemetry."
- **Telemetry:** "Generate sample temperature data for Sensor A1 for the last 7 days with a 30-minute sampling rate."
- **Alarms:** "Show all active alarms with CRITICAL severity."
- **Anomaly detection:** "Analyze the power consumption of Building 3 for the past week and flag any anomalies."
- **Relations:** "Show all devices related to asset 'Factory Floor 1' and their connection types."
