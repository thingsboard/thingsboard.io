## Built-in transport protocols

These protocols apply to devices that communicate over standard IP transports and can connect directly to ThingsBoard Edge.

- <DocLink product={props.product} path="reference/apis-and-sdks/mqtt-api" target="_blank">MQTT API</DocLink>
- <DocLink product={props.product} path="reference/apis-and-sdks/coap-api" target="_blank">CoAP API</DocLink>
- <DocLink product={props.product} path="reference/apis-and-sdks/http-api" target="_blank">HTTP API</DocLink>
- <DocLink product={props.product} path="reference/apis-and-sdks/lwm2m-api" target="_blank">LwM2M API</DocLink>
- <DocLink product={props.product} path="reference/apis-and-sdks/snmp-api" target="_blank">SNMP API</DocLink>

Most protocols support JSON, Protobuf, or a custom data format. This is the best option for new devices when you control the firmware.

## IoT Gateway

<a href="/docs/iot-gateway/" target="_blank" rel="noopener noreferrer">ThingsBoard IoT Gateway</a> connects devices in local networks without direct internet access, or using non-IP protocols — including MQTT, OPC-UA, Modbus, BLE, HTTP, CAN, BACnet, ODBC, and SNMP. The gateway converts device data to the ThingsBoard format and forwards it over MQTT to the platform.

## LoRaWAN

ThingsBoard Edge supports ChirpStack and many other LoRaWAN network servers via <a href="/docs/pe/user-guide/integrations/" target="_blank" rel="noopener noreferrer">Integrations</a>, including <a href="/docs/pe/user-guide/integrations/ttn/" target="_blank" rel="noopener noreferrer">TheThingsStack</a>, <a href="/docs/pe/user-guide/integrations/tti/" target="_blank" rel="noopener noreferrer">TheThingsIndustries</a>, <a href="/docs/pe/user-guide/integrations/loriot/" target="_blank" rel="noopener noreferrer">LORIOT</a>, <a href="/docs/pe/user-guide/integrations/thingpark/" target="_blank" rel="noopener noreferrer">Actility ThingPark</a>, and any server that supports <a href="/docs/pe/user-guide/integrations/http/" target="_blank" rel="noopener noreferrer">webhooks</a> or <a href="/docs/pe/user-guide/integrations/mqtt/" target="_blank" rel="noopener noreferrer">MQTT</a>. Custom <a href="/docs/pe/user-guide/integrations/" target="_blank" rel="noopener noreferrer">data converters</a> let you transform incoming payloads to suit your data model.

## Sigfox

ThingsBoard Edge supports Sigfox via the built-in <a href="/docs/pe/user-guide/integrations/sigfox/" target="_blank" rel="noopener noreferrer">Sigfox integration</a>.
