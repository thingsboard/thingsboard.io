## v4.4.1 (Nov 25, 2026)

**Patch** release with everything from [ThingsBoard v4.4.1](/docs/pe/releases/releases-table/v4-4-x/#v4-4-1) and adds the following:

* <a href="https://github.com/thingsboard/thingsboard-edge/pull/254" target="_blank" rel="noopener noreferrer">#254</a> **Mail, SMS and notifications:** Delegate mail, SMS and notification sends from Edge to the cloud by <a href="https://github.com/MazurenkoNick" target="_blank" rel="noopener noreferrer">@MazurenkoNick</a>.
* <a href="https://github.com/thingsboard/thingsboard-edge/pull/253" target="_blank" rel="noopener noreferrer">#253</a> **Persistent RPC sync:** Sync persistent RPC (v2) status updates and delete events from Edge to the cloud by <a href="https://github.com/MazurenkoNick" target="_blank" rel="noopener noreferrer">@MazurenkoNick</a>.
* <a href="https://github.com/thingsboard/thingsboard-edge/pull/263" target="_blank" rel="noopener noreferrer">#263</a> **API key sync:** Process API key sync messages on the edge side by <a href="https://github.com/MazurenkoNick" target="_blank" rel="noopener noreferrer">@MazurenkoNick</a>.
* <a href="https://github.com/thingsboard/thingsboard-edge/pull/252" target="_blank" rel="noopener noreferrer">#252</a> **Licensing:** Move Edge to license client 3.0.0 by <a href="https://github.com/MazurenkoNick" target="_blank" rel="noopener noreferrer">@MazurenkoNick</a>.

Upgrade the ThingsBoard server to 4.4.1 before the Edge: older servers do not process the mail, SMS and notification sends that Edge 4.4.1 delegates to them. The upgrade also removes the system mail and SMS settings that the cloud used to sync to the Edge, and rotates the Edge JWT signing key, so users signed in to the Edge UI have to log in again.

## v4.4.0 (Oct 5, 2026)

**Major** release with everything from [ThingsBoard v4.4.0](/docs/pe/releases/releases-table/v4-4-x/#v4-4-0).

Starting with this release, ThingsBoard Edge is one product, licensed under the Business Source License 1.1, and its Docker images and Linux packages use the `tb-edge` names: `thingsboard/tb-edge:<version>EDGE` and `tb-edge-<version>.deb` / `.rpm` from the [thingsboard-edge GitHub releases](https://github.com/thingsboard/thingsboard-edge/releases). Edge 4.4.0, 4.4.0.1 and 4.4.0.2 were also published under the former Edge PE names (`thingsboard/tb-edge-pe:<version>EDGEPE` and the `tb-edge-<version>pe` packages); those keep working, and the upgrade instructions use the `tb-edge` names.
