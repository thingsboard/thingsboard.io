## v4.4.0 (Oct 10, 2026)

**Major** release with everything from [ThingsBoard v4.4.0](/docs/pe/releases/releases-table/v4-4-x/#v440-sep-29-2026).

Starting with this release, the Edge Docker image, image tag and Linux packages use the `tb-edge` names: `thingsboard/tb-edge:4.4.0EDGE` replaces `thingsboard/tb-edge-pe:<version>EDGEPE`.
