In this step, you will create an Edge instance record in your ThingsBoard account, install the instance, and access the Edge UI.

---

## Provision Edge

Before installing Edge software, create an Edge instance record in your ThingsBoard account. This generates the credentials Edge uses to authenticate.

<Steps>
1. Log in to your ThingsBoard account as a Tenant Administrator. Use your own credentials or the defaults (`tenant@thingsboard.org` / `tenant`).

2. Go to **Edge management → Edges**, click **Add edge** in the top-right corner, and select **Add new edge**.

3. Enter a name for the Edge instance and click **Add**.
</Steps>

## Install ThingsBoard Edge

After you create the Edge instance, the installation instructions appear in a dialog. Each Edge has preset configurations that contain important credentials, such as **Edge Secret**, **Edge Key**, etc.

<Steps>
1. In the **Edge created** dialog, select your installation method — **Docker**, **Ubuntu**, or **CentOS/RHEL** — and follow the displayed commands to install and start ThingsBoard Edge.

2. Once Edge starts (this may take a few seconds), open <a href="http://localhost:8080" target="_blank" rel="noopener noreferrer">http://localhost:8080</a> in a browser and log in with your Tenant Administrator credentials.
</Steps>

If you are unable to access or use the preset configurations, see the <DocLink product={props.product} path="installation/" target="_blank">manual installation instructions</DocLink>.

<Aside type="tip" title="Manage Edge remotely">
Instead of running the install commands yourself, install Edge with [Remote Agent](/docs/edge/pe/installation/agent/): you deploy Edge from the ThingsBoard UI, upgrade it with volume backups and rollback, and monitor its containers and logs without logging in to the host.
</Aside>

<Aside type="tip">
If you closed the dialog, reopen the instructions by clicking the Edge instance and then clicking **Install & Connection Instructions**.
</Aside>
