In this step, you will create an Edge instance record in your ThingsBoard account, install the instance, and access the Edge UI.

---

## Provision Edge

Before installing Edge software, create an Edge instance record in your ThingsBoard account. This generates the credentials (**Edge key** and **Edge secret**) that Edge uses to authenticate on the server.

<Steps>
1. Log in to your ThingsBoard account as a Tenant Administrator. Use your own credentials or the defaults (`tenant@thingsboard.org` / `tenant`).

2. Go to **Edge management > Edges**, click **Add edge**, and select **Add new edge**.

3. Enter a name for the Edge{props.product === Products.EDGE_PE && <>, keep or change the <strong>Edge profile</strong>,</>} and click **Add**. The new Edge appears at the top of the list, and the **Edge created! Check Install & Connect Instructions** dialog opens with the installation instructions.
</Steps>

---

## Install ThingsBoard Edge

The dialog contains ready-to-use commands. They already include the Edge key and Edge secret of this Edge, so you do not need to copy anything by hand.

<Steps>
1. In the dialog, select the tab for your installation method (**Docker**, **Ubuntu**, or **CentOS/RHEL**) and run the displayed commands to install and start ThingsBoard Edge. The dialog opens on the **Agent** tab, which is for remote installation with a Remote Agent; you do not need it for this tutorial.

2. Once Edge starts (this may take a few seconds), open <a href="http://localhost:8080" target="_blank" rel="noopener noreferrer">http://localhost:8080</a> in a browser and log in with your Tenant Administrator credentials. If Edge runs on the same machine as the server and you changed the ports as the instructions suggest, use port `18080` instead.

3. In the Edge UI, go to **Edge > Status**. The status is **Connected**. On the server, the **Attributes** tab of the Edge shows the server attribute `active` = `true`.
</Steps>

<Aside type="tip">
If you closed the dialog, or turned on **Do not show again** earlier, open the Edge and click **Install & Connect Instructions** on its **Details** tab.
</Aside>

If you cannot use the commands from the dialog, see the <DocLink product={props.product} path="installation/" target="_blank">manual installation instructions</DocLink>.
