## Major improvements

### Available now

- <DocLink product={Products.EDGE_PE} path='installation/agent'>Installation with Remote Agent</DocLink>: Install, monitor, update, and upgrade ThingsBoard Edge on remote hosts from the ThingsBoard server.

### Coming soon

- **Edge profiles:** Manage the configuration of many Edge instances in one place through shared profiles.
- **More device protocols on Edge:** Connect devices to ThingsBoard Edge over protocols that today are available only through ThingsBoard IoT Gateway.
- **New Edge home page:** An updated Edge overview on the ThingsBoard server, and a new home page on ThingsBoard Edge itself.
