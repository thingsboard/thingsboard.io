<DocSection id="java" current={props.section}>

ThingsBoard is built on Java and requires Java 17 to run. Install OpenJDK 17 from the Ubuntu package repository:

```bash
sudo apt update && sudo apt install -y openjdk-17-jdk-headless
```

Set Java 17 as the default version. Use the non-interactive command:

```bash
sudo update-alternatives --set java /usr/lib/jvm/java-17-openjdk-$(dpkg --print-architecture)/bin/java
```

Or, if you have multiple Java versions installed and want to choose interactively:

```bash
sudo update-alternatives --config java
```

Verify the installation:

```bash
java -version
```

</DocSection>

<DocSection id="troubleshooting" current={props.section}>

Check the service status:

```bash
sudo systemctl status thingsboard
```

ThingsBoard logs are stored in `/var/log/thingsboard`. Check for errors:

```bash
grep ERROR /var/log/thingsboard/thingsboard.log
```

Monitor logs in real time:

```bash
tail -f /var/log/thingsboard/thingsboard.log
```

Or via journalctl:

```bash
sudo journalctl -u thingsboard.service -f --no-pager
```

For more troubleshooting tips, see the <DocLink product={props.product} path="guides/troubleshooting">Troubleshooting</DocLink> guide.

</DocSection>
