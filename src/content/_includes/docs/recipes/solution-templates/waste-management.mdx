The **Waste Management** solution template represents a solution for monitoring and controlling the fullness of waste containers. With this solution, you can monitor the placement of garbage bins, their fullness, and view statistics about garbage bins.

With a single installation action, the template deploys a fully functional dashboard, device profiles, alarms, and demo devices. No custom rule chains, widgets, or backend configuration are required.

## Key application areas

This solution template can be used as a baseline for:

- **Smart municipalities:** Optimizing city-wide trash collection routes to reduce traffic and emissions
- **Parks and recreation:** Servicing bins in remote park areas only when necessary
- **Commercial campuses:** Managing waste generation across large office parks or university grounds

## Install solution template

To understand how the Waste management solution works, start by installing the solution template.

<Steps>
1. Go to **Solution templates** in the main menu.
2. Find **Waste management** and click **Install**.
3. Follow the provided configuration instructions and click **Close**.
4. The **Waste Management Administration** dashboard opens automatically.
</Steps>

After installation, a fully functional simulation for monitoring waste container fullness is created automatically. No devices, integrations, or custom code are required to start exploring the solution.

## System components

The Waste Management template includes:

- **Dashboard:** The Waste Management Administration dashboard displays data from waste sensors, provides an interactive map with bin locations and fullness indicators, a list of all sensors, and a centralized alarm view
- **Devices:** Ten pre-provisioned waste monitoring sensors that are already connected and provide demo telemetry data
- **Device profile and logic:** A predefined Waste Sensor <DocLink product={props.product} path='user-guide/device-profiles'>device profile</DocLink> with built-in logic and pre-configured alarms for fullness level and low battery conditions

### Dashboard states

The dashboard consists of two states:

- **Main state:** Displays the location and filling status of bins on an interactive map, provides real-time data on bin fullness, allows viewing and managing all available sensors, and includes controls for the notification system regarding fullness and battery level
- **Bin details state:** Opens when a sensor row is selected from the list or when clicking details on a sensor popup on the map. Allows viewing and editing basic information and sensor placement, monitoring trash and battery statistics, and controlling the notification system for fullness and battery levels

The dashboard can be fully customized using the <DocLink product={props.product} path='user-guide/dashboards'>dashboard</DocLink> development tools.

## Devices

Ten demo waste monitoring sensors are created automatically with demonstration data. The solution expects devices to publish telemetry data in JSON format using the following keys:

```json
{"fullLevel": 42, "batteryLevel": 77}
```

To send telemetry on behalf of a device, use the following command. Replace `$ACCESS_TOKEN` with the actual access token of the device you want to send data to:

<Code code={`curl -v -X POST \\
  -d '{"fullLevel": 42, "batteryLevel": 77}' \\
  http://${tbHost(props.product)}/api/v1/$ACCESS_TOKEN/telemetry \\
  --header "Content-Type:application/json"`} lang="bash" />

The example uses the <DocLink product={props.product} path='reference/http-api'>HTTP API</DocLink>.
Other connectivity options (MQTT, CoAP, LwM2M, etc.) are supported as well. See <DocLink product={props.product} path='getting-started-guides/connectivity'>connecting devices</DocLink> for details.

## Alarms

Alarm generation is handled by <DocLink product={props.product} path='user-guide/alarm-rules'>alarm rules</DocLink> configured in the Waste Sensor <DocLink product={props.product} path='user-guide/device-profiles'>device profile</DocLink>.

| Alarm type | Severity | Condition |
|---|---|---|
| Bin full | Warning | Fill level reaches 90% or above |
| Low battery | Warning | Battery level drops below 30% |

Alarm thresholds and enable/disable state can be modified directly from the dashboard using the **Edit Sensor** form.

## Conclusion

The Waste Management solution template delivers a container monitoring system with real-time fullness tracking, interactive map visualization, and configurable alarms. It enables fast onboarding and serves as a foundation for both demonstrations and production waste collection optimization use cases.
